# Setting Up Your First Hypertable

This page intentionally contains style issues so reviewdog can comment on them
inline. Each line below trips a different rule.

Connect to Tiger Cloud and create a hypertable in your service, e.g. for metrics.
The columnstore compresses old data — it saves a lot of space.

Click **Save** to apply your changes.

Convert a chunk to the columnstore with the old API:

```sql
SELECT compress_chunk('_timescaledb_internal._hyper_1_1_chunk');
```
