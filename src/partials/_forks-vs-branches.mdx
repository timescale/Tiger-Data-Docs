### Forks and branches

There are two ways to copy a {C.SERVICE_SHORT}:

| | Fork | Branch |
|---|---|---|
| Available on | Standard and Fluid | Fluid |
| What it is | A full, independent copy with its own storage | A lightweight copy that shares the primary {C.SERVICE_SHORT}'s storage and stores only what changes |
| Ready in | Minutes to hours, growing with the data | A minute or two, whatever the data size |
| Lifetime | Long-lived | Short-lived |
| Features | High availability, read replicas, backups, point-in-time recovery | Compute and IOPS settings only; no high availability, backups, or point-in-time recovery |
| Use for | Staging, disaster recovery, upgrade rehearsal | Development, CI, agent workflows |
