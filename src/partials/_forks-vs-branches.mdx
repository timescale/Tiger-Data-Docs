{props.heading && <h3 id="forks-and-branches">Forks and branches</h3>}

{props.heading && <p>Fluid {C.SERVICE_SHORT}s offer a lighter alternative to a fork. A branch shares the {C.SERVICE_SHORT}'s storage, is ready in about a minute, and supports a smaller set of operations. Choose by how long you need the copy and what it must support.</p>}

| | Fork | Branch |
|---|---|---|
| What it is | A full, independent copy of the {C.SERVICE_SHORT} with its own storage | An isolated copy that shares the {C.SERVICE_SHORT}'s storage and stores only what differs |
| Available on | Standard and Fluid {C.SERVICE_SHORT}s | Fluid {C.SERVICE_SHORT}s |
| Ready in | Minutes to hours, growing with the data | About a minute, whatever the data size |
| Starts from | The {C.SERVICE_SHORT}'s current data, or a point in time | The {C.SERVICE_SHORT}'s current data |
| Operations | Everything you can do with the parent {C.SERVICE_SHORT}: resize, add replicas, back up and restore, connect data sources, monitor, upgrade, and more | Resize, reset the password, pause and resume, delete |
| Billing | Compute and storage by the hour | Compute and storage by the minute. Storage is copy-on-write: you pay only for the data the branch changes or adds, not for the data it shares with the {C.SERVICE_SHORT} |
| Use for | Staging, disaster recovery, upgrade rehearsal | Development, CI, agent workflows |
