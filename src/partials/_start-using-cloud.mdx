To start using {C.CLOUD_LONG} for your data:

1. [Create a {C.ACCOUNT_LONG}][create-an-account]: register to get access to {C.CONSOLE} as a centralized point to administer and interact with your data.
1. [Create a {C.SERVICE_LONG}][create-a-service]: that is, a {C.PG} database instance, powered by [{C.TIMESCALE_DB}][timescaledb], built for production, and extended with cloud features like transparent data tiering to object storage.
1. [Connect to your {C.SERVICE_LONG}][connect-to-your-service]: to run queries, add and migrate your data from other sources.

[connect-to-your-service]: /getting-started/services/#connect-to-your-service
[create-a-service]: /getting-started/services/#create-a-service
[create-an-account]: /getting-started/services/#create-a-tiger-cloud-account
[timescaledb]: https://www.tigerdata.com/docs/#TimescaleDB
