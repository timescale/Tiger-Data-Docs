To start using {C.CLOUD_LONG} for your data:

1. [Create a {C.ACCOUNT_LONG}](/getting-started/services/#create-a-tiger-cloud-account): register to get access to {C.CONSOLE} as a centralized point to administer and interact with your data.
1. [Create a {C.SERVICE_LONG}](/getting-started/services/#create-a-service): that is, a {C.PG} database instance, powered by [{C.TIMESCALE_DB}](https://www.tigerdata.com/docs/#TimescaleDB), built for production, and extended with cloud features like transparent data tiering to object storage.
1. [Connect to your {C.SERVICE_LONG}](/getting-started/services/#connect-to-your-service): to run queries, add and migrate your data from other sources.
