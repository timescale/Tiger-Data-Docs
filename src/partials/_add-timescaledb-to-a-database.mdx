import * as C from "../constants";
import { Steps, Step } from "@stainless-api/docs/components";

<Steps>

<Step title={`Connect to a database on your ${C.PG} instance`}>

In {C.PG}, the default user and database are both `postgres`. To use a 
different database, set `<database-name>` to the name of that database:

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

</Step>

<Step title={`Add ${C.TIMESCALE_DB} to the database`}>

```sql
CREATE EXTENSION IF NOT EXISTS timescaledb;
```

</Step>

<Step title={`Check that ${C.TIMESCALE_DB} is installed`}>

```sql
\dx
```

You see the list of installed extensions:

```sql
                                                         List of installed extensions
Name     | Version | Default version |   Schema   |                                      Description                                      
-------------+---------+-----------------+------------+---------------------------------------------------------------------------------------
plpgsql     | 1.0     | 1.0             | pg_catalog | PL/pgSQL procedural language
timescaledb | 2.24.0  | 2.24.0          | public     | Enables scalable inserts and complex queries for time-series data (Community Edition)
(2 rows)
```
Press `\q` to exit the list of extensions.

</Step>

</Steps>
