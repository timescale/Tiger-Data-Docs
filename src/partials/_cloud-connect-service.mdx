import * as C from "@constants";
import { Tabs, TabItem } from "@astrojs/starlight/components";
import { Steps, Step } from "@stainless-api/docs/components";

import NotAvailableFreePlan from "./_not-available-in-free-plan.mdx";

<Steps>

<Step title={`Check your ${C.SERVICE_SHORT} is running correctly`}>

In [{C.CONSOLE}][services-portal], check that your {C.SERVICE_SHORT} is marked as `Running`.

![Check {C.SERVICE_SHORT} is running][check-service_short-is-running]

</Step>

<Step title={`Connect to your ${C.SERVICE_SHORT}`}>

Connect using {C.DATA_MODE} or SQL editor in {C.CONSOLE}, or psql in the command line:

<Tabs>

<TabItem label="Data view in Console">

<NotAvailableFreePlan />

1. In {C.CONSOLE}, click `Data view`.
1. In the connection drop-down in the top right, select your {C.SERVICE_SHORT}.

   ![Select a connection][select-a-connection]

1. Run a test query:

   ```sql
   SELECT CURRENT_DATE;
   ```

   This query gives you the current date, you have successfully connected to your {C.SERVICE_SHORT}.

And that is it, you are up and running. Enjoy developing with {C.COMPANY}.

</TabItem>

<TabItem label="SQL editor in Console">

1. In {C.CONSOLE}, select your {C.SERVICE_SHORT}.
1. Click `SQL editor`.

   ![Check a {C.SERVICE_SHORT} is running][check-a-service_short-is-running]

1. Run a test query:

   ```sql
   SELECT CURRENT_DATE;
   ```

   This query gives you the current date, you have successfully connected to your {C.SERVICE_SHORT}.

And that is it, you are up and running. Enjoy developing with {C.COMPANY}.

</TabItem>

<TabItem label="psql on the command line">

1. Install psql.
1. Run the following command in the terminal using the service URL from the config file you have saved during service creation:

   ```
   psql "<your-service-url>"
   ```

1. Run a test query:

   ```sql
   SELECT CURRENT_DATE;
   ```

   This query returns the current date. You have successfully connected to your {C.SERVICE_SHORT}.

And that is it, you are up and running. Enjoy developing with {C.COMPANY}.

</TabItem>

</Tabs>

</Step>

</Steps>

Quick recap. You:
- Manage your {C.SERVICE_SHORT}s in {C.CONSOLE}: add {C.READ_REPLICA}s and enable 
  high availability, compress data into the {C.COLUMNSTORE}, change parameters, and so on.
- Analyze your data in the [{C.DATA_MODE}][portal-data-mode] in {C.CONSOLE}: write queries with
  autocomplete, save them in folders, share them, create charts/dashboards, and much more.
- Store configuration and security information in your config file.
