<NumberedItem title={`Check your ${C.SERVICE_SHORT} is running correctly`}>

In [{C.CONSOLE}](https://console.cloud.tigerdata.com/dashboard/services), check that your {C.SERVICE_SHORT} is marked as `Running`.

<Image src={imgServicesView} alt="Tiger Console services list showing a running service" />

</NumberedItem>

<NumberedItem title={`Connect to your ${C.SERVICE_SHORT}`}>

Connect using {C.DATA_MODE} or {C.SQL_EDITOR} in {C.CONSOLE}, or psql in the command line:

<Tabs>

<TabItem label={`${C.DATA_MODE} in ${C.CONSOLE_SHORT}`}>


1. In {C.CONSOLE}, toggle `Data view`.
1. In the connection drop-down in the top right, select your {C.SERVICE_SHORT}.

   <ThemeImage light={imgDataModeDropdownLight} dark={imgDataModeDropdownDark} alt="Select a connection in Tiger Cloud data mode" />

1. Run a test query:

   ```sql
   SELECT CURRENT_DATE;
   ```

   This query gives you the current date, you have successfully connected to your {C.SERVICE_SHORT}.

And that is it, you are up and running. Enjoy developing with {C.COMPANY}.

</TabItem>

<TabItem label={`${C.SQL_EDITOR} in ${C.CONSOLE_SHORT}`}>

1. In {C.CONSOLE}, select your {C.SERVICE_SHORT}.
1. Click `SQL Editor` at the bottom.

   <ThemeImage light={imgSqlEditorEmptyLight} dark={imgSqlEditorEmptyDark} alt="SQL editor in Tiger Console Ops mode" />

1. Run a test query:

   ```sql
   SELECT CURRENT_DATE;
   ```

   This query gives you the current date, you have successfully connected to your {C.SERVICE_SHORT}.

And that is it, you are up and running. Enjoy developing with {C.COMPANY}.

</TabItem>

<TabItem label="psql on the command line">

1. Install psql.
1. Run the following command in the terminal using the service URL from the config file you have saved during service creation:

   ```
   psql "<your-service-url>"
   ```

1. Run a test query:

   ```sql
   SELECT CURRENT_DATE;
   ```

   This query returns the current date. You have successfully connected to your {C.SERVICE_SHORT}.

And that is it, you are up and running. Enjoy developing with {C.COMPANY}.

</TabItem>

</Tabs>

</NumberedItem>

</NumberedList>

Quick recap. You:
- Manage your {C.SERVICE_SHORT}s in the {C.OPS_MODE} in {C.CONSOLE}: add {C.READ_REPLICA}s and enable 
  high availability, compress data into the {C.COLUMNSTORE}, change parameters, and so on.
- Analyze your data in the [{C.DATA_MODE}](https://console.cloud.tigerdata.com/dashboard/data-view?popsql) in {C.CONSOLE}: write queries with
  autocomplete, save them in folders, share them, create charts/dashboards, and much more.
- Store configuration and security information in your config file.
