To create a hypertable:

<NumberedList>

<NumberedItem title="Connect to your service">

In {C.CONSOLE}, click `Data view`, then select a {C.SERVICE_SHORT}.

</NumberedItem>

<NumberedItem title={`Create a ${C.PG} table`}>

Copy the following into your query, then click `Run`:

 ```sql
 CREATE TABLE stocks_real_time (
   time TIMESTAMPTZ NOT NULL,
   symbol TEXT NOT NULL,
   price DOUBLE PRECISION NULL,
   day_volume INT NULL
 ) WITH (
    tsdb.hypertable
 );
 ```
