## Inefficient `compress_chunk_time_interval` configuration

When you configure `compress_chunk_time_interval` but do not set the primary dimension as the first column in `orderby`, {C.TIMESCALE_DB} converts chunks back to the {C.ROWSTORE} before merging. This makes merging less efficient. Set the primary dimension of the chunk as the first column in `orderby` to improve efficiency.
