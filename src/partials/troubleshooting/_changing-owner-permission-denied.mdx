## Permission denied when changing ownership of tables and {C.HYPERTABLE}s

**Message:**

```
ERROR: permission denied for schema _timescaledb_internal
```

You might see this error when using the `ALTER TABLE` command to change the
ownership of tables or {C.HYPERTABLE}s.

This use of `ALTER TABLE` is blocked because the `tsdbadmin` user is not a
superuser.

To change table ownership, use the [`REASSIGN`](https://www.postgresql.org/docs/current/sql-reassign-owned.html) command instead:

```sql
REASSIGN OWNED BY <current_role> TO <desired_role>;
```
