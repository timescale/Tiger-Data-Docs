## Error loading the {C.TIMESCALE_DB} extension on Windows

If you see a message saying that {C.PG} cannot load the {C.TIMESCALE_DB} library `timescaledb-<version>.dll`:

```sql
ERROR: could not load library "C:/Program Files/PostgreSQL/16/lib/timescaledb-2.14.2.dll": The specified module could not be found.
```

Start a new psql session to your {C.SELF_SHORT} instance and create the `timescaledb` extension as the first command:

```bash
psql -X -d "postgres://<user>:<password>@<source_host>:<source_port>/<db_name>" -c "CREATE EXTENSION IF NOT EXISTS timescaledb;"
```
