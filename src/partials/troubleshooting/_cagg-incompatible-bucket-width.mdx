## Hierarchical {C.CAGG} fails with incompatible bucket width

```sql
ERROR:  cannot create continuous aggregate with incompatible bucket width
DETAIL:  Time bucket width of "<BUCKET>" [1 year] should be multiple of the time bucket width of "<BUCKET>" [1 day].
```

If you attempt to create a hierarchical {C.CAGG}, you must use
compatible {C.TIME_BUCKET}s. You can't create a {C.CAGG} with a
fixed-width {C.TIME_BUCKET} on top of a {C.CAGG} with a variable-width
{C.TIME_BUCKET}. For more information, see the restrictions section in
[hierarchical {C.CAGG}s](/build/continuous-aggregates/hierarchical-continuous-aggregates#restrictions).
