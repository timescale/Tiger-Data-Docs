## Out of memory errors after enabling the columnstore

```
Error out of memory
DETAIL: Failed on request of size 16777216 in memory context "ErrorContext".
```

By default, {C.COLUMNSTORE} policies move all uncompressed chunks to the {C.COLUMNSTORE}.
However, before converting a large backlog of chunks from the {C.ROWSTORE} to the {C.COLUMNSTORE},
best practice is to set `maxchunks_to_compress` and limit the amount of chunks to be converted. For example:

```sql
SELECT alter_job(job_id, config.maxchunks_to_compress => 10);
```

When all chunks have been converted to the {C.COLUMNSTORE}, set `maxchunks_to_compress` to `0`, unlimited.
