## User permissions do not allow {C.CHUNK}s to be converted to {C.COLUMNSTORE} or {C.ROWSTORE}

**Message:**

```
ERROR: must be owner of hypertable "HYPERTABLE_NAME"
```

You might get this error if you attempt to compress a {C.CHUNK} into the {C.COLUMNSTORE}, or decompress it back
into {C.ROWSTORE} with a non-privileged user account. To compress or decompress a {C.CHUNK}, your user account
must have permissions that allow it to perform `CREATE INDEX` on the {C.CHUNK}. You can check the permissions
of the current user with this command at the `psql` command prompt:

```sql
\dn+ <USERNAME>
```

To resolve this problem, grant your user account the appropriate privileges with
this command:

```sql
GRANT PRIVILEGES
    ON TABLE <TABLE_NAME>
    TO <ROLE_TYPE>;
```

For more information about the `GRANT` command, see the
[{C.PG} documentation](https://www.postgresql.org/docs/current/sql-grant.html).
