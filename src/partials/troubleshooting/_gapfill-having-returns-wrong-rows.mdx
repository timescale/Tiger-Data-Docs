## Filtering a `time_bucket_gapfill()` query returns no rows or wrong counts

`HAVING` and subqueries are applied before gapfilling runs, so they filter the aggregation
results rather than the gapfilled rows. To filter the gapfilled rows, wrap the gapfill query in
a common table expression and filter its results. See
[`time_bucket_gapfill()`](/reference/timescaledb/hyperfunctions/time_bucket_gapfill/time_bucket_gapfill).
