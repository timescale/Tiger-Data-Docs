## Scheduled jobs stop running

Your scheduled jobs might stop running for various reasons. On {C.SELF_SHORT}
{C.TIMESCALE_DB}, you can fix this by restarting background workers:

<Tabs>
<TabItem label={`${C.TIMESCALE_DB} >= 2.12`}>
```sql
SELECT _timescaledb_functions.start_background_workers();
```
</TabItem>
<TabItem label={`${C.TIMESCALE_DB} < 2.12`}>
```sql
SELECT _timescaledb_internal.start_background_workers();
```
</TabItem>
</Tabs>

On {C.CLOUD_LONG} and {C.MST_LONG}, restart background workers by doing one of the following:

- Run `SELECT timescaledb_pre_restore()`, followed by `SELECT
    timescaledb_post_restore()`.
- Power the service off and on again. This might cause a downtime of a few
    minutes while the service restores from backup and replays the write-ahead
    log.
