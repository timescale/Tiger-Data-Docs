## Queries fail when defining {C.CAGG}s but work on regular tables

{C.CAGG_CAP}s do not work on all queries. For example, {C.TIMESCALE_DB} does not support window functions on
{C.CAGG}s. If you use an unsupported function, you see the following error:

```sql
ERROR:  invalid continuous aggregate view
SQL state: 0A000
```
