## Log error: could not access file "timescaledb"

If your {C.PG} logs have this error preventing it from starting up, you
should double-check that the {C.TIMESCALE_DB} files have been installed to the
correct location. The installation methods use `pg_config` to get {C.PG}'s
location. However, if you have multiple versions of {C.PG} installed on the
same machine, the location `pg_config` points to may not be for the version you
expect. To check which version of {C.TIMESCALE_DB} is used:

```bash
$ pg_config --version
PostgreSQL 12.3
```

If that is the correct version, double-check that the installation path is
the one you'd expect. For example, for {C.PG} 11.0 installed via
Homebrew on macOS it should be `/usr/local/Cellar/postgresql/11.0/bin`:

```bash
$ pg_config --bindir
/usr/local/Cellar/postgresql/11.0/bin
```

If either of those steps is not the version you are expecting, you need to
either uninstall the incorrect version of {C.PG} if you can, or update your
`PATH` environmental variable to have the correct path of `pg_config` listed
first, that is, by prepending the full path:

```bash
export PATH = /usr/local/Cellar/postgresql/11.0/bin:$PATH
```

Then, reinstall {C.TIMESCALE_DB} and it should find the correct installation
path.
