- Install the {C.PG} client tools on your migration machine. This includes `psql`, and `pg_dump`.
- Read [the release notes][relnotes] for the version of {C.TIMESCALE_DB} that you are upgrading to.
- [Perform a backup][backup] of your database. While {C.TIMESCALE_DB}
    upgrades are performed in-place, upgrading is an intrusive operation. Always
    make sure you have a backup on hand, and that the backup is readable in the
    case of disaster.

[backup]: /self-hosted/backup-and-restore/
[relnotes]: https://github.com/timescale/timescaledb/releases
