## Install psql on Windows

The `psql` tool is installed by default on Windows systems when you install
{C.PG}, and this is the most effective way to install the tool. These
instructions use the interactive installer provided by {C.PG} and
EnterpriseDB.

### Installing psql on Windows

<NumberedList>

<NumberedItem title={`Download and run the ${C.PG} installer from`}>

[www.enterprisedb.com][windows-installer].

</NumberedItem>

<NumberedItem title="In the `Select Components` dialog, check `Command Line Tools`, along with">

any other components you want to install, and click `Next`.

</NumberedItem>

<NumberedItem title="Complete the installation wizard to install the package."></NumberedItem>

</NumberedList>

[windows-installer]: https://www.postgresql.org/download/windows/
