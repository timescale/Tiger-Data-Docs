import * as C from "@constants";

## Compare {C.TDB_COMMUNITY} and {C.CLOUD_LONG}

{C.TDB_COMMUNITY} is the open-source {C.TIMESCALE_DB} engine you install and run yourself. {C.CLOUD_LONG}
hosts that engine as a service and adds the [managed platform capabilities](#managed-platform-and-operations). For a full
matrix including AWS, Azure, and self-hosted deployment details, see the
[feature comparison](/get-started/feature-comparison).

### Core engine capabilities

Both offerings include the same {C.TIMESCALE_DB} database features.

| Capability | {C.TDB_COMMUNITY} | {C.CLOUD_LONG} |
| ---------- | :---------------: | :------------: |
| {C.HYPERTABLE_CAP}s | ✓ | ✓ |
| {C.HYPERCORE_CAP} ({C.ROWSTORE}/{C.COLUMNSTORE}) | ✓ | ✓ |
| {C.CAGG_CAP}s | ✓ | ✓ |
| Full {C.PG} compatibility | ✓ | ✓ |
| Data retention policies | ✓ | ✓ |
| {C.HYPERFUNC_CAP} | ✓ | ✓ |

### Managed platform and operations

| Capability | {C.TDB_COMMUNITY} | {C.CLOUD_LONG} |
| ---------- | :---------------: | :------------: |
| Tiered storage (high-performance and object tiers) | ✗ | ✓ |
| {C.ICEBERG_CONNECTOR_SHORT} (sync to Iceberg tables in your data lake) | ✗ | ✓ |
| Managed source connectors (S3, Kafka, {C.PG}) | Manual | ✓ |
| Performance insights | ✗ | ✓ |
| Automatic {C.HA_REPLICA}s and managed {C.READ_REPLICA}s | Manual | ✓ |
| Metrics, dashboards, and alerting  | ✗ | ✓ |
| Platform-managed backups, upgrades, and patching | Manual | ✓ |
| SOC 2 Type II (service organization controls) | ✗ | ✓ |
| {C.CLI_LONG} and {C.MCP_LONG} | ✗ | ✓ |

**Legend:**
- `✓` included,
- `✗` not available,
- `Manual` you can approximate with self-hosted tooling and your own operations.
