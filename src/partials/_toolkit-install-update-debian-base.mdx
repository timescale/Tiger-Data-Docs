## Install {C.TOOLKIT_LONG}

These instructions use the `apt` package manager.

<NumberedList>

<NumberedItem title="Update your local repository list">

```bash
sudo apt update
```

</NumberedItem>

<NumberedItem title="Install TimescaleDB Toolkit">

```bash
sudo apt install timescaledb-toolkit-postgresql-18
```

</NumberedItem>

<NumberedItem title={`Connect to the database where you want to use ${C.TOOLKIT_SHORT}`}>

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

</NumberedItem>

<NumberedItem title={`Create the ${C.TOOLKIT_SHORT} extension in the database`}>

```sql
CREATE EXTENSION timescaledb_toolkit;
```

</NumberedItem>

</NumberedList>

## Update {C.TOOLKIT_LONG}

Update {C.TOOLKIT_SHORT} by installing the latest version and running `ALTER EXTENSION`.

<NumberedList>

<NumberedItem title="Update your local repository list">

```bash
apt update
```

</NumberedItem>

<NumberedItem title={`Install the latest version of ${C.TOOLKIT_LONG}`}>

```bash
apt install timescaledb-toolkit-postgresql-18
```

</NumberedItem>

<NumberedItem title={`Connect to the database where you want to use ${C.TOOLKIT_SHORT}`}>

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

</NumberedItem>

<NumberedItem title={`Update the ${C.TOOLKIT_SHORT} extension in the database`}>

```sql
ALTER EXTENSION timescaledb_toolkit UPDATE;
```

<Callout variant="note">

For some {C.TOOLKIT_SHORT} versions, you might need to disconnect and reconnect active
sessions.

</Callout>

</NumberedItem>

</NumberedList>
