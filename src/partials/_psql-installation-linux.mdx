### Install psql on Linux

You can use the `apt` on Debian-based systems, `yum` on Red Hat-based systems,
and `pacman` package manager to install the `psql` tool.

<Tabs>

<TabItem label="Debian">

### Installing psql using the apt package manager

<NumberedList>

<NumberedItem title="Make sure your `apt` repository is up to date:">

```bash
apt-get update
```

</NumberedItem>

<NumberedItem title="Install the `postgresql-client` package:">

```bash
apt-get install postgresql-client
```

</NumberedItem>

</NumberedList>

</TabItem>

<TabItem label="Red Hat">

### Installing psql using the yum package manager

<NumberedList>

<NumberedItem title="Make sure your `yum` repository is up to date:">

```bash
yum update
```

</NumberedItem>

<NumberedItem title="Install the `postgresql-client` package:">

```bash
dnf install postgresql14
```

</NumberedItem>

</NumberedList>

</TabItem>

<TabItem label="ArchLinux">

### Installing psql using the pacman package manager

<NumberedList>

<NumberedItem title="Make sure your `pacman` repository is up to date:">

```bash
pacman -Syu
```

</NumberedItem>

<NumberedItem title="Install the `postgresql-client` package:">

```bash
pacman -S postgresql-libs
```

</NumberedItem>

</NumberedList>

</TabItem>

</Tabs>
