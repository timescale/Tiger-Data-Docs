## Policies

### `timescaledb.max_background_workers (int)`

Max background worker processes allocated to {C.TIMESCALE_DB}. Set to at least 1 +
the number of databases loaded with the {C.TIMESCALE_DB} extension in a {C.PG} instance. Default value is 16.

## {C.SERVICE_LONG} tuning

### `timescaledb.disable_load (bool)`
Disable the loading of the actual extension
