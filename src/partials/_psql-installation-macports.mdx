#### Installing psql using MacPorts

<Steps>

<Step title="Install the latest version of `libpqxx`:">

```bash
sudo port install libpqxx 
```

</Step>

<Step title="(Optional) View the files that were installed by `libpqxx`:">

```bash
port contents libpqxx
```

</Step>

</Steps>
