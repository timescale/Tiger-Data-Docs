#### Installing psql using MacPorts

<NumberedList>

<NumberedItem title="Install the latest version of `libpqxx`:">

```bash
sudo port install libpqxx 
```

</NumberedItem>

<NumberedItem title="(Optional) View the files that were installed by `libpqxx`:">

```bash
port contents libpqxx
```

</NumberedItem>

</NumberedList>
