<NumberedItem title={`Add the ${C.TIMESCALE_DB} repository`}>

<Tabs>

<TabItem label="Red Hat">

```bash
sudo tee /etc/yum.repos.d/timescale_timescaledb.repo <<EOL
[timescale_timescaledb]
name=timescale_timescaledb
baseurl=https://packagecloud.io/timescale/timescaledb/el/\$releasever/\$basearch
repo_gpgcheck=1
gpgcheck=0
enabled=1
gpgkey=https://packagecloud.io/timescale/timescaledb/gpgkey
sslverify=1
sslcacert=/etc/pki/tls/certs/ca-bundle.crt
metadata_expire=300
EOL
```

</TabItem>

<TabItem label="Fedora">

```bash
sudo tee /etc/yum.repos.d/timescale_timescaledb.repo <<EOL
[timescale_timescaledb]
name=timescale_timescaledb
baseurl=https://packagecloud.io/timescale/timescaledb/el/9/\$basearch
repo_gpgcheck=1
gpgcheck=0
enabled=1
gpgkey=https://packagecloud.io/timescale/timescaledb/gpgkey
sslverify=1
sslcacert=/etc/pki/tls/certs/ca-bundle.crt
metadata_expire=300
EOL
```

</TabItem>
</Tabs>

</NumberedItem>

<NumberedItem title="Update your local repository list">

```bash
sudo yum update
```

</NumberedItem>

<NumberedItem title="Install TimescaleDB">

To avoid errors, **do not** install {C.TDB_APACHE} and {C.TDB_COMMUNITY} at the same time.

```bash
sudo yum install timescaledb-2-postgresql-18 postgresql18
```

<NumberedItem title={`Tune your ${C.PG} instance for TimescaleDB`}>

```bash
sudo timescaledb-tune --pg-config=/usr/pgsql-18/bin/pg_config 
```   

This script is included with the `timescaledb-tools` package when you install TimescaleDB.
For more information, see [configuration](/self-hosted/configuration/).

</NumberedItem>

<NumberedItem title={`Enable and start ${C.PG}`}>

```bash
sudo systemctl enable postgresql-18
sudo systemctl start postgresql-18
```

</NumberedItem>

<NumberedItem title={`Log in to ${C.PG} as \`postgres\``}>

```bash
sudo -u postgres psql
```
You are now in the psql shell.

</NumberedItem>

<NumberedItem title="Set the password for `postgres`">

```bash
 \password postgres
 ```

 When you have set the password, type `\q` to exit psql.

</NumberedItem>
