You need admin rights to to update the configuration on your source database. If you are using
a managed service, follow the instructions in the `From MST` tab on this page.

<NumberedList>
<NumberedItem title={`Install the \`wal2json\` extension on your source database`}>
[Install wal2json](https://github.com/eulerto/wal2json) on your source database.
</NumberedItem>

<NumberedItem title={`Prevent ${C.PG} from treating the data in a snapshot as outdated`}>

```shell
psql -X -d $SOURCE -c 'alter system set old_snapshot_threshold=-1'
```

This is not applicable if the source database is {C.PG} 17 or later.
</NumberedItem>

<NumberedItem title="Set the Write-Ahead Log (WAL) to record the information needed for logical decoding">

```shell
psql -X -d $SOURCE -c 'alter system set wal_level=logical'
```
</NumberedItem>

<NumberedItem title="Restart the source database">
Your configuration changes are now active. However, verify that the
settings are live in your database.
</NumberedItem>

<NumberedItem title={`Enable live-migration to replicate \`DELETE\` and \`UPDATE\` operations`}>
<EnableReplication />
</NumberedItem>
</NumberedList>
