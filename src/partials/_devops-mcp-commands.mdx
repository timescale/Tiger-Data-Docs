import * as C from "@constants";


{C.MCP_LONG} exposes the following MCP tools to your AI Assistant:

| Command                  | Parameter           | Required | Description                                                                                                                                                                                                                                                                                                     |
|--------------------------|---------------------|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `service_list`           | -                   | -        | Returns a list of the {C.SERVICE_SHORT}s in the current {C.PROJECT_SHORT}.                                                                                                                                                                                                                                            |
| `service_get`            | -                   | -        | Returns detailed information about a {C.SERVICE_SHORT}.                                                                                                                                                                                                                                                            |
|                          | `service_id`        | ✓        | The unique identifier of the {C.SERVICE_SHORT} (10-character alphanumeric string).                                                                                                                                                                                                                                 |
|                          | `with_password`     | -        | Set to `true` to include the password in the response and connection string. <br/> **WARNING**: never do this unless the user explicitly requests the password.                                                                                                                                                 |
| `service_create`         | -                   | -        | Create a new {C.SERVICE_SHORT} in {C.CLOUD_LONG}. <br/> **WARNING**: creates billable resources.                                                                                                                                                                                                                      |
|                          | `name`              | -        | Set the human-readable name of up to 128 characters for this {C.SERVICE_SHORT}.                                                                                                                                                                                                                                    |
|                          | `addons`            | -        | Set the array of [addons][create-service] to enable for the {C.SERVICE_SHORT}. Options: <ul><li>`time-series`: enables {C.TIMESCALE_DB}</li><li>`ai`: enables the AI and vector extensions</li></ul> Set an empty array for {C.PG}-only.                                                                                 |
|                          | `region`            | -        | Set the [AWS region][cloud-regions] to deploy this {C.SERVICE_SHORT} in.                                                                                                                                                                                                                                           |
|                          | `cpu_memory`        | -        | CPU and memory allocation combination. <br /> Available configurations are: <ul><li>shared/shared</li><li>0.5 CPU/2 GB</li><li>1 CPU/4 GB</li><li>2 CPU/8 GB</li><li>4 CPU/16 GB</li><li>8 CPU/32 GB</li><li>16 CPU/64 GB</li><li>32 CPU/128 GB</li></ul>                                                       |
|                          | `replicas`          | -        | Set the number of [high-availability replicas][readreplica] for fault tolerance.                                                                                                                                                                                                                                |
|                          | `wait`              | -        | Set to `true` to wait for the {C.SERVICE_SHORT} to be fully ready before returning.                                                                                                                                                                                                                                  |
|                          | `timeout_minutes`   | -        | Set the timeout in minutes to wait for {C.SERVICE_SHORT} to be ready. Only used when `wait=true`. Default: 30 minutes                                                                                                                                                                                              |
|                          | `set_default`       | -        | By default, the new {C.SERVICE_SHORT} is the default for following commands in {C.CLI_SHORT}. Set to `false` to keep the previous {C.SERVICE_SHORT} as the default.                                                                                                                                                      |
|                          | `with_password`     | -        | Set to `true` to include the password for this {C.SERVICE_SHORT} in response and connection string. <br/> **WARNING**: never set to `true` unless user explicitly requests the password.                                                                                                                           |
| `service_fork`           | -                   | -        | Fork an existing {C.SERVICE_SHORT} to create a new independent copy. <br/> **WARNING**: creates billable resources.                                                                                                                                                                                                |
|                          | `service_id`        | ✓        | The unique identifier of the {C.SERVICE_SHORT} to fork (10-character alphanumeric string).                                                                                                                                                                                                                         |
|                          | `fork_strategy`     | ✓        | Fork strategy: <ul><li>`NOW`: fork at the current database state</li><li>`LAST_SNAPSHOT`:fork at last existing snapshot. This is the faster option</li><li>`PITR`: create a point-in-time recovery. You must also set the `target_time` parameter for PITR forks.  </li></ul>                                   |
|                          | `target_time`       | -        | Set the target time for a `PIRT` `fork_strategy` in RFC3339 format. For example `2025-01-15T10:30:00Z`).                                                                                                                                                                                                        |
|                          | `name`              | -        | Set the human-readable name for the forked {C.SERVICE_SHORT}. Defaults to `{source-service-name}-fork`.                                                                                                                                                                                                            |
|                          | `cpu_memory`        | -        | CPU and memory allocation combination. Inherits from source {C.SERVICE_SHORT} if not specified. <br /> Available configurations are: <ul><li>shared/shared</li><li>0.5 CPU/2 GB</li><li>1 CPU/4 GB</li><li>2 CPU/8 GB</li><li>4 CPU/16 GB</li><li>8 CPU/32 GB</li><li>16 CPU/64 GB</li><li>32 CPU/128 GB</li></ul> |
|                          | `wait`              | -        | Set to `true` to wait for the forked {C.SERVICE_SHORT} to be fully ready before returning. Default: `false`.                                                                                                                                                                                                       |
|                          | `timeout_minutes`   | -        | Set the timeout in minutes to wait for forked {C.SERVICE_SHORT} to be ready. Only used when `wait=true`. Default: 30 minutes                                                                                                                                                                                       |
|                          | `set_default`       | -        | By default, the forked {C.SERVICE_SHORT} is set as the default for following commands in {C.CLI_SHORT}. Set to `false` to keep the previous {C.SERVICE_SHORT} as the default.                                                                                                                                            |
|                          | `with_password`     | -        | Set to `true` to include the password for the forked {C.SERVICE_SHORT} in response and connection string. <br/> **WARNING**: never set to `true` unless user explicitly requests the password.                                                                                                                     |
| `service_update_password` | -                   | -        | Update the password for the `tsdbadmin` for this {C.SERVICE_SHORT}. The password change takes effect immediately and may terminate existing connections.                                                                                                                                                           |
|                          | `service_id` | ✓        | The unique identifier of the {C.SERVICE_SHORT} you want to update the password for.                                                                                                                                                                                                                                |
|                          | `password`          | ✓        | The new password for the `tsdbadmin` user.                                                                                                                                                                                                                                                                      |
| `service_start`          | -                   | -        | Start a stopped {C.SERVICE_SHORT}. The {C.SERVICE_SHORT} transitions from an inactive state to active and becomes available for connections.                                                                                                                                                                          |
|                          | `service_id` | ✓        | The unique identifier of the {C.SERVICE_SHORT} to start (10-character alphanumeric string).                                                                                                                                                                                                                        |
|                          | `wait`              | -        | Set to `true` to wait for the {C.SERVICE_SHORT} to be fully started before returning. Default: `true`.                                                                                                                                                                                                             |
|                          | `timeout_minutes`   | -        | Set the timeout in minutes to wait for {C.SERVICE_SHORT} to start. Only used when `wait=true`. Default: 10 minutes                                                                                                                                                                                                 |
| `service_stop`           | -                   | -        | Stop a running {C.SERVICE_SHORT}. The {C.SERVICE_SHORT} transitions to an inactive state and no longer accepts connections.                                                                                                                                                                                           |
|                          | `service_id` | ✓        | The unique identifier of the {C.SERVICE_SHORT} to stop (10-character alphanumeric string).                                                                                                                                                                                                                         |
|                          | `wait`              | -        | Set to `true` to wait for the {C.SERVICE_SHORT} to be fully stopped before returning. Default: `true`.                                                                                                                                                                                                             |
|                          | `timeout_minutes`   | -        | Set the timeout in minutes to wait for {C.SERVICE_SHORT} to stop. Only used when `wait=true`. Default: 10 minutes                                                                                                                                                                                                  |
| `service_resize`         | -                   | -        | Resize a {C.SERVICE_SHORT} by changing CPU and memory allocation. The {C.SERVICE_SHORT} may be temporarily unavailable during the resize operation. <br/> **WARNING**: changing resources affects billing.                                                                                                             |
|                          | `service_id` | ✓        | The unique identifier of the {C.SERVICE_SHORT} to resize (10-character alphanumeric string).                                                                                                                                                                                                                       |
|                          | `cpu_memory`        | ✓        | CPU and memory allocation combination. <br /> Available configurations are: <ul><li>0.5 CPU/2 GB</li><li>1 CPU/4 GB</li><li>2 CPU/8 GB</li><li>4 CPU/16 GB</li><li>8 CPU/32 GB</li><li>16 CPU/64 GB</li><li>32 CPU/128 GB</li></ul>                                                                             |
|                          | `wait`              | -        | Set to `true` to wait for the resize operation to complete before returning. Default: `true`.                                                                                                                                                                                                                   |
|                          | `timeout_minutes`   | -        | Set the timeout in minutes to wait for resize to complete. Only used when `wait=true`. Default: 10 minutes                                                                                                                                                                                                      |
| `service_logs`           | -                   | -        | View logs for a {C.SERVICE_SHORT}. Returns up to the specified number of log entries with optional time filtering.                                                                                                                                                                                                 |
|                          | `service_id` | ✓        | The unique identifier of the {C.SERVICE_SHORT} to fetch logs from (10-character alphanumeric string).                                                                                                                                                                                                              |
|                          | `tail`              | -        | Number of log lines to show. Default: `100`. Maximum: `500`.                                                                                                                                                                                                                                                    |
|                          | `until`             | -        | Fetch logs before this timestamp in RFC3339 format (for example, `2024-01-15T10:00:00Z`).                                                                                                                                                                                                                       |
|                          | `node`              | -        | Specific {C.SERVICE_SHORT} node to fetch logs from. Use `0` for primary node, higher numbers for HA replicas.                                                                                                                                                                                                      |
| `db_execute_query`                       | -                   | -        | Execute a single SQL query against a {C.SERVICE_SHORT}. This command returns column metadata, result rows, affected row count, and execution time. Multi-statement queries are not supported.  <br/> **WARNING**: can execute destructive SQL including INSERT, UPDATE, DELETE, and DDL commands.                  |
|                          | `service_id` | ✓        | The unique identifier of the {C.SERVICE_SHORT}. Use `tiger_service_list` to find {C.SERVICE_SHORT} IDs.                                                                                                                                                                                                               |
|                          | `query`             | ✓        | The SQL query to execute. Single statement queries are supported.                                                                                                                                                                                                                                               |
|                          | `parameters`        | -        | Query parameters for parameterized queries. Values are substituted for the `$n` placeholders in the query.                                                                                                                                                                                                      |
|                          | `timeout_seconds`   | -        | The query timeout in seconds. Default: `30`.                                                                                                                                                                                                                                                                    |
|                          | `role`              | -        | The {C.SERVICE_SHORT} role/username to connect as. Default: `tsdbadmin`.                                                                                                                                                                                                                                           |
|                          | `pooled`            | -        | Use [connection pooling][Connection pooling]. This is only available if you have already enabled it for the {C.SERVICE_SHORT}. Default: `false`.                                                                                                                                                                   |
