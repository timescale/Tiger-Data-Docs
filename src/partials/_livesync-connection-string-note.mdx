<Callout variant="note">
When using the `postgres://user:pass@host:port/db` URI format, URL-encode special characters in the password (for example `@` → `%40`, `:` → `%3A`, `/` → `%2F`, `#` → `%23`) to avoid URL-parsing errors. Alternatively, use the `keyword=value` parameter format instead of a URI; see the [libpq connection strings reference](https://www.postgresql.org/docs/current/libpq-connect.html#LIBPQ-CONNSTRING) (URI vs. parameter keywords).
</Callout>
