import * as C from "@constants";


| Key                       | Default           | Description                                                                 |
|---------------------------|-------------------|-----------------------------------------------------------------------------|
| `analytics`               | `true`            | Enable or disable usage analytics                                   |
| `api_url`                 | `https://console.cloud.tigerdata.com/public/api/v1` | Base URL of the {C.REST_LONG} that {C.CLI_LONG} calls. An endpoint override; you don't normally change it |
| `color`                   | `true`            | Enable or disable colored output                                    |
| `console_url`             | `https://console.cloud.tigerdata.com` | Base URL of {C.CONSOLE_LONG}, used to build the OAuth sign-in URL. An endpoint override; you don't normally change it |
| `docs_mcp`                | `true`            | Enable or disable the {C.COMPANY} documentation MCP proxy                      |
| `docs_mcp_url`            | `https://mcp.tigerdata.com/docs` | Endpoint of the {C.COMPANY} documentation {C.MCP_SHORT} server that {C.MCP_LONG} proxies to when `docs_mcp` is `true`. An endpoint override; you don't normally change it |
| `gateway_url`             | `https://console.cloud.tigerdata.com/api` | Base URL of the token endpoint used by OAuth authentication. An endpoint override; you don't normally change it |
| `mcp_max_rows`            | `100`             | Set the maximum number of rows returned by the `db_execute_query` {C.MCP_SHORT} tool          |
| `output`                  | `table`           | Set the output format to `json`, `yaml`, or `table`                         |
| `password_storage`        | `keyring`         | Set the password storage method. Options are `keyring`, `pgpass`, or `none` |
| `read_only`               | `false`           | Enable or disable read-only mode. When `true`, mutating CLI commands and {C.MCP_SHORT} tools (`service create`, `fork`, `start`, `stop`, `resize`, `update-password`, and `delete`) are refused, and the database sessions opened by `db connect`, `db connection-string`, and `db_execute_query` run in {C.CLOUD_LONG}'s immutable read-only mode, so writes and DDL are rejected by the server. Read commands and tools are unaffected |
| `releases_url`            | `https://cli.tigerdata.com` | Base URL that `tiger upgrade` and the update check fetch releases from. An endpoint override; you don't normally change it |
| `service_id`              | -                 | Set the default {C.SERVICE_SHORT} to manage                                             |
| `version_check`           | `true`            | Enable or disable checking for a new version of {C.CLI_LONG} on startup                       |

`config_dir` also appears in `tiger config show`, but it is read-only there: set it with the `--config-dir` flag or the `TIGER_CONFIG_DIR` environment variable, not with `tiger config set`.

You can also set these configuration options as environment variables. Environment variables:
* Take precedence over configuration parameters values.  
* Are in upper case and use the `TIGER_` prefix. For example, `TIGER_ANALYTICS`
