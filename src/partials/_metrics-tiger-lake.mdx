These metrics show the state of the {C.ICEBERG_CONNECTOR_LONG}, including how far behind the source it is, how much data it has written, and the progress of the snapshots. Every metric carries the `project_id`, `region`, `service_id`, and `connector` labels. The `connector` label is always `tigerlake`.

|Metric|Description|
|-|-|
|`tigerlake_cdc_metrics_total_number_of_events_seen`|Events read from the replication stream since the connector started.|
|`tigerlake_cdc_metrics_milliseconds_since_last_event`|Milliseconds since the last event was read. A growing value can indicate lag.|
|`tigerlake_cdc_metrics_milliseconds_behind_source`|Age of the last event read from the replication stream, in milliseconds.|
|`tigerlake_cdc_metrics_pending_equality_deletes`|Updates and deletes buffered for the next commit to Iceberg.|
|`tigerlake_cdc_metrics_streaming_queue_current_size`|Events currently queued for processing.|
|`tigerlake_cdc_metrics_last_committed_tx_time_millis`|Transaction time of the last batch committed to Iceberg, in Unix epoch milliseconds.|
|`tigerlake_cdc_metrics_bytes_read_total`|Bytes read from your service by replication and gapfill since the connector started.|
|`tigerlake_cdc_metrics_bytes_ingested_total`|Bytes of replicated and gapfilled rows handed to the Iceberg writer since the connector started.|
|`tigerlake_connector_config_error`|Returns 1 for a configuration error, such as missing IAM permissions, that prevents the connector from initializing the Iceberg catalog, otherwise 0.|
|`tigerlake_gapfill_metrics_gapfill_running_ms`|Milliseconds the current gapfill replay has been running, or 0 when idle.|
|`tigerlake_iceberg_metrics_total_records_written`|Records written to Iceberg across synced tables. This is a gauge and can drop after compaction.|
|`tigerlake_snapshot_metrics_snapshot_in_progress`|1 while any initial copy is running, otherwise 0.|
|`tigerlake_snapshot_metrics_number_of_snapshot_in_progress`|Initial copies currently running.|
|`tigerlake_snapshot_metrics_number_of_snapshots`|Initial copies completed successfully since the connector started.|
|`tigerlake_snapshot_metrics_number_failed_snapshots`|Initial copies that failed since the connector started.|
|`tigerlake_snapshot_metrics_number_of_rows`|Rows read by initial copies since the connector started.|
|`tigerlake_snapshot_metrics_bytes_total`|Bytes of source rows read by initial copies since the connector started.|
