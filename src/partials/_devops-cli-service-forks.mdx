<NumberedItem title={`Fork the ${C.SERVICE_SHORT}`}>

```shell
 tiger service fork tgrservice --now --no-wait --name bob
```
You must specify exactly one timing option: `--now` (fork at current state), `--last-snapshot` (fork at last snapshot, faster), or `--to-timestamp` (fork at specific point in time). By default a fork matches the resources of the parent {C.SERVICE_LONG}. For paid plans, specify `--cpu` and/or `--memory` for dedicated resources.
