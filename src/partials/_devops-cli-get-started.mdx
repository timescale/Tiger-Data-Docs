## Create your first {C.SERVICE_LONG}

Create a new {C.SERVICE_LONG} using {C.CLI_LONG}:

<Steps>

<Step title={`Submit a ${C.SERVICE_SHORT} creation request`}>

By default, {C.CLI_LONG} creates a {C.SERVICE_SHORT} for you that matches your [{C.PRICING_PLAN}][pricing-plans]:
* **{C.FREE}**: shared CPU/memory and the `time-series` and `ai` capabilities (only available in `us-east-1` region)
* **Paid {C.PRICING_PLAN}**: 0.5 CPU and 2 GB memory with the `time-series` capability
```shell
tiger service create
```
To control the {C.SERVICE_SHORT} configuration, use the [`service create` flags][cli-create-custom-service]. For
example, to create a free service if you are in a paid {C.PRICING_PLAN}, call
`tiger service create --memory shared --cpu shared`.

<Callout variant="note">
Free services with shared CPU/memory are only available in the `us-east-1` region. Paid services can be created in any available AWS or Azure region using the `--region` flag.
</Callout>
