## Install {C.TOOLKIT_LONG}

The {C.TOOLKIT_SHORT} extension is pre-installed and pre-enabled when you
[Install {C.TIMESCALE_DB} on Kubernetes](/get-started/choose-your-path/install-timescaledb). Once you start the container, the extension is already 
active in your database and ready to use. No additional installation steps are required.

## Update {C.TOOLKIT_LONG}

To get the latest version of {C.TOOLKIT_SHORT}, update the {C.TIMESCALE_DB} HA Docker image used by your Kubernetes StatefulSet:

<NumberedList>

<NumberedItem title="Update the StatefulSet to use the latest image">

Replace `<new-version>` with the desired version tag. For example, `pg18`. You find the available tags on 
the [{C.TIMESCALE_DB} HA Docker Hub page](https://hub.docker.com/r/timescale/timescaledb-ha/tags).

```shell
kubectl set image statefulset/timescaledb timescaledb=timescale/timescaledb-ha:<new-version> -n tigerdata
```

Kubernetes performs a rolling update, replacing the pod with the new image version.

</NumberedItem>

<NumberedItem title="Verify the new image is running">

```shell
kubectl get statefulset timescaledb -n tigerdata -o jsonpath='{.spec.template.spec.containers[0].image}'
```

</NumberedItem>

<NumberedItem title={`Connect to your ${C.TIMESCALE_DB} pod and verify the extension versions`}>

```shell
kubectl exec -it test-pod -- bash -c "psql -h \$PGHOST -U \$PGUSER -d \$PGDATABASE"
\dx
```

</NumberedItem>

</NumberedList>
