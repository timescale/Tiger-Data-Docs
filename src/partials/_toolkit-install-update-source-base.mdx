## Install {C.TOOLKIT_LONG}

To install {C.TOOLKIT_SHORT} from source:

<NumberedList>

<NumberedItem title="Build the extension from the latest source code">

Follow the build instructions in the [TimescaleDB Toolkit GitHub repository][toolkit-gh-install] to download and
build the latest version.

</NumberedItem>

<NumberedItem title="Connect to your database">

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

</NumberedItem>

<NumberedItem title="Update the Toolkit extension in the database">

```bash
CREATE EXTENSION timescaledb_toolkit;
```

</NumberedItem>

</NumberedList>

## Update {C.TOOLKIT_LONG}

To update {C.TOOLKIT_SHORT} installed from source:

<NumberedList>

<NumberedItem title="Build the extension from the latest source code">

</NumberedItem>
