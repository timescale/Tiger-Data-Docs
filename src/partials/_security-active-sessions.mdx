Every sign-in to your {C.ACCOUNT_LONG} is an active session: each browser you use {C.CONSOLE} from, and each machine where you logged in with [{C.CLI_LONG}](/get-started/quickstart/tiger-cli), which also covers the bundled {C.MCP_LONG}. You can review these sessions and revoke any of them from {C.CONSOLE}. Revoking a session signs that device out remotely, so it is the way to cut off access for a device you no longer control, or for {C.CLI_SHORT} and {C.MCP_SHORT} on a machine where you can't run `tiger auth logout`.

To review and revoke sessions:

<NumberedList>

<NumberedItem title={`Click your user name in the top right of ${C.CONSOLE} and select \`Account settings\``}>

The `Active sessions` list shows each device signed in to your {C.ACCOUNT_SHORT}, with its location, sign-in time, and last activity. Web sessions show the browser and operating system; {C.CLI_SHORT} sessions show the {C.CLI_LONG} version and platform, for example `tiger-cli/0.24.0 (darwin/arm64)`.

</NumberedItem>

<NumberedItem title="Revoke the sessions you don't recognize or no longer need">

Click `Revoke` next to a session to sign that device out, or `Revoke all other sessions` to sign out everything except the browser you are using. A revoked {C.CLI_SHORT} session stops working immediately; to use {C.CLI_LONG} on that machine again, run `tiger auth login`.

</NumberedItem>

</NumberedList>
