import * as C from "@constants";



1. **Connect to your {C.SERVICE_LONG}**

   For {C.CLOUD_LONG}, open an [SQL editor](/getting-started/run-queries-from-console/) in [{C.CONSOLE}](https://console.cloud.timescale.com/dashboard/services). For self-hosted, use [`psql`](/integrate/query-administration/psql/#connect-to-your-service).

1. **Enable logical replication for your {C.SERVICE_LONG}**

   1. Run the following command to enable logical replication:

      ```sql
      ALTER SYSTEM SET wal_level = logical;
      SELECT pg_reload_conf();
      ```

   1. Restart your {C.SERVICE_SHORT}.

1. **Create a table**

   Create a table to test the integration. For example:

     ```sql
     CREATE TABLE sensor_data (
     id SERIAL PRIMARY KEY,
     device_id TEXT NOT NULL,
     temperature FLOAT NOT NULL,
     recorded_at TIMESTAMPTZ DEFAULT now()
     );
     ```
