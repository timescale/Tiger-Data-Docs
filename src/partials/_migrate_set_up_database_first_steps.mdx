<NumberedList>
<NumberedItem title="Take the applications that connect to the source database offline">
The duration of the migration is proportional to the amount of data stored in your database. By
disconnecting your app from your database you avoid any possible data loss.
</NumberedItem>

<NumberedItem title="Set your connection strings">
These variables hold the connection information for the source database and target {C.SERVICE_LONG}:

```bash
export SOURCE="postgres://<user>:<password>@<source host>:<source port>/<db_name>"
export TARGET="postgres://tsdbadmin:<PASSWORD>@<HOST>:<PORT>/tsdb?sslmode=require"
```

You find the connection information for your {C.SERVICE_LONG} in the configuration file you
downloaded when you created the service.
</NumberedItem>
</NumberedList>
