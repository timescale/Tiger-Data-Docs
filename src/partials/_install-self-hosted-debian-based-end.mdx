import * as C from "@constants";
import { NumberedList, NumberedItem } from "@components/NumberedList";


<NumberedItem title="Update your local repository list">

```bash
sudo apt update
```

</NumberedItem>

<NumberedItem title={`Install ${C.TIMESCALE_DB}`}>

```bash
sudo apt install timescaledb-2-postgresql-18 postgresql-client-18
```

To install a specific {C.TIMESCALE_DB} [release](https://packagecloud.io/timescale/timescaledb), set the version. For example:

`sudo apt-get install timescaledb-2-postgresql-14='2.6.0*' timescaledb-2-loader-postgresql-14='2.6.0*'`

Older versions of {C.TIMESCALE_DB} may not support all the OS versions listed on this page.

</NumberedItem>

<NumberedItem title={`Tune your ${C.PG} instance for ${C.TIMESCALE_DB}`}>

```bash
sudo timescaledb-tune
```

By default, this script is included with the `timescaledb-tools` package when you install {C.TIMESCALE_DB}. Use the prompts to tune your development or production environment. For more information on manual configuration, see [Configuration](/reference/configuration). If you have an issue, run `sudo apt install timescaledb-tools`.

</NumberedItem>

<NumberedItem title={`Restart ${C.PG}`}>

```bash
sudo systemctl restart postgresql
```

</NumberedItem>

<NumberedItem title={`Log in to ${C.PG} as \`postgres\``}>

```bash
sudo -u postgres psql
```

You are in the psql shell.

</NumberedItem>

<NumberedItem title={`Set the password for \`postgres\``}>

```bash
\password postgres
```

When you have set the password, type `\q` to exit psql.

</NumberedItem>
