{C.HYPERTABLE_CAP}s are {C.PG} tables in {C.TIMESCALE_DB} that automatically partition your time-series data by time. Time-series data represents the way a system, process, or behavior changes over time. {C.HYPERTABLE_CAP}s enable {C.TIMESCALE_DB} to work efficiently with time-series data.  Each {C.HYPERTABLE} is made up of child tables called chunks. Each chunk is assigned a range 
of time, and only contains data from that range. When you run a query, {C.TIMESCALE_DB} identifies the correct chunk and 
runs the query on it, instead of going through the entire table. 

<HypercoreIntroShort />

Because {C.TIMESCALE_DB} is 100% {C.PG}, you can use all the standard {C.PG} tables, indexes, stored
procedures, and other objects alongside your {C.HYPERTABLE}s. This makes creating and working with {C.HYPERTABLE}s similar 
to standard {C.PG}.
