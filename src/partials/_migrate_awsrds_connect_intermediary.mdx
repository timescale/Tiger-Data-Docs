## Create an intermediary EC2 Ubuntu instance
<NumberedList>

<NumberedItem title="Select the RDS/Aurora instance to migrate">

In [https://console.aws.amazon.com/rds/home#databases:](https://console.aws.amazon.com/rds/home#databases:),
select the RDS/Aurora {C.PG} instance to migrate.

</NumberedItem>

<NumberedItem title={`Click \`Actions\` > \`Set up EC2 connection\``}>

Press `Create EC2 instance` and use the following settings:
 - **AMI**: Ubuntu Server.
 - **Key pair**: use an existing pair or create a new one that you will use to access the intermediary machine.
 - **VPC**: by default, this is the same as the database instance.
 - **Configure Storage**: adjust the volume to at least the size of RDS/Aurora {C.PG} instance you are migrating from.
 You can reduce the space used by your data on {C.CLOUD_LONG} using [{C.HYPERCORE_CAP}](/build/columnar-storage).

</NumberedItem>

<NumberedItem title={`Click \`Launch instance\`, then connect via SSH`}>

AWS creates your EC2 instance. Click `Connect to instance` > `SSH client` and follow the instructions to create the connection to your intermediary EC2 instance.

</NumberedItem>

</NumberedList>

## Install the psql client tools on the intermediary instance

<NumberedList>

<NumberedItem title="Connect to your intermediary EC2 instance. For example:">

```sh
ssh -i "<key-pair>.pem" ubuntu@<EC2 instance's Public IPv4>
```

</NumberedItem>

<NumberedItem title={`On your intermediary EC2 instance, install the ${C.PG} client.`}>

```sh
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
wget -qO- https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo tee /etc/apt/trusted.gpg.d/pgdg.asc &>/dev/null
sudo apt update
sudo apt install postgresql-client-16 -y # "postgresql-client-16" if your source DB is using PG 16.
psql --version && pg_dump --version
```

Keep this terminal open, you need it to connect to the RDS/Aurora {C.PG} instance for migration.

</NumberedItem>

</NumberedList>

## Set up secure connectivity between your RDS/Aurora {C.PG} and EC2 instances

<NumberedList>

<NumberedItem title="Select the RDS/Aurora instance to migrate">

In [https://console.aws.amazon.com/rds/home#databases:](https://console.aws.amazon.com/rds/home#databases:),
select the RDS/Aurora {C.PG} instance to migrate.

</NumberedItem>

<NumberedItem title="Open the inbound rules for the security group">

Scroll down to `Security group rules (1)` and select the `EC2 Security Group - Inbound` group. The
`Security Groups (1)` window opens. Click the `Security group ID`, then click `Edit inbound rules`.

![Create security group rule to enable RDS/Aurora PostgreSQL EC2 connection](https://assets.timescale.com/docs/images/migrate/rds-add-security-rule-to-ec2-instance.svg)

</NumberedItem>

<NumberedItem title="On your intermediary EC2 instance, get your local IP address:">

```sh
ec2metadata --local-ipv4
```
Bear with me on this one, you need this IP address to enable access to your RDS/Aurora {C.PG} instance.

</NumberedItem>

<NumberedItem title={`Add inbound rule for your EC2 instance`}>

In `Edit inbound rules`, click `Add rule`, then create a {C.PG} `TCP` rule granting access
to the local IP address for your EC2 instance. Then click `Save rules`. 

![Create security rule to enable RDS/Aurora PostgreSQL EC2 connection](https://assets.timescale.com/docs/images/migrate/rds-add-inbound-rule-for-ec2-instance.png)

</NumberedItem>

</NumberedList>

## Test the connection between your RDS/Aurora {C.PG} and EC2 instances

<NumberedList>

<NumberedItem title="Select the RDS/Aurora instance to migrate">

In [https://console.aws.amazon.com/rds/home#databases:](https://console.aws.amazon.com/rds/home#databases:),
select the RDS/Aurora {C.PG} instance to migrate.

</NumberedItem>

<NumberedItem title="Create the source connection string">

On your intermediary EC2 instance, use the values of `Endpoint`, `Port`, `Master username`, and `DB name`
to create the {C.PG} connectivity string for the `SOURCE` variable.

![Record endpoint, port, VPC details](https://assets.timescale.com/docs/images/migrate/migrate-source-rds-instance.svg)

```sh
export SOURCE="postgres://<Master username>:<Master password>@<Endpoint>:<Port>/<DB name>"
```
The value of `Master password` was supplied when this RDS/Aurora {C.PG} instance was created.

</NumberedItem>

<NumberedItem title="Test your connection:">

```sh
psql -d $SOURCE 
```
You are connected to your RDS/Aurora {C.PG} instance from your intermediary EC2 instance.

</NumberedItem>

</NumberedList>
