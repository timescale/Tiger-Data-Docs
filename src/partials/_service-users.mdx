By default, when you create a new {C.SERVICE_SHORT}, a new `tsdbadmin` user is created.
This is the user that you use to connect to your new {C.SERVICE_SHORT}.

<Callout variant="tip">

The `tsdbadmin` user is the owner of the database, but is not a superuser. You
cannot access the `postgres` user. There is no superuser access to {C.CLOUD_LONG} databases.

</Callout>

In your {C.SERVICE_SHORT}, the `tsdbadmin` user can create another user
with any other role. For a complete list of roles available, see the
[{C.PG} role attributes documentation][pg-roles-doc].

You cannot create multiple databases in a single {C.SERVICE_SHORT}. If you need data isolation, use schemas or create additional {C.SERVICE_SHORT}s.

[pg-roles-doc]: https://www.postgresql.org/docs/current/role-attributes.html
