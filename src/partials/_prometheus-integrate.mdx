[Prometheus](https://prometheus.io/docs/introduction/overview/) is an open-source monitoring system with a dimensional data model, flexible query language, and a modern alerting approach.

This page shows you how to export your {C.SERVICE_SHORT} telemetry to Prometheus:

- For {C.CLOUD_LONG}, using a dedicated Prometheus exporter in {C.CONSOLE}.

- For {C.SELF_LONG}, using [{C.PG} Exporter](https://grafana.com/oss/prometheus/exporters/postgres-exporter/).


<Prerequisites context="integration">
<CloudOrSelf />
<ConnectionDetails />

- [Prometheus](https://prometheus.io/docs/prometheus/latest/installation/) downloaded and running.

  To reduce latency and potential data transfer costs, run Prometheus on a machine in the same AWS region as your {C.SERVICE_LONG}.
</Prerequisites>

## Export {C.SERVICE_LONG} telemetry to Prometheus

To export your data, do the following:

<Tabs>

<TabItem label={C.CLOUD_LONG}>

To export metrics from a {C.SERVICE_LONG}, you create a dedicated Prometheus exporter in {C.CONSOLE}, attach it to your {C.SERVICE_SHORT}, then configure Prometheus to scrape metrics using the exposed URL. See [Exported metrics](/integrate/observability-alerting/exported-metrics) for the full list of default and additional metrics you can export. The Prometheus exporter is available for [Scale and Enterprise](/deploy/tiger-cloud/tiger-cloud-aws/pricing-and-account-management#features-included-in-each-pricing-plan) {C.PRICING_PLAN}s.

<NumberedList>

<NumberedItem title="Create a Prometheus exporter">

1. In [{C.CONSOLE}](https://console.cloud.tigerdata.com/dashboard/services), click `Exporters` > `+ New exporter`.

1. Select `Metrics` for data type and `Prometheus` for provider.

   <Image src={imgCreatePrometheus} alt="Creating a Prometheus exporter in Tiger Console" />

1. Choose the region for the exporter. Only {C.SERVICE_SHORT}s in the same project and region can be attached to this exporter.

1. Name your exporter.

1. Change the auto-generated Prometheus credentials, if needed. See [official documentation](https://prometheus.io/docs/guides/basic-auth/) on basic authentication in Prometheus.

1. Optionally tick `PostgreSQL metrics` to export [additional metrics](/integrate/observability-alerting/exported-metrics#postgresql-metrics), then click `Create exporter`.

</NumberedItem>

<NumberedItem title={`Attach the exporter to a ${C.SERVICE_SHORT}`}>

1. Select a {C.SERVICE_SHORT}, then click `Operations` > `Exporters`.

1. Select the exporter in the drop-down, then click `Attach exporter`.

   <Image src={imgAttachPrometheus} alt="Attaching a Prometheus exporter to a service in Tiger Console" />

The exporter is now attached to your {C.SERVICE_SHORT}. To unattach it, click the trash icon in the exporter list.

</NumberedItem>

<NumberedItem title="Configure the Prometheus scrape target">

1. Select your service, then click `Operations` > `Exporters` and click the information icon next to the exporter. You see the exporter details.

   <Image src={imgPrometheusDetails} alt="Prometheus exporter details showing endpoint and credentials" />

1. Copy the exporter URL.

1. In your Prometheus installation, update `prometheus.yml` to point to the exporter URL as a scrape target:

   ```yml
   scrape_configs:
    - job_name: "timescaledb-exporter"
      scheme: https
      static_configs:
        - targets: ["my-exporter-url"]
      basic_auth:
        username: "user"
        password: "pass"
   ```

   See the [Prometheus documentation](https://prometheus.io/docs/prometheus/latest/configuration/configuration/#scrape_config) for details on configuring scrape targets.

   You can now monitor your {C.SERVICE_SHORT} metrics.

</NumberedItem>

</NumberedList>



</TabItem>

<TabItem label={C.SELF_LONG_CAP}>

To export metrics from {C.SELF_LONG}, you import telemetry data about your database to {C.PG} Exporter, then configure Prometheus to scrape metrics from it. {C.PG} Exporter exposes metrics that you define, excluding the system metrics.

<NumberedList>

<NumberedItem title={`Install ${C.PG} Exporter`}>

Install [{C.PG} Exporter](https://grafana.com/oss/prometheus/exporters/postgres-exporter/?tab=installation) on a machine that can reach your {C.SELF_LONG} instance.

</NumberedItem>

<NumberedItem title="Create a user to access telemetry data about your database">

1. Connect to your database in [`psql`](/integrate/query-administration/psql) using your [connection details](/integrate/find-connection-details).

 1. Create a user named `monitoring` with a secure password:

    ```sql
    CREATE USER monitoring WITH PASSWORD '<password>';
    ```

 1. Grant the `pg_read_all_stats` permission to the `monitoring` user:

    ```sql
    GRANT pg_read_all_stats to monitoring;
    ```

</NumberedItem>

<NumberedItem title={`Import telemetry data about your database to ${C.PG} Exporter`}>

1. Connect {C.PG} Exporter to your database:

    Use your [connection details](/integrate/find-connection-details) to import telemetry data about your database. You connect as
    the `monitoring` user:

     - Local installation:
        ```shell
        export DATA_SOURCE_NAME="postgres://<user>:<password>@<host>:<port>/<database>?sslmode=<sslmode>"
        ./postgres_exporter
        ```
     - Docker:
        ```shell
        docker run -d \
           -e DATA_SOURCE_NAME="postgres://<user>:<password>@<host>:<port>/<database>?sslmode=<sslmode>" \
           -p 9187:9187 \
           prometheuscommunity/postgres-exporter
        ```

 1. Check the metrics for your database in the Prometheus format:

     - Browser:

       Navigate to `http://<exporter-host>:9187/metrics`.

     - Command line:
        ```shell
        curl http://<exporter-host>:9187/metrics
        ```

</NumberedItem>

<NumberedItem title="Configure Prometheus to scrape metrics">

1. In your Prometheus installation, update `prometheus.yml` to point to your {C.PG} Exporter instance as a scrape
    target. In the following example, you replace `<exporter-host>` with the hostname or IP address of the {C.PG}
    Exporter.

    ```yaml
    global:
      scrape_interval: 15s

    scrape_configs:
    - job_name: 'postgresql'
      static_configs:
       - targets: ['<exporter-host>:9187']
    ```

    If `prometheus.yml` has not been created during installation, create it manually. If you are using Docker, you can
    find the IPAddress in `Inspect` > `Networks` for the container running {C.PG} Exporter.

 1. Restart Prometheus.

 1. Check the Prometheus UI at `http://<prometheus-host>:9090/targets` and `http://<prometheus-host>:9090/tsdb-status`.

    You see the {C.PG} Exporter target and the metrics scraped from it.

</NumberedItem>

</NumberedList>
