## Graph OHLCV data

When you have extracted the raw OHLCV data, you can use it to graph the result
in a candlestick chart, using Grafana. To do this, you need to have Grafana set
up to connect to your {C.SELF_LONG} instance.

<NumberedList>

<NumberedItem title="Ensure Grafana is installed and connected">

Ensure you have Grafana installed, and you are using the TimescaleDB
database that contains the Twelve Data dataset set up as a data source.

</NumberedItem>

<NumberedItem title="Create a new dashboard">

In Grafana, from the `Dashboards` menu, click `New Dashboard`. In the
`New Dashboard` page, click `Add a new panel`.

</NumberedItem>

<NumberedItem title="Select the Candlestick visualization">

In the `Visualizations` menu in the top right corner, select `Candlestick`
from the list. Ensure you have set the Twelve Data dataset as
your data source.

</NumberedItem>

<NumberedItem title="Paste the OHLCV query">

Click `Edit SQL` and paste in the query you used to get the OHLCV values.

</NumberedItem>

<NumberedItem title="Select the Table format">

In the `Format as` section, select `Table`.

</NumberedItem>

<NumberedItem title="Apply and save your graph">

Adjust elements of the table as required, and click `Apply` to save your
graph to the dashboard.

![Creating a candlestick graph in Grafana using 1-day OHLCV tick data](https://assets.timescale.com/docs/images/Grafana_candlestick_1day.webp)

</NumberedItem>

</NumberedList>
