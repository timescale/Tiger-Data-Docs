## Graph OHLCV data

When you have extracted the raw OHLCV data, you can use it to graph the result
in a candlestick chart, using Grafana. To do this, you need to have Grafana set
up to connect to your {C.SELF_LONG} instance.

### Graphing OHLCV data

<NumberedList>

<NumberedItem title="Ensure you have Grafana installed, and you are using the TimescaleDB">

database that contains the Twelve Data dataset set up as a
data source.

</NumberedItem>

<NumberedItem title="In Grafana, from the `Dashboards` menu, click `New Dashboard`. In the">

`New Dashboard` page, click `Add a new panel`.

</NumberedItem>

<NumberedItem title="In the `Visualizations` menu in the top right corner, select `Candlestick`">

from the list. Ensure you have set the Twelve Data dataset as
your data source.

</NumberedItem>

<NumberedItem title="Click `Edit SQL` and paste in the query you used to get the OHLCV values."></NumberedItem>

<NumberedItem title="In the `Format as` section, select `Table`."></NumberedItem>

<NumberedItem title="Adjust elements of the table as required, and click `Apply` to save your">

graph to the dashboard.
