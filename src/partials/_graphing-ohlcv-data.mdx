## Graph OHLCV data

When you have extracted the raw OHLCV data, you can use it to graph the result
in a candlestick chart, using Grafana.

<NumberedList>

<NumberedItem title="Create a new dashboard">

In Grafana, from the `Dashboards` page, click `New` and select `New dashboard`.

</NumberedItem>

<NumberedItem title="Add a Candlestick visualization">

Click `Add visualization`, then select the data source that connects to your {C.SERVICE_LONG} and the `Candlestick` visualization type in the top right.

</NumberedItem>

<NumberedItem title="Paste the OHLCV query">

In the `Queries` section, select `Code` and paste the query you used to get the OHLCV values:

```sql
SELECT * FROM one_day_candle
WHERE symbol = 'BTC/USD' AND bucket >= NOW() - INTERVAL '14 days'
ORDER BY bucket;
```

</NumberedItem>

<NumberedItem title="Apply and save your graph">

Adjust elements of the table as required, and click `Apply` to save your
graph to the dashboard.

</NumberedItem>

</NumberedList>
