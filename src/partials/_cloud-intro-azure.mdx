{C.CLOUD_LONG} is the modern {C.PG} data platform for all your applications. It enhances {C.PG} to handle time series, events,
real-time analytics, and vector search, all in a single database alongside transactional workloads.

You get one system that handles live data ingestion, late and out-of-order updates, and low latency queries, with the performance, reliability, and scalability your app needs. Ideal for IoT, crypto, finance, SaaS, and a myriad other domains, {C.CLOUD_LONG} allows you to build data-heavy, mission-critical apps while retaining the familiarity and reliability of {C.PG}.

A {C.SERVICE_LONG} is a single optimised {C.PG} instance extended with innovations in the database engine and cloud
infrastructure to deliver speed without compromise. A {C.SERVICE_LONG} instance is 10-1000x faster at scale! A {C.SERVICE_SHORT}
is ideal for applications requiring strong data consistency, complex relationships, and advanced querying capabilities.
Get ACID compliance, extensive SQL support, JSON handling, and extensibility through custom functions, data types, and
extensions. To the {C.PG} you know and love, {C.CLOUD_LONG} adds the following capabilities:

Store and query [time-series data](https://www.tigerdata.com/blog/time-series-database-an-explainer#what-is-a-time-series-database) at scale: get faster time-based queries with {C.HYPERTABLE}s, {C.CAGG}s, and columnar storage, and save money by compressing data into the {C.COLUMNSTORE} and deleting old data with automated policies. Build AI applications with fast, accurate similarity search using the pgvector and pgvectorscale extensions, and create vector embeddings and perform LLM reasoning on your data with the pgai extension.

All {C.SERVICE_LONG}s include the tooling you expect for production and developer environments: [live migration](/migrate/live-migration),
[automatic backups and PITR](/deploy/tiger-cloud/tiger-cloud-aws/high-availability/backup-restore), [high availability](/deploy/tiger-cloud/tiger-cloud-aws/high-availability/high-availability), [{C.READ_REPLICA}s](/deploy/tiger-cloud/tiger-cloud-aws/high-availability/read-scaling), [data forking](/deploy/tiger-cloud/tiger-cloud-aws/service-management/fork-services), [connection pooling](/deploy/tiger-cloud/tiger-cloud-aws/service-management/connection-pooling), 
[usage-based storage](/deploy/tiger-cloud/tiger-cloud-aws/pricing-and-account-management#how-your-bill-is-calculated), secure in-{C.CONSOLE} [SQL editing](/build/data-management/run-queries-from-tiger-console), {C.SERVICE_SHORT} [metrics](/deploy/tiger-cloud/tiger-cloud-aws/monitoring#metrics)
and [insights](/deploy/tiger-cloud/tiger-cloud-aws/monitoring#insights),&nbsp;[streamlined maintenance](/deploy/tiger-cloud/tiger-cloud-aws/upgrades),&nbsp;and much more. {C.CLOUD_LONG} continuously monitors your {C.SERVICE_SHORT}s and prevents common {C.PG} out-of-memory crashes.
