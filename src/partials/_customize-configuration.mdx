{C.CLOUD_LONG} allows you to customize many {C.CLOUD_LONG}-specific and {C.PG}
configuration options for each {C.SERVICE_SHORT} individually. Most configuration values
for a {C.SERVICE_SHORT} are initially set in accordance with best practices given the
compute and storage settings of the {C.SERVICE_SHORT}. Any time you increase or decrease
the compute for a {C.SERVICE_SHORT}, the most essential values are set to reflect the size
of the new {C.SERVICE_SHORT}.

<Callout variant="warning">

You can modify most parameters without restarting the {C.SERVICE_SHORT}.
However, some changes do require a restart, resulting in some brief downtime
that is usually about 30&nbsp;seconds. An example of a change that needs a
restart is modifying the compute resources of a running {C.SERVICE_SHORT}.

</Callout>

## View {C.SERVICE_SHORT} operation details

To modify configuration parameters, first select the {C.SERVICE_SHORT} that you want to
modify. This displays the {C.SERVICE_SHORT} details, with these tabs across the top:
`Overview`, `Actions`, `Explorer`, `Monitoring`, `Connections`, `Operations`, and `AI`. Select `Operations`, then `Database parameters`.

![Database configuration parameters](https://assets.timescale.com/docs/images/tiger-on-azure/tiger-console-service-configuration-parameters.png)

### Modify basic parameters

Under the `Common parameters` tab, you can modify a limited set of the
parameters that are most often modified in a {C.CLOUD_LONG} or {C.PG} instance.
To modify a configured value, hover over the value and click the revealed pencil
icon. This reveals an editable field to apply your change. Clicking anywhere
outside of that field saves the value to be applied.

![Change Tiger Cloud configuration parameters](https://assets.timescale.com/docs/images/tsc-settings-change.png)

### Apply configuration changes

When you have modified the configuration parameters that you would like to
change, click `Apply changes`. For some changes, such as
`timescaledb.max_background_workers`, the {C.SERVICE_SHORT} needs to be restarted. In this
case, the button reads `Apply changes and restart`.

A confirmation dialog is displayed which indicates whether a restart is
required. Click `Confirm` to apply the changes, and restart if necessary.
