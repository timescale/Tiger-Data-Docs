{C.CLOUD_LONG} allows you to customize many {C.CLOUD_LONG}-specific and {C.PG}
configuration options for each {C.SERVICE_SHORT} individually. Most configuration values
for a {C.SERVICE_SHORT} are initially set in accordance with best practices given the
compute and storage settings of the {C.SERVICE_SHORT}. Any time you increase or decrease
the compute for a {C.SERVICE_SHORT}, the most essential values are set to reflect the size
of the new {C.SERVICE_SHORT}.

<Callout variant="warning">

You can modify most parameters without restarting the {C.SERVICE_SHORT}.
However, some changes do require a restart, resulting in some brief downtime
that is usually about 30&nbsp;seconds. An example of a change that needs a
restart is modifying the compute resources of a running {C.SERVICE_SHORT}.

</Callout>

## Modify a configuration parameter

<NumberedList>

<NumberedItem title="Open database parameters">

Select the {C.SERVICE_SHORT} you want to modify, then click `Operations` > `Database parameters`.

<ThemeImage light={imgTigerConsoleServiceConfigurationParametersLight} dark={imgTigerConsoleServiceConfigurationParametersDark} alt="Database configuration parameters" />

</NumberedItem>

<NumberedItem title="Edit a parameter value">

Under `Common parameters`, hover over the value you want to change and click the edit icon. This reveals an editable field. Clicking anywhere outside of that field saves the value to be applied.

<ThemeImage light={imgTscSettingsChangeLight} dark={imgTscSettingsChangeDark} alt="Change Tiger Cloud configuration parameters" />

</NumberedItem>

<NumberedItem title="Apply the change">

Click `Apply changes and restart`. For some changes, such as `timescaledb.max_background_workers`, the {C.SERVICE_SHORT} needs to be restarted.

</NumberedItem>

<NumberedItem title="Confirm the change">

In the confirmation dialog, click `Confirm` to apply the change, and restart the {C.SERVICE_SHORT} if necessary.

</NumberedItem>

</NumberedList>
