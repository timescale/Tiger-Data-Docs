## Install {C.TOOLKIT_LONG}

These instructions use the `yum` package manager.

<Steps>

<Step title="Update your local repository list">

```bash
sudo yum update
```

</Step>

<Step title={`Install ${C.TOOLKIT_LONG}`}>

```bash
sudo yum install timescaledb-toolkit-postgresql-18
```

</Step>

<Step title={`Connect to the database where you want to use ${C.TOOLKIT_SHORT}`}>

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

</Step>

<Step title={`Create the ${C.TOOLKIT_SHORT} extension in the database`}>

```sql
CREATE EXTENSION timescaledb_toolkit;
```

</Step>

</Steps>

## Update {C.TOOLKIT_LONG}

Update {C.TOOLKIT_SHORT} by installing the latest version and running `ALTER EXTENSION`.

<Steps>

<Step title="Update your local repository list">

```bash
yum update
```

</Step>

<Step title={`Install the latest version of ${C.TOOLKIT_LONG}`}>

```bash
yum install timescaledb-toolkit-postgresql-18
```

</Step>

<Step title={`Connect to the database where you want to use ${C.TOOLKIT_SHORT}`}>

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

</Step>

<Step title={`Update the ${C.TOOLKIT_SHORT} extension in the database`}>

```sql
ALTER EXTENSION timescaledb_toolkit UPDATE;
```

<Callout variant="note">

For some {C.TOOLKIT_SHORT} versions, you might need to disconnect and reconnect active
sessions.

</Callout>

</Step>

</Steps>
