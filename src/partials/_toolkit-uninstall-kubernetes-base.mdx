## Uninstall {C.TOOLKIT_LONG}

{C.TOOLKIT_SHORT} is included in the TimescaleDB HA Docker image and cannot be uninstalled separately. To remove {C.TOOLKIT_SHORT}, you need to remove the entire TimescaleDB deployment. See [Uninstall TimescaleDB from Kubernetes](/deploy/self-hosted/uninstall).

If you only want to remove the extension from a specific database without removing the deployment:

<NumberedList>

<NumberedItem title="Connect to your TimescaleDB pod">

```shell
kubectl exec -it test-pod -- bash -c "psql -h \$PGHOST -U \$PGUSER -d \$PGDATABASE"
```

</NumberedItem>

<NumberedItem title={`Drop the ${C.TOOLKIT_SHORT} extension`}>

At the `psql` prompt:

```sql
DROP EXTENSION timescaledb_toolkit;
```

<Callout variant="warning">

Using `CASCADE` drops all objects that depend on the {C.TOOLKIT_SHORT} extension. Ensure you have backed up any data
you want to keep.

</Callout>

</NumberedItem>

</NumberedList>
