import * as C from "../constants";
import { Steps, Step } from "@stainless-api/docs/components";


ArchLinux packages are built by the community.

<Steps>

<Step title={`Install the latest ${C.PG} and ${C.TIMESCALE_DB} packages`}>

```bash
sudo pacman -Syu timescaledb timescaledb-tune postgresql-libs
```

</Step>

<Step title={`Initalize your ${C.PG} instance`}>

```bash
sudo -u postgres initdb --locale=en_US.UTF-8 --encoding=UTF8 -D /var/lib/postgres/data --data-checksums
```

</Step>

<Step title={`Tune your ${C.PG} instance for TimescaleDB`}>

```bash
sudo timescaledb-tune
```   

This script is included with the `timescaledb-tools` package when you install TimescaleDB. For more information, see [configuration][config].

</Step>

<Step title={`Enable and start ${C.PG}`}>

```bash
sudo systemctl enable postgresql.service
sudo systemctl start postgresql.service
```

</Step>

<Step title={`Log in to ${C.PG} as \`postgres\``}>

```bash
sudo -u postgres psql
```
You are in the psql shell.

</Step>

<Step title="Set the password for `postgres`">

```bash
 \password postgres
 ```

 When you have set the password, type `\q` to exit psql.

</Step>

</Steps>

[config]: /self-hosted/configuration/
