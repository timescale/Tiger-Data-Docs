import * as C from "@constants";
import { NumberedList, NumberedItem } from "@components/NumberedList";


ArchLinux packages are built by the community.

<NumberedList>

<NumberedItem title={`Install the latest ${C.PG} and ${C.TIMESCALE_DB} packages`}>

```bash
sudo pacman -Syu timescaledb timescaledb-tune postgresql-libs
```

</NumberedItem>

<NumberedItem title={`Initalize your ${C.PG} instance`}>

```bash
sudo -u postgres initdb --locale=en_US.UTF-8 --encoding=UTF8 -D /var/lib/postgres/data --data-checksums
```

</NumberedItem>

<NumberedItem title={`Tune your ${C.PG} instance for ${C.TIMESCALE_DB}`}>

```bash
sudo timescaledb-tune
```   

This script is included with the `timescaledb-tools` package when you install {C.TIMESCALE_DB}. For more information, see [configuration](/reference/configuration).

</NumberedItem>

<NumberedItem title={`Enable and start ${C.PG}`}>

```bash
sudo systemctl enable postgresql.service
sudo systemctl start postgresql.service
```

</NumberedItem>

<NumberedItem title={`Log in to ${C.PG} as \`postgres\``}>

```bash
sudo -u postgres psql
```
You are in the psql shell.

</NumberedItem>

<NumberedItem title="Set the password for `postgres`">

```bash
 \password postgres
 ```

 When you have set the password, type `\q` to exit psql.

</NumberedItem>

</NumberedList>
