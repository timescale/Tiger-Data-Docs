[VisuaLeaf](https://visualeaf.com/database/timescaledb/) is a cross-platform desktop database client for Windows, macOS, and Linux, with a SQL editor, a results grid, a visual query builder, ER diagrams, and charts built from query results. It has a dedicated {C.TIMESCALE_DB} connection type, and a free Community Edition alongside paid editions.

This page explains how to integrate VisuaLeaf with your {C.SERVICE_LONG}.

In this integration guide, you:

- Connect VisuaLeaf to your {C.SERVICE_SHORT} using its {C.TIMESCALE_DB} connection type.
- Browse your schema and hypertables in the VisuaLeaf `Connections` sidebar.
- Run a time-series query from the VisuaLeaf SQL editor.

## Connect VisuaLeaf to your service

To connect to {C.CLOUD_LONG}:

<NumberedList>
  <NumberedItem title="Start VisuaLeaf and open the connection dialog">

    Click `New Connection` to open the `Connect a database` picker.

  </NumberedItem>
  <NumberedItem title="Select TimescaleDB as the connection type">

    In the search box, type `timescale`, then select `TimescaleDB`. It is listed under `PostgreSQL-compatible` and connects over the standard {C.PG} wire protocol.

    <Image src={imgVisualeafSelectTimescaledb} alt="VisuaLeaf New Connection dialog with timescale typed in the database search box and the TimescaleDB connection type shown under PostgreSQL-compatible" />

  </NumberedItem>
  <NumberedItem title="Configure the connection">

    Fill in the connection name and use your [connection details](/integrate/find-connection-details) for `Host`, `Port` (`5432` by default), `Database`, `Username`, and `Password`. {C.CLOUD_LONG} accepts unencrypted connections, so expand `Advanced driver properties` and set `sslmode` to `require` to make sure yours is encrypted.

  </NumberedItem>
  <NumberedItem title="Click `Test Connection`, then `Save & Connect`">

    A successful test shows `Connection successful` above the connection fields. `Save & Connect` saves the connection and opens it in the `Connections` sidebar.

    <Image src={imgVisualeafTestConnection} alt="VisuaLeaf New Connection form with the Tiger Cloud service host, port, database, and username filled in, and a Connection successful banner after clicking Test Connection" />

  </NumberedItem>
</NumberedList>

You have successfully integrated VisuaLeaf with {C.CLOUD_LONG}.

## Verify the integration

<NumberedList>
  <NumberedItem title="Browse the schema">

    In the `Connections` sidebar, expand your connection, then your database. Expand the `public` schema, then `Tables`, to see your hypertables. The internal `_timescaledb_*` and `timescaledb_*` schemas are listed alongside your own schemas. Double-click a hypertable to open its rows in a data grid.

    <Image src={imgVisualeafObjectBrowser} alt="VisuaLeaf Connections sidebar with the tsdb database on Tiger Cloud expanded, showing the internal _timescaledb schemas and the public schema's Tables folder containing the greenhouse_readings hypertable, with the hypertable's rows open in a data grid beside it" />

  </NumberedItem>
  <NumberedItem title="Run a query against a hypertable">

    Right-click your database and select `New SQL Editor`. Run a query against one of your hypertables, for example:

    ```sql
    SELECT time_bucket('1 hour', ts) AS bucket, greenhouse,
      avg(temperature)::numeric(4,1) AS avg_temp,
      max(humidity) AS max_humidity
    FROM greenhouse_readings
    WHERE greenhouse = 'Osaka'
    GROUP BY bucket, greenhouse
    ORDER BY bucket
    LIMIT 12;
    ```

    Press `F5` to run the whole script, or `F9` to run only the selected text. The results grid opens below the editor.

    <Image src={imgVisualeafQueryResults} alt="VisuaLeaf SQL editor with a time_bucket query against the greenhouse_readings hypertable and a results grid below it showing hourly average temperature and maximum humidity" />

  </NumberedItem>
</NumberedList>
