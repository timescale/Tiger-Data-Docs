[qStudio](https://www.timestored.com/qstudio/) is a modern free SQL editor that provides syntax highlighting, code-completion, excel export, charting, and much more. You can use it to run queries, browse tables, and create charts for your {C.SERVICE_LONG}.

This page explains how to integrate qStudio with {C.CLOUD_LONG}.

<Prerequisites context="integration">
<IntegrationPrereqs />

- [qStudio](https://www.timestored.com/qstudio/download) downloaded and installed.
</Prerequisites>

## Connect qStudio to your service

To connect to {C.CLOUD_LONG}:

<NumberedList>
  <NumberedItem title="Start qStudio" />
  <NumberedItem title="Click `Server` > `Add Server`" />
  <NumberedItem title="Configure the connection">
    - For `Server Type`, select `Postgres`.
    - For `Connect By`, select `Host`.
    - For `Host`, `Port`, `Database`, `Username`, and `Password`, use your [connection details](/integrate/find-connection-details).

    <Image src={imgIntegrationsQstudio} alt="qStudio connected to a Tiger Cloud service" />
  </NumberedItem>
  <NumberedItem title="Click `Test`">
    qStudio indicates whether the connection works.
  </NumberedItem>
  <NumberedItem title="Click `Add`">
    The server is listed in the `Server Tree`.
  </NumberedItem>
</NumberedList>

You have successfully integrated qStudio with {C.CLOUD_LONG}.
