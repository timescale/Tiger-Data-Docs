[qStudio][qstudio] is a modern free SQL editor that provides syntax highlighting, code-completion, excel export, charting, and much more. You can use it to run queries, browse tables, and create charts for your {C.SERVICE_LONG}.

This page explains how to integrate qStudio with {C.CLOUD_LONG}.

## Prerequisites

<IntegrationPrereqs />

- [Download][qstudio-downloads] and install qStudio.

## Connect qStudio to your service

To connect to {C.CLOUD_LONG}:

1. **Start qStudio**

2. **Click `Server` > `Add Server`**

3. **Configure the connection**

   - For `Server Type`, select `Postgres`.
   - For `Connect By`, select `Host`.
   - For `Host`, `Port`, `Database`, `Username`, and `Password`, use your [connection details][connection-info].

   ![qStudio integration][qstudio-integration]

4. **Click `Test`**

   qStudio indicates whether the connection works.

5. **Click `Add`**

   The server is listed in the `Server Tree`.

You have successfully integrated qStudio with {C.CLOUD_LONG}.
