[Mode Analytics](https://mode.com/) is a collaborative analytics platform that lets you query, visualize, and share data through SQL, notebooks, and dashboards.

This page shows you how to connect Mode to {C.COMPANY} as a data connection, so that you can explore and visualize the data in your service or database.

In this integration guide, you:

- Add your service or database to Mode as a data connection.
- Verify that Mode can query your data.

<Prerequisites context="integration">
<IntegrationPrereqs />
<ConnectionDetails />
- A [Mode](https://mode.com/) workspace, with permissions to add a database connection.
</Prerequisites>

## Add your service or database to Mode

Mode's `Direct Connect` option connects to publicly accessible databases over an encrypted connection. {C.CLOUD_LONG} services are publicly accessible by default. For {C.SELF_LONG}, make sure your instance accepts connections from the public internet, or use Mode's Bridge agent instead if it's only reachable over a private network or virtual private network (VPN).

<NumberedList>
  <NumberedItem title="Open the database connection settings in Mode">

    In Mode, click your name in the top-left corner, then select `Connect a Database`.

  </NumberedItem>
  <NumberedItem title="Choose Direct Connect">

    Select `Direct Connect`, the option for databases reachable over the public internet. If your database isn't publicly reachable, for example a self-hosted instance behind a firewall or VPN, use Mode's Bridge agent instead.

  </NumberedItem>
  <NumberedItem title="Enter your connection details">

    Select `PostgreSQL` as the database type, then enter your [connection details](/integrate/find-connection-details):

    - **Host** and **Port**: your `host` and `port`.
    - **Database name**: your `dbname`.
    - **Username** and **Password**: your `user` and `password`.

    Turn on SSL. {C.CLOUD_LONG} rejects unencrypted connections; for self-hosted TimescaleDB, turn it on if your instance is configured to require SSL.

  </NumberedItem>
  <NumberedItem title="Allowlist Mode's IP addresses">

    Direct Connect reaches your database from a fixed set of Mode IP addresses. Add the current list from [Mode's connection documentation](https://mode.com/help/articles/connecting-mode-to-your-database) to your database's network or firewall allow list. In {C.CLOUD_LONG}, add them to your service's IP allow list under `Security` in the console.

  </NumberedItem>
  <NumberedItem title="Test and save the connection">

    Click `Connect`. Mode tests the connection and reports whether it succeeded; if it fails, Mode shows whether the problem is SSL, network access, or credentials.

  </NumberedItem>
</NumberedList>

## Verify the integration

To confirm Mode is working with your service or database:

<NumberedList>
  <NumberedItem title="Open a new query">

    In Mode, click `+ New` > `Query`, then select your connection from the data source list.

  </NumberedItem>
  <NumberedItem title="Run a query">

    Run a simple query against one of your tables:

    ```sql
    SELECT * FROM <table_name> LIMIT 10;
    ```

    You see rows from your service or database in the results pane, confirming that Mode can read your data.

  </NumberedItem>
</NumberedList>

You have successfully integrated Mode Analytics with {C.COMPANY}.

## Troubleshooting

- **Connection fails with an SSL error:** confirm SSL is turned on in the connection settings. {C.CLOUD_LONG} requires encrypted connections; for {C.SELF_LONG}, confirm your instance is configured for SSL if you enabled it.
- **Connection times out:** confirm Mode's IP addresses are added to your database's allow list, and that the host and port are correct. If your database isn't publicly reachable, use Mode's Bridge agent instead of Direct Connect.
- **Authentication failed:** confirm the username and password match your [connection details](/integrate/find-connection-details) exactly.

For other connectivity and authentication issues, see [Troubleshoot {C.CLOUD_LONG} integrations](/integrate/troubleshooting).
