[Amazon CloudWatch](https://aws.amazon.com/cloudwatch/) is a monitoring and observability service designed to help collect, analyze, and act on data from applications, infrastructure, and services running in AWS and on-premises environments.

You can export telemetry data from your {C.SERVICE_LONG}s with the time-series and analytics capability enabled to CloudWatch. See [Exported metrics](/integrate/observability-alerting/exported-metrics) for the full list of default and additional metrics you can export.

This pages explains how to export telemetry data from your {C.SERVICE_LONG} into CloudWatch by creating a {C.CLOUD_LONG} data exporter, then attaching it to the {C.SERVICE_SHORT}. This integration is available for [Scale and Enterprise](/deploy/tiger-cloud/tiger-cloud-aws/pricing-and-account-management#features-included-in-each-pricing-plan) pricing tiers.

## Reference

When you create the IAM OIDC provider, the URL must match the region you create the exporter in.
It must be one of the following:
