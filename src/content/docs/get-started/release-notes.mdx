For information about new features and improvements to {C.CLOUD_LONG}, see the [Changelog](/get-started/new). For other products, see:

* [{C.TIMESCALE_DB}](https://github.com/timescale/timescaledb/releases) - an open-source database that makes SQL scalable
  for time-series data, packaged as a {C.PG} extension.
* [{C.TOOLKIT_LONG}](https://github.com/timescale/timescaledb-toolkit/releases) - additional functions to ease all things analytics
  when using {C.TIMESCALE_DB}.
* [{C.PGAI_SHORT}](https://github.com/timescale/pgai/releases) - brings AI workflows to your {C.PG} database.
* [{C.PGVECTORSCALE}](https://github.com/timescale/pgvectorscale/releases/tag/0.2.0) - higher performance embedding search and cost-efficient storage for AI applications on {C.PG}.
* [{C.PG_SPOT}](https://github.com/timescale/pgspot/releases) - spot vulnerabilities in {C.PG} extension scripts.
* [live-migration](https://hub.docker.com/r/timescale/live-migration/tags) - a Docker image to migrate data to a {C.SERVICE_LONG}.
