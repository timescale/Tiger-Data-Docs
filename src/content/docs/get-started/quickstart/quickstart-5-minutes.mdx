In this page, you will create a {C.SERVICE_LONG}, connect to it, create your first {C.HYPERTABLE}, and run a query. By the end you'll have a working time-series table and see query results, all in under 5 minutes.

For a more extensive lesson on what {C.HYPERTABLE}s are and why they matter, see [Your first {C.HYPERTABLE}](/build/how-to/your-first-hypertable).

<Prerequisites>
  - A [{C.CLOUD_LONG} account](https://console.cloud.tigerdata.com/)
</Prerequisites>

## Step 1: Create a {C.SERVICE_SHORT}

<NumberedList>
   <NumberedItem title={`Create a ${C.SERVICE_SHORT}`}>
   In [{C.CONSOLE}](https://console.cloud.tigerdata.com/), click `New service` > `Real-time analytics`. Choose any provider, region, and compute size. Select a development environment with no replicas and no power-ups.
   </NumberedItem>
   <NumberedItem title={`Wait for the ${C.SERVICE_SHORT} to be ready`}>
   Click `Create service`. The {C.SERVICE_SHORT} is ready in a few seconds.
   </NumberedItem>
   <NumberedItem title="Download the database config">
   Download the database config and store it somewhere safe, you'll need the connection string to connect to your {C.SERVICE_SHORT}.
   </NumberedItem>
</NumberedList>

For more detail, see [Create a {C.SERVICE_LONG}](/get-started/quickstart/create-service).

## Step 2: Connect to your {C.SERVICE_SHORT}

Pick one way to run SQL:

- **{C.CONSOLE} (easiest):** In {C.CONSOLE}, open your {C.SERVICE_SHORT}, then use `Data view` at the top or `SQL Editor` at the bottom. You're connected as soon as you see the query panel.
- **psql:** From your terminal, run `psql "<your-service-url>"` using the connection string from the config file you downloaded.

Run this to confirm you're connected:

```sql
SELECT CURRENT_DATE;
```

You should see today's date. If you do, you're ready for the next step. For connection options, including other clients, see [Connect your app](/get-started/quickstart/connect-your-app).

## Step 3: Create your first {C.HYPERTABLE} and run a query

We'll create a small **{C.HYPERTABLE}** (a table optimized for time-series data), insert a few rows, and query them. You'll use standard SQL; the database handles partitioning automatically.

<NumberedList>
   <NumberedItem title={`Create the ${C.HYPERTABLE}`}>
   Run this in {C.CONSOLE} or your SQL client:

   ```sql
   CREATE TABLE conditions (
      time        TIMESTAMPTZ       NOT NULL,
      location    TEXT              NOT NULL,
      device      TEXT              NOT NULL,
      temperature DOUBLE PRECISION  NULL,
      humidity    DOUBLE PRECISION  NULL
   ) WITH (
      tsdb.hypertable,
      tsdb.segmentby = 'device',
      tsdb.orderby = 'time DESC'
   );
   ```

   You should see a confirmation that the table was created. The `tsdb.hypertable` option makes this a {C.HYPERTABLE} partitioned by time.
   </NumberedItem>
   <NumberedItem title="Insert sample data">
   ```sql
   INSERT INTO conditions (time, location, device, temperature, humidity)
   VALUES
      (NOW() - INTERVAL '2 hours', 'office', 'sensor-1', 22.1, 45.0),
      (NOW() - INTERVAL '1 hour',  'office', 'sensor-1', 22.3, 44.8),
      (NOW(),                      'office', 'sensor-1', 22.2, 45.1);
   ```
   </NumberedItem>
   <NumberedItem title="Query the data">
   ```sql
   SELECT * FROM conditions ORDER BY time DESC;
   ```

   You should see your three rows with the most recent first. You've just created a {C.HYPERTABLE}, inserted time-series data, and queried it, all with standard SQL.
   </NumberedItem>
</NumberedList>

<Callout variant="tip">
  **What just happened?** The table is partitioned by time into **{C.CHUNK}s**
  behind the scenes. You didn't have to manage {C.CHUNK}s; you just used the table.
  For the full picture, see [Your first {C.HYPERTABLE}](/build/how-to/your-first-hypertable).
</Callout>
