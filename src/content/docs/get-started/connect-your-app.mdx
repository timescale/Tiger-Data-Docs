Tiger Data is compatible with {C.PG}, so you can use any {C.PG} client or driver.

## Connection string

Your connection string follows the standard {C.PG} format:

```
postgresql://username:password@host:port/database
```

## Popular languages & frameworks

- **Python**: psycopg2, SQLAlchemy, asyncpg
- **Node.js**: pg, Prisma, TypeORM
- **Go**: pgx, database/sql with pq
- **Java**: JDBC, Spring Data
- **Ruby**: pg gem, ActiveRecord

See [Integrations](/integrate) for detailed guides.
