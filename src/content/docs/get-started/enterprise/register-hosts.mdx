Registering your infrastructure hosts is the second step of setting up TimescaleDB Enterprise. The
console connects to each host over SSH so it can provision and manage {C.TIMESCALE_DB} on them.

## Prerequisites

- You have [installed the console](/get-started/enterprise/install-console) and signed in.

## Register a host

<NumberedList>
  <NumberedItem title="Add the database host">
    In the console, add the host by providing its hostname or IP address and an SSH user.
  </NumberedItem>
  <NumberedItem title="Authorize the console's SSH key">
    The console generates an SSH key and displays the public key. Add that public key to the host's authorized keys.
  </NumberedItem>
  <NumberedItem title="Open the required ports">
    Open the ports the console needs to reach the host: `22`, `8008`, `9100`, `9187`, `9399`, and `9127`. See [system requirements](/get-started/enterprise/requirements) for what each port is for.
  </NumberedItem>
  <NumberedItem title="Test the connection">
    Run the built-in connection test to confirm the console can reach the host before you deploy.
  </NumberedItem>
  <NumberedItem title="Register a backup host (optional)">
    Register a separate host for backups the same way, authorizing the generated public key on that host.
  </NumberedItem>
</NumberedList>
