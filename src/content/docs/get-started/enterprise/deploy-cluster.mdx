Deploying your first cluster is the final step of setting up TimescaleDB Enterprise. You deploy a
{C.TIMESCALE_DB} cluster from the console, which takes about 10 minutes.

## Prerequisites

- You have [installed the console](/get-started/enterprise/install-console).
- You have [registered your infrastructure hosts](/get-started/enterprise/register-hosts).

## Deploy the cluster

<NumberedList>
  <NumberedItem title="Name the cluster">
    Give the cluster a name.
  </NumberedItem>
  <NumberedItem title="Choose a backup host (optional)">
    Select a registered host to store backups.
  </NumberedItem>
  <NumberedItem title="Deploy">
    Start the deployment.
  </NumberedItem>
  <NumberedItem title="Watch the deployment">
    Follow progress in the Operations tab, which streams every step live. You can download the logs at any point.
  </NumberedItem>
  <NumberedItem title="Connect and monitor">
    When the cluster is running, copy the connection string from the console to connect to your database. Pre-built dashboards for cluster health are available from the console.
  </NumberedItem>
</NumberedList>
