Setting up TimescaleDB Enterprise takes three steps, and installing the console is the first:

1. **Install the console** (this page): load and start the console, then sign in.
2. [Register your infrastructure hosts](/get-started/enterprise/register-hosts): connect the console to the hosts that run your database.
3. [Deploy your first cluster](/get-started/enterprise/deploy-cluster): create a cluster and connect to it.

The console is the control plane for TimescaleDB Enterprise. It ships as a single self-contained
bundle, so nothing is pulled from an external registry.

## Prerequisites

- A console host with Docker Engine and Docker Compose v2.
- One or more Linux hosts for the database that meet the [system requirements](/get-started/enterprise/requirements).
- SSH access from the console host to the database hosts.
- A TimescaleDB Enterprise console bundle from {C.COMPANY}.

## Install and sign in

<NumberedList>
  <NumberedItem title="Download and verify the bundle">
    Using the signed URLs provided by the {C.COMPANY} team, download the bundle and its checksum, then verify it:

    ```sh
    curl -L -o onprem-bundle-<VERSION>.tar.gz "${BUNDLE_URL}"
    curl -L -o onprem-bundle-<VERSION>.tar.gz.sha256 "${CHECKSUM_URL}"
    sha256sum -c onprem-bundle-<VERSION>.tar.gz.sha256
    ```
  </NumberedItem>
  <NumberedItem title="Extract the bundle and load the image">
    ```sh
    mkdir tsdb-console
    tar -C tsdb-console -xzf onprem-bundle-<VERSION>.tar.gz
    cd tsdb-console
    docker load -i images/app.tar
    ```
  </NumberedItem>
  <NumberedItem title="Configure the environment">
    Copy the template and set the required secrets. The stack does not start without them:

    ```sh
    cp .env.example .env
    ```

    In the `.env` file, set an admin token for signing in and passwords for the monitoring components, generating a strong random value for each. You can also set the console's public address to serve it over TLS.
  </NumberedItem>
  <NumberedItem title="Start the console">
    ```sh
    docker compose up -d
    ```
  </NumberedItem>
  <NumberedItem title="Sign in">
    Open the console in your browser on port `8080` and sign in with the admin token you set.
  </NumberedItem>
</NumberedList>

<Callout variant="note">
The console uses a single admin token. Restrict access to it, for example by placing the console behind a VPN or bastion host.
</Callout>

Next, [register your infrastructure hosts](/get-started/enterprise/register-hosts).
