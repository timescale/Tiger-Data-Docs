<TabItem label="Source">

You can install {C.TIMESCALE_DB} on any local system from source.

To install {C.TIMESCALE_DB} from source, you need:

- **{C.PG}**: Install a [supported version of {C.PG}](https://www.postgresql.org/download/). We recommend not using {C.TIMESCALE_DB} with {C.PG} 17.1, 16.5, 15.9, 14.14, 13.17, or 12.21. These minor versions [introduced a breaking binary interface change](https://www.postgresql.org/about/news/postgresql-172-166-1510-1415-1318-and-1222-released-2965/) that was reverted in subsequent releases. Build with {C.PG} 17.2, 16.6, or higher.

- **Build tools**:
  - [CMake 3.11 or later](https://cmake.org/download/)
  - C language compiler (`gcc` or `clang`). On Windows, Visual Studio 2015 or later works instead, ensure you install the CMake and Git components.

<TestPlan>
target: self-hosted
machine: bare
os: debian
1. fork the service
2. run command: `sudo apt install gnupg postgresql-common apt-transport-https lsb-release wget`
3. answer `Continue? [Y/n]` with `Y`
4. run command: `sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh`
5. answer `Press Enter to continue, or Ctrl-C to abort.` with `<Enter>`
6. run command: `echo "deb https://packagecloud.io/timescale/timescaledb/debian/ $(lsb_release -c -s) main" | sudo tee /etc/apt/sources.list.d/timescaledb.list`
7. run command: `wget --quiet -O - https://packagecloud.io/timescale/timescaledb/gpgkey | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/timescaledb.gpg`
8. run command: `sudo apt update`
9. run command: `sudo apt install timescaledb-2-postgresql-18 postgresql-client-18`
10. answer `Continue? [Y/n]` with `Y`
11. run command: `sudo timescaledb-tune`
12. answer `Is this correct? [(y)es/(n)o]:` with `y`
13. answer `Is this okay? [(y)es/(n)o]:` with `y`
14. answer `Tune memory/parallelism/WAL and other settings? [(y)es/(n)o]:` with `y`
15. answer `Is this okay? [(y)es/(s)kip/(q)uit]:` with `y` each time
16. run command: `sudo systemctl restart postgresql`
17. run command: `sudo -u postgres psql`
18. answer `postgres=#` with `\password postgres`
19. answer `Enter new password for user "postgres":` with `<PASSWORD>`
20. answer `Enter it again:` with `<PASSWORD>`
21. answer `postgres=#` with `\q`
22. run command: `psql -d "postgres://postgres:<PASSWORD>@localhost:5432/postgres"`
23. answer `postgres=#` with `CREATE EXTENSION IF NOT EXISTS timescaledb;`
24. answer `postgres=#` with `\dx`
25. answer `postgres=#` with `\q`
26. expect rows: `SELECT 1 FROM pg_extension WHERE extname = 'timescaledb'`
</TestPlan>
