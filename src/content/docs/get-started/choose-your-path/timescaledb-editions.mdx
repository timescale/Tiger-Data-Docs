- {C.TDB_APACHE}
- {C.TDB_COMMUNITY}

<PrivacyPolicy />

## Check your installed edition

If you are already running {C.TIMESCALE_DB}, check your edition with this command:

```sql
SHOW timescaledb.license;
```

This returns either `timescale` ({C.TDB_COMMUNITY} features enabled, the default) or `apache` (Apache 2-only mode).

For more detail, query `pg_settings`:

```sql
SELECT name, setting, source, sourcefile, sourceline
FROM pg_settings
WHERE name = 'timescaledb.license';
```

This is more informative because it tells you:

- `setting`: the current value, `timescale` or `apache`.
- `source`: where it was set, such as the default, a configuration file, or the session.
- `sourcefile` and `sourceline`: which configuration file and line it came from, if applicable.

## {C.TDB_APACHE}

{C.TDB_APACHE} is available under the [Apache 2.0 license](https://github.com/timescale/timescaledb/blob/master/LICENSE-APACHE). This is a classic open source license,
meaning that it is completely unrestricted - anyone can take this code and offer it as a service.

You can install {C.TDB_APACHE} on your own on-premises or cloud
infrastructure and run it for free.

You can sell {C.TDB_APACHE} as a service, even if you're not the
main contributor.

You can modify the {C.TDB_APACHE} source code and run it for
production use.

## {C.TDB_COMMUNITY}

{C.TDB_COMMUNITY} is the advanced, best, and most feature complete
version of {C.TIMESCALE_DB}, available under the terms of the
[{C.COMPANY} License (TSL)](https://github.com/timescale/timescaledb/blob/master/tsl/LICENSE-TIMESCALE).

For more information about the {C.COMPANY} license, see [this blog post](https://www.tigerdata.com/blog/how-we-are-building-a-self-sustaining-open-source-business-in-the-cloud-era).

Many of the most recent features of {C.TIMESCALE_DB} are only available in
{C.TDB_COMMUNITY}.

You can install {C.TDB_COMMUNITY} in your own on-premises or cloud
infrastructure and run it for free. {C.TDB_COMMUNITY} is completely
free if you manage your own service.

You cannot sell {C.TDB_COMMUNITY} as a service, even if you are the
main contributor.

You can modify the {C.TDB_COMMUNITY} source code and run it for
production use. Developers using {C.TDB_COMMUNITY} have the "right
to repair" and make modifications to the source code and run it in their own
on-premises or cloud infrastructure. However, you cannot make modifications to
the {C.TDB_COMMUNITY} source code and offer it as a service.

You can access a hosted version of {C.TDB_COMMUNITY} through
[{C.CLOUD_LONG}](/get-started/quickstart/create-service), a cloud-native platform for time-series and real-time analytics.
