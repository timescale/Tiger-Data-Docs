## Overview

Access and analyze service logs from your Managed Service for TimescaleDB (MST) instance to troubleshoot issues, monitor database activity, and audit operations. This guide covers the various methods for viewing and downloading logs.

## Prerequisites

- An active MST service instance
- Access to the MST console with appropriate permissions
- (Optional) CLI tools for programmatic log access

## Troubleshooting

Common issues when accessing or analyzing logs.

- **Logs not appearing**: Check that logging is enabled and verify permissions
- **Incomplete log entries**: Review log rotation settings and retention periods
- **Cannot download logs**: Verify browser permissions or CLI authentication
- **Log search not returning results**: Adjust time range or check filter syntax
