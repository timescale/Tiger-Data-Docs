## Overview

Export metrics from your Managed Service for TimescaleDB (MST) instance to Prometheus for comprehensive monitoring and alerting. The Prometheus endpoint provides access to key database metrics including CPU, memory, storage usage, and query performance statistics.

## Prerequisites

- An active MST service instance
- A running Prometheus server (v2.x or later recommended)
- Network access from Prometheus to your MST service endpoint
- Basic familiarity with PromQL (Prometheus Query Language)

## Available metrics

Overview of the metrics exposed by the MST Prometheus endpoint.

### Database performance metrics

- Query execution times and throughput
- Connection pool statistics
- Cache hit ratios
- Replication lag (for replicated instances)

### Resource utilization metrics

- CPU usage
- Memory consumption
- Storage utilization
- I/O statistics

### TimescaleDB-specific metrics

- Hypertable chunk information
- Compression statistics
- Continuous aggregate status

## Troubleshooting

Common issues and solutions when setting up Prometheus monitoring.

- **Connection refused errors**: Verify network connectivity and firewall rules
- **Authentication failures**: Check that credentials are correctly configured
- **Missing metrics**: Ensure the endpoint is enabled and the scrape configuration is correct
- **High cardinality warnings**: Review label usage and consider metric filtering
