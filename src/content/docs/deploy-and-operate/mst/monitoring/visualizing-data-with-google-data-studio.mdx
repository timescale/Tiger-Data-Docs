## Overview

Connect Google Looker Studio (formerly Google Data Studio) to your Managed Service for TimescaleDB (MST) instance to create interactive reports and dashboards. Looker Studio's native PostgreSQL connector enables direct visualization of your time-series data without data replication.

## Prerequisites

- An active MST service instance
- A Google account with access to Looker Studio
- MST connection credentials (host, port, database, username, password)
- Network configuration allowing Looker Studio to connect to your MST instance

```sql
  SUM(value) as total_value
FROM metrics

GROUP BY 1, 2
ORDER BY 1
```

## Troubleshooting

Common issues and solutions when using Looker Studio with MST.

- **Connection timeout**: Verify network configuration and firewall rules allow Looker Studio IPs
- **Authentication failed**: Check database credentials and user permissions
- **Query timeout**: Simplify complex queries or add appropriate indexes
- **SSL connection errors**: Verify SSL configuration and certificate format (PKCS-8 required for client keys)
- **No data displayed**: Check date ranges and query filters

## Limitations

Important limitations to be aware of when using Looker Studio with MST.

- Queries may timeout after 3-5 minutes for complex operations
- Private IP connections to Cloud SQL-based instances are not supported
- Real-time data refresh is limited compared to dedicated BI tools
