## Overview

Tiger Cloud high availability (HA) ensures your database remains operational with minimal downtime by automatically detecting failures and promoting standby instances. This guide covers HA architecture, configuration options, and best practices for maintaining continuous database operations.

## Prerequisites

- A Tiger Cloud database instance
- Understanding of your uptime requirements and acceptable downtime
- Network configuration that supports multi-zone deployments
- Sufficient compute and storage quotas for standby instances

## Best practices

- Place standby instances in different availability zones from the primary
- Place read replicas in a third zone for additional reliability
- Test failover procedures at least quarterly
- Configure connection pooling to handle failover gracefully
- Monitor replication lag and set alerts for synchronization issues
- Document failover procedures for manual intervention scenarios
- Maintain clear documentation of your HA configuration
