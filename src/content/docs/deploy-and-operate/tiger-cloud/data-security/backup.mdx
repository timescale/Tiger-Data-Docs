## Overview

Tiger Cloud provides automated backup capabilities to protect your data against hardware failures, accidental deletions, and disasters. This guide covers backup types, configuration options, and best practices for ensuring your data is always recoverable.

## Prerequisites

- An active Tiger Cloud database instance
- Appropriate permissions to configure backup settings
- Understanding of your Recovery Point Objective (RPO) and Recovery Time Objective (RTO) requirements

## Best practices

- Follow the 3-2-1 rule: three copies of data, two different storage types, one offsite
- Define clear RPO and RTO objectives before configuring backups
- Regularly test backup restores in a separate environment
- Monitor backup job status and set up alerts for failures
- Review backup configurations quarterly as your data grows
