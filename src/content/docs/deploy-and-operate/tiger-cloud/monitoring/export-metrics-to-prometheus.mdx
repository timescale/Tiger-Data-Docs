## Overview

This guide explains how to export metrics from your Tiger Cloud services to Prometheus for monitoring, visualization, and alerting. Prometheus integration enables you to use industry-standard tooling like Grafana for dashboards and Alertmanager for sophisticated alerting workflows.

## Prerequisites

- An active Tiger Cloud service
- A running Prometheus instance
- Network connectivity between Prometheus and Tiger Cloud
- Access to the Tiger Cloud Console

## Available metrics

Reference of metrics exposed by the Tiger Cloud Prometheus endpoint.

### Connection metrics

- Active connections
- Connection pool utilization
- Connection wait times

### Query performance metrics

- Query throughput (queries per second)
- Query latency histograms
- Query errors and timeouts

### Resource metrics

- CPU utilization
- Memory usage
- Disk I/O operations
- Storage capacity

### Replication metrics

- Replication lag
- Replication status
- WAL metrics

### Cache metrics

- Buffer cache hit ratio
- Shared buffer utilization

## Troubleshooting

Common issues and solutions:

- Prometheus unable to scrape metrics endpoint
- Authentication failures
- Missing or incomplete metrics
- High cardinality issues with large numbers of databases
- Scrape timeouts

## Best practices

- Use appropriate scrape intervals (15-60 seconds for most metrics)
- Implement metric relabeling to reduce cardinality if needed
- Secure the metrics endpoint in production environments
- Set up recording rules for frequently-used queries
- Use predictive alerting (e.g., `predict_linear`) for capacity planning
