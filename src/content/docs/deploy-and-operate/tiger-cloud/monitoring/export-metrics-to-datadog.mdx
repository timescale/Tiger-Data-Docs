## Overview

This guide explains how to export database metrics from your Tiger Cloud services to DataDog for unified monitoring and observability. DataDog integration provides comprehensive dashboards, intelligent alerting, and the ability to correlate database performance with your application metrics and traces.

## Prerequisites

- An active Tiger Cloud service
- A DataDog account with API access
- DataDog API key and (optionally) Application key
- Access to the Tiger Cloud Console

## Available metrics

Reference of metrics exported to DataDog.

### Connection metrics

- `tiger.connections.active`
- `tiger.connections.idle`
- `tiger.connections.waiting`
- `tiger.connections.total`

### Query metrics

- `tiger.queries.count`
- `tiger.queries.latency`
- `tiger.queries.errors`
- `tiger.queries.rows_returned`

### Resource metrics

- `tiger.cpu.usage`
- `tiger.memory.usage`
- `tiger.storage.used`
- `tiger.storage.available`

### Replication metrics

- `tiger.replication.lag`
- `tiger.replication.status`

## Troubleshooting

Common issues and solutions:

- Metrics not appearing in DataDog
- API key authentication errors
- Incorrect DataDog site configuration
- Missing tags on metrics
- Delayed metric delivery

## Best practices

- Use consistent tagging across all Tiger Cloud services
- Enable Database Monitoring for query-level visibility
- Set up monitors based on baseline performance
- Correlate database metrics with application metrics
- Use DataDog's anomaly detection for dynamic thresholds
