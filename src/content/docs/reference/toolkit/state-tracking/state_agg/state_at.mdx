Determine the state at a given time from a state aggregate. Returns `NULL` for a time before the first reading. For
a time at or after the last reading, returns the last state.

## Samples

Create a state aggregate and determine the state at a particular time.

```sql
SELECT state_at(
  (SELECT state_agg(ts, state) FROM states_test),
  '2020-01-01 00:00:05+00'
);
```

Returns:

```
state_at
----------
START
```

## Arguments

The syntax is:

```sql
state_at(
  agg StateAgg,
  point TIMESTAMPTZ
) RETURNS TEXT

state_at_int(
  agg StateAgg,
  point TIMESTAMPTZ
) RETURNS BIGINT
```

| Name | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| agg | StateAgg | - | ✔ | A state aggregate created with [`state_agg`](/reference/toolkit/state-tracking/state_agg/state_agg) |
| point | TIMESTAMPTZ | - | ✔ | The time to get the state at |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| state\_at \| state\_at\_int | TEXT \| BIGINT | The state at the given time. |
