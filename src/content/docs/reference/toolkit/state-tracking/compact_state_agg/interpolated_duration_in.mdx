Calculate the total duration in the given state. Unlike [`duration_in`](/reference/toolkit/state-tracking/compact_state_agg/duration_in), you can use this function across
multiple state aggregates that cover different time buckets. Any missing values at the start of a time bucket are
interpolated from the previous state aggregate.

`start` must not be after the first timestamp in `agg`, and `start + interval` must not be before the last timestamp
in `agg`. Otherwise the function raises an error.

## Samples

Create a test table that tracks when a system switches between `starting`, `running`, and `error` states. Query the
table for the time spent in the `running` state. To perform the interpolation, the `LAG` function is used to get the
previous state aggregate.

If you prefer to see the result in seconds, [`EXTRACT`](https://www.postgresql.org/docs/current/functions-datetime.html#FUNCTIONS-DATETIME-EXTRACT) the epoch from the returned result.

```sql
SET timezone TO 'UTC';
CREATE TABLE states(time TIMESTAMPTZ, state TEXT);
INSERT INTO states VALUES
  ('1-1-2020 10:00', 'starting'),
  ('1-1-2020 10:30', 'running'),
  ('1-3-2020 16:00', 'error'),
  ('1-3-2020 18:30', 'starting'),
  ('1-3-2020 19:30', 'running'),
  ('1-5-2020 12:00', 'stopping');

SELECT
  time,
  toolkit_experimental.interpolated_duration_in(
    agg,
    'running',
    time,
    '1 day',
    LAG(agg) OVER (ORDER BY time)
) FROM (
  SELECT
    time_bucket('1 day', time) as time,
    toolkit_experimental.compact_state_agg(time, state) as agg
  FROM
    states
  GROUP BY time_bucket('1 day', time)
) s;
```

Returns:

```
time                    | interpolated_duration_in
------------------------+--------------------------
2020-01-01 00:00:00+00  | 13:30:00
2020-01-03 00:00:00+00  | 20:30:00
2020-01-05 00:00:00+00  | 12:00:00
```

## Arguments

The syntax is:

```sql
interpolated_duration_in(
  agg CompactStateAgg,
  state {TEXT | BIGINT},
  start TIMESTAMPTZ,
  interval INTERVAL,
  prev CompactStateAgg
) RETURNS INTERVAL
```

| Name | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| agg | CompactStateAgg | - | ✔ | A state aggregate created with [`compact_state_agg`](/reference/toolkit/state-tracking/compact_state_agg/compact_state_agg). Must not be `NULL` |
| state | TEXT \| BIGINT | - | ✔ | The state to query |
| start | TIMESTAMPTZ | - | ✔ | The start of the interval to be calculated |
| interval | INTERVAL | - | ✔ | The length of the interval to be calculated |
| prev | CompactStateAgg | - | ✔ | The state aggregate from the prior interval, used to interpolate the value at `start`. Pass `NULL` if there is none; nothing before the first timestamp in `agg` is then counted. `start` must be at or after the last timestamp in `prev` |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| interpolated\_duration\_in | INTERVAL | The total time spent in the queried state. Displayed as `days`, `hh:mm:ss`, or a combination of the two. |
