Aggregate data into a space-saving aggregate object, which stores frequency information in an intermediate form. You can
then use any of the accessors in this group to return estimated frequencies or the most common elements.

## Samples

Create a space-saving aggregate over a field `ZIP` in a `HomeSales` table, with a frequency cutoff of 5%:

```sql
SELECT toolkit_experimental.freq_agg(0.05, ZIP) FROM HomeSales;
```

## Arguments

The syntax is:

```sql
freq_agg(
  frequency DOUBLE PRECISION,
  value BIGINT | TEXT
) RETURNS SpaceSavingAggregate
```

| Name | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| `frequency` | DOUBLE PRECISION | - | ✔ | `topn()` returns up to `n` of the values whose maximum estimated frequency is at least `frequency`. Must be greater than `0.0` and less than `1.0`. The aggregate also stores values below this cutoff, up to `floor(1 / frequency) + 1` values in total. |
| `value` | BIGINT \| TEXT | - | ✔ | The column to store frequencies for |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| freq\_agg | SpaceSavingAggregate | An object storing the most common elements of the given table and their estimated frequency. The exact type is `SpaceSavingBigIntAggregate` or `SpaceSavingTextAggregate` depending on the input type. You can pass this object to any of the accessor functions to get a final result. |
