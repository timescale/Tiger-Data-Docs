The `saturating_add` function adds two numbers, saturating at -2,147,483,648 and 2,147,483,647 instead of overflowing.

## Arguments

The syntax is:

```sql
saturating_add(
  x INT,
  y INT
) RETURNS INT
```

| Name | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| x | INT | - | ✔ | An integer to add to `y` |
| y | INT | - | ✔ | An integer to add to `x` |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| saturating\_add | INT | The result of `x + y`, saturating at the numeric bounds instead of overflowing. The numeric bounds are the upper and lower bounds of the 32-bit signed integers |
