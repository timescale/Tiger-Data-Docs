
| Name | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| candlestick | Candlestick | - | ✔ | Candlestick aggregate |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| open | DOUBLE PRECISION | The opening price |
