Downsample your data with the [ASAP smoothing algorithm](http://arxiv.org/pdf/1703.00983). This algorithm preserves the approximate shape and larger trends of the input data, while minimizing the local variance between points.

## Samples

This example uses a table called `metrics`, with columns for `date` and `reading`. The columns contain measurements that
have been accumulated over a large interval of time. This example takes that data and provides a smoothed representation
of 8 points, but that still shows any anomalous readings:

```sql
SET TIME ZONE 'UTC';
CREATE TABLE metrics(date TIMESTAMPTZ, reading DOUBLE PRECISION);
INSERT INTO metrics
SELECT
    '2020-1-1 UTC'::timestamptz + make_interval(hours=>foo),
    (5 + 5 * sin(foo / 12.0 * PI()))
    FROM generate_series(1,168) foo;

SELECT * FROM unnest(
  (SELECT asap_smooth(date, reading, 8)
    FROM metrics)
);
```

## Arguments

The syntax is:

```sql
asap_smooth(
  ts TIMESTAMPTZ,
  value DOUBLE PRECISION,
  resolution INT
) RETURNS Timevector
```

| Name | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| ts | TIMESTAMPTZ | - | ✔ | Timestamps for each data point. Rows where `ts` or `value` is `NULL` are skipped. |
| value | DOUBLE PRECISION | - | ✔ | The value at each timestamp. Rows where `ts` or `value` is `NULL` are skipped. |
| resolution | INT | - | ✔ | The approximate number of points to return. Must be greater than 0. |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| asap\_smooth | Timevector | A timevector of smoothed values. Each point takes its timestamp from an input point. Unpack it with `unnest`. For more information, see the documentation on [timevectors](/reference/toolkit/timevector). |
