## Function categories

- **candlestick_agg** - Financial candlestick aggregations
- **counter_agg** - Counter and gauge aggregations
- **gauge_agg** - Gauge metric aggregations
- **downsampling** - Data downsampling functions
- **percentile-approximation** - Approximate percentile calculations
- **state-tracking** - State transition tracking
- **statistical-analysis** - Statistical functions
- **time_weight** - Time-weighted calculations
