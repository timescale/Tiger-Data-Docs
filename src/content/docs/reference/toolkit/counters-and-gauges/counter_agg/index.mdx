Analyze data whose values are designed to monotonically increase, and where any decreases are treated as resets. The
`counter_agg` functions simplify this task, which can be difficult to do in pure SQL.

If it's possible for your readings to decrease as well as increase, use [`gauge_agg`](/reference/toolkit/counters-and-gauges/gauge_agg) instead.

## Samples

### Roll up counter aggregates and calculate deltas

Create daily counter aggregates for a counter with id `bar`:

```sql
SELECT
    date_trunc('day', ts) AS dt,
    counter_agg(ts, val) AS counter_summary
FROM foo
WHERE id = 'bar'
GROUP BY date_trunc('day');
```

Roll up the daily aggregates to get a counter aggregate that covers all recorded timestamps:

```sql
WITH t AS (
    SELECT
        date_trunc('day', ts) AS dt,
        counter_agg(ts, val) AS counter_summary
    FROM foo
    WHERE id = 'bar'
    GROUP BY date_trunc('day')
)
SELECT rollup(counter_summary) AS full_cs
FROM t;
```

Calculate the delta, or the difference between the final and first values, from each daily counter aggregate. Also
calculate the fraction of the total delta that happens on each day:

```sql
WITH t AS (
    SELECT
        date_trunc('day', ts) AS dt,
        counter_agg(ts, val) AS counter_summary
    FROM foo
    WHERE id = 'bar'
    GROUP BY date_trunc('day')
), q AS (
    SELECT rollup(counter_summary) AS full_cs
    FROM t
)
SELECT
    dt,
    delta(counter_summary),
    delta(counter_summary) / (SELECT delta(full_cs) FROM q LIMIT 1) AS normalized
FROM t;
```

## Available functions

### Aggregate

- [`counter_agg()`](/reference/toolkit/counters-and-gauges/counter_agg/counter_agg): aggregate counter data into an intermediate form for further analysis

### Accessors

- [`corr()`](/reference/toolkit/counters-and-gauges/counter_agg/corr): calculate the correlation coefficient from a counter aggregate
- [`counter_zero_time()`](/reference/toolkit/counters-and-gauges/counter_agg/counter_zero_time): calculate the time when a counter value was zero
- [`delta()`](/reference/toolkit/counters-and-gauges/counter_agg/delta): calculate the change in a counter's value
- [`extrapolated_delta()`](/reference/toolkit/counters-and-gauges/counter_agg/extrapolated_delta): estimate the total change in a counter over a time period
- [`extrapolated_rate()`](/reference/toolkit/counters-and-gauges/counter_agg/extrapolated_rate): estimate the average rate of change over a time period
- [`first_time()`](/reference/toolkit/counters-and-gauges/counter_agg/first_time): get the timestamp of the first point in a counter aggregate
- [`first_val()`](/reference/toolkit/counters-and-gauges/counter_agg/first_val): get the value of the first point in a counter aggregate
- [`idelta_left()`](/reference/toolkit/counters-and-gauges/counter_agg/idelta_left): calculate the instantaneous change at the left boundary
- [`idelta_right()`](/reference/toolkit/counters-and-gauges/counter_agg/idelta_right): calculate the instantaneous change at the right boundary
- [`intercept()`](/reference/toolkit/counters-and-gauges/counter_agg/intercept): calculate the y-intercept from a counter aggregate
- [`interpolated_delta()`](/reference/toolkit/counters-and-gauges/counter_agg/interpolated_delta): calculate the change over a specific time range with interpolation
- [`interpolated_rate()`](/reference/toolkit/counters-and-gauges/counter_agg/interpolated_rate): calculate the rate of change over a specific time range with interpolation
- [`irate_left()`](/reference/toolkit/counters-and-gauges/counter_agg/irate_left): calculate the instantaneous rate at the left boundary
- [`irate_right()`](/reference/toolkit/counters-and-gauges/counter_agg/irate_right): calculate the instantaneous rate at the right boundary
- [`last_time()`](/reference/toolkit/counters-and-gauges/counter_agg/last_time): get the timestamp of the last point in a counter aggregate
- [`last_val()`](/reference/toolkit/counters-and-gauges/counter_agg/last_val): get the value of the last point in a counter aggregate
- [`num_changes()`](/reference/toolkit/counters-and-gauges/counter_agg/num_changes): get the number of times the counter changed value
- [`num_elements()`](/reference/toolkit/counters-and-gauges/counter_agg/num_elements): get the number of points in a counter aggregate
- [`num_resets()`](/reference/toolkit/counters-and-gauges/counter_agg/num_resets): get the number of counter resets
- [`rate()`](/reference/toolkit/counters-and-gauges/counter_agg/rate): calculate the average rate of change
- [`slope()`](/reference/toolkit/counters-and-gauges/counter_agg/slope): calculate the slope from a counter aggregate
- [`time_delta()`](/reference/toolkit/counters-and-gauges/counter_agg/time_delta): calculate the elapsed time in a counter aggregate

### Rollup

- [`rollup()`](/reference/toolkit/counters-and-gauges/counter_agg/rollup): combine multiple counter aggregates

### Mutator

- [`with_bounds()`](/reference/toolkit/counters-and-gauges/counter_agg/with_bounds): add time bounds to a counter aggregate for extrapolation
