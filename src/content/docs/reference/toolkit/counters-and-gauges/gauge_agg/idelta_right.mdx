Calculate the instantaneous change at the right, or latest, edge of a gauge aggregate. This is equal to the last value
minus the second-last value.

## Samples

Get the instantaneous change at the end of each 15-minute gauge aggregate.

```sql
SELECT
    id,
    bucket,
    idelta_right(summary)
FROM (
    SELECT
        id,
        time_bucket('15 min'::interval, ts) AS bucket,
        gauge_agg(ts, val) AS summary
    FROM foo
    GROUP BY id, time_bucket('15 min'::interval, ts)
) t
```

## Arguments

The syntax is:

```sql
idelta_right(
  summary GaugeSummary
) RETURNS DOUBLE PRECISION
```

| Name | Type | Default | Required | Description |
| --- | --- | --- | --- | --- |
| `summary` | `GaugeSummary` | - | ✔ | A gauge aggregate created using [`gauge_agg`](/reference/toolkit/counters-and-gauges/gauge_agg/gauge_agg) |

## Returns

| Column | Type | Description |
|--------|------|-------------|
| idelta\_right | DOUBLE PRECISION | The instantaneous delta at the right, or latest, edge of the gauge aggregate |
