title: "Hyperfunctions"
description: "Reference list of all available TimescaleDB hyperfunctions"
---
Tiger Cloud includes all hyperfunctions by default, while self-hosted TimescaleDB includes a subset of them. For additional hyperfunctions, install the [TimescaleDB Toolkit](/deploy/self-hosted/install-and-update/install-toolkit) extension.

Available hyperfunctions

Hyperfunctions are organized by their analytical purpose. Functions marked with ✓ in the `Toolkit` column require an installation of TimescaleDB Toolkit for self-hosted deployments. Functions marked with ✓ in the `Experimental` column are still under development.

Experimental hyperfunctions are still under active development and subject to change. When you upgrade to a new version of TimescaleDB Toolkit, experimental features might have changed or been removed. Be prepared to update your code if you use experimental hyperfunctions.
