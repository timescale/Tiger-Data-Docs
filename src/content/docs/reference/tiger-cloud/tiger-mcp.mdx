{C.MCP_LONG} gives your AI assistant access to {C.CLOUD_LONG} so you can manage {C.SERVICE_SHORT}s and query your data using natural language. It is built into the {C.CLI_LONG} binary and mirrors {C.CLI_SHORT} functionality.

To install and configure {C.MCP_LONG} for your AI assistant, see [Integrate Tiger Cloud with your AI assistant](/get-started/quickstart/mcp-cli). This page is the reference for the {C.MCP_SHORT} tools and the `tiger mcp` commands that control them.
