{C.MCP_LONG} gives your AI agent access to {C.CLOUD_LONG} so you can manage {C.SERVICE_SHORT}s and query your data in natural language. It is built into the {C.CLI_LONG} binary.

To install and configure {C.MCP_LONG} for your AI agent, see [Integrate Tiger Cloud with your AI agent](/get-started/quickstart/mcp-cli). This page is the reference for the {C.MCP_SHORT} tools your agent can call.

## Manage the {C.MCP_SHORT} server

To install, list, inspect, and start {C.MCP_LONG}, use the `tiger mcp` commands, documented in the [{C.CLI_LONG} reference](/reference/tiger-cloud/tiger-cli#mcp). Global flags that apply when running {C.MCP_SHORT} are in the [configuration parameters](/reference/tiger-cloud/tiger-cli#configuration-parameters).

{C.MCP_LONG} ships inside the open-source {C.CLI_LONG}. [File an issue in the repo](https://github.com/timescale/tiger-cli) to report bugs or request features and help shape the product.
