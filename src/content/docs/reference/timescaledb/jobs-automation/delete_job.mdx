Delete a {C.JOB} registered with the automation framework.
This works for {C.JOB}s as well as policies.

If the {C.JOB} is currently running, the process is terminated.

## Samples

Delete the {C.JOB} with the {C.JOB} id 1000:

```sql
SELECT delete_job(1000);
```

## Arguments

The syntax is:

```sql
SELECT delete_job(
    job_id = <job_id>
);
```

| Name | Type | Default | Required | Description |
|---|---|---|---|---|
| `job_id` | INTEGER | - | ✔ | TimescaleDB background {C.JOB} id |
