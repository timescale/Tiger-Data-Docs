Remove all policies from a {C.CAGG}. The removed {C.COLUMNSTORE} and
retention policies apply to the {C.CAGG}, *not* to the original
{C.HYPERTABLE}.

```sql
timescaledb_experimental.remove_all_policies(
     relation REGCLASS,
     if_exists BOOL = false
) RETURNS BOOL
```

## Samples

Remove all policies from a {C.CAGG} named
`example_continuous_aggregate`. This includes refresh policies, {C.COLUMNSTORE}
policies, and data retention policies. It doesn't include custom jobs:

```sql
SELECT timescaledb_experimental.remove_all_policies('example_continuous_aggregate');
```

## Arguments

The syntax is:

```sql
SELECT timescaledb_experimental.remove_all_policies(
    relation = '<view_name>',
    if_exists = true | false
);
```

| Name | Type | Default | Required | Description |
|-|-|-|-|-|
| `relation` | `REGCLASS` | - | ✔ | The {C.CAGG} to remove all policies from |
| `if_exists` | `BOOL` | false | - | When true, prints a warning instead of erroring if any policies are missing. |

## Returns

Returns `true` if successful.
