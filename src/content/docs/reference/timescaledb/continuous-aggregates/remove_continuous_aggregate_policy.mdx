Remove all refresh policies from a {C.CAGG}.

```sql
remove_continuous_aggregate_policy(
    continuous_aggregate REGCLASS,
    if_exists BOOL = NULL
) RETURNS VOID
```

<Callout variant="note">
  To view the existing {C.CAGG} policies, see the [policies informational view](/reference/timescaledb/informational-views/policies).
</Callout>

## Samples

Remove all refresh policies from the `cpu_view` {C.CAGG}:

```sql
SELECT remove_continuous_aggregate_policy('cpu_view');
```

## Arguments

The syntax is:

```sql
SELECT remove_continuous_aggregate_policy(
    continuous_aggregate = '<view_name>',
    if_exists = true | false
);
```

| Name | Type | Default | Required | Description |
|-|-|-|-|-|
| `continuous_aggregate` | `REGCLASS` | - | ✔ | Name of the {C.CAGG} the policies should be removed from |
| `if_exists` (formerly `if_not_exists`) | `BOOL` | false | - | When true, prints a warning instead of erroring if the policy doesn't exist. Renamed in {C.TIMESCALE_DB} 2.8. |
