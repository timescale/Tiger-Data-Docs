Separate a {C.CHUNK} from a [{C.HYPERTABLE}][hypertables-section].

![Hypertable structure][hypertable-structure]

The {C.CHUNK} becomes a standalone {C.HYPERTABLE} with the same name and schema. All existing constraints and
indexes on the {C.CHUNK} are preserved after detaching. Foreign keys are dropped.

In this initial release, you cannot detach a {C.CHUNK} that has been [converted to the {C.COLUMNSTORE}][setup-hypercore].

## Samples

Detach a {C.CHUNK} from a {C.HYPERTABLE}:

```sql
CALL detach_chunk('_timescaledb_internal._hyper_1_2_chunk');
```

## Arguments

The syntax is:

```sql
CALL detach_chunk(
    chunk = '<chunk_name>'
);
```

|Name|Type| Description                  |
|---|---|------------------------------|
| `chunk` | REGCLASS | Name of the {C.CHUNK} to detach. |
