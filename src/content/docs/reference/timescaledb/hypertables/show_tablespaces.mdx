Show the tablespaces attached to a {C.HYPERTABLE}.

## Samples

```sql
SELECT * FROM show_tablespaces('conditions');

 show_tablespaces
------------------
 disk1
 disk2
```

## Arguments

The syntax is:

```sql
SELECT show_tablespaces(
    hypertable = '<hypertable_name>'
);
```

|Name|Type| Default | Required | Description|
|---|---|---|---|---|
| `hypertable` | REGCLASS | - | ✔ | {C.HYPERTABLE} to show attached tablespaces for.|

## Returns

| Column | Type | Description |
|-|-|-|
| show\_tablespaces | NAME | The name of each tablespace attached to the {C.HYPERTABLE}. Returns one row per attached tablespace. |

The function returns a set of tablespace names. If no tablespaces are attached to the {C.HYPERTABLE}, the function returns an empty result set.
