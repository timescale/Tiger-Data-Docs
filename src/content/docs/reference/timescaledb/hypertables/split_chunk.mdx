Split a large {C.CHUNK} at a specific point in time. If you do not specify the timestamp to split at, the {C.CHUNK}
is split equally.

## Samples

- Split a chunk at a specific time:

  ```sql
  CALL split_chunk('chunk_1', split_at => '2025-03-01 00:00');
  ```

- Split a {C.CHUNK} in two:

  For example, If the {C.CHUNK} duration is, 24 hours, the following command splits `chunk_1` into
  two {C.CHUNK}s of 12 hours each.

  ```sql
  CALL split_chunk('chunk_1');
  ```

## Arguments

The syntax is:

```sql
CALL split_chunk(
    chunk = '<chunk_name>',
    split_at = <split_point>
);
```

|Name|Type| Default | Required | Description                      |
|---|---|---|---|----------------------------------|
| `chunk` | REGCLASS | - | ✔ | Name of the {C.CHUNK} to split.      |
| `split_at` | "any" | `NULL` | ✖ | The point at which to split the {C.CHUNK}. Accepts TIMESTAMPTZ for time-based dimensions or INTEGER for integer-based dimensions. If not specified, the {C.CHUNK} is split in half. |
