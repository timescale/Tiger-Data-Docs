Get the approximate total disk space used by a {C.HYPERTABLE} or {C.CAGG},
that is, the sum of the size for the table itself including {C.CHUNK}s,
any indexes on the table, and any toast tables. The size is reported
in bytes. This is equivalent to computing the sum of `total_bytes`
column from the output of `hypertable_approximate_detailed_size` function.

When a {C.CAGG} name is provided, the function
transparently looks up the backing {C.HYPERTABLE} and returns its statistics
instead.

<Callout variant="note">
  This function relies on the per backend caching using the in-built
  {C.PG} storage manager layer to compute the approximate size
  cheaply. The PG cache invalidation clears off the cached size for a
  {C.CHUNK} when DML happens into it. That size cache is thus able to get
  the latest size in a matter of minutes. Also, due to the backend
  caching, any long running session will only fetch latest data for new
  or modified {C.CHUNK}s and can use the cached data (which is calculated
  afresh the first time around) effectively for older {C.CHUNK}s. Thus it
  is recommended to use a single connected {C.PG} backend session to
  compute the approximate sizes of {C.HYPERTABLE}s to get faster results.
</Callout>

For more information about using {C.HYPERTABLE}s, including {C.CHUNK} size partitioning,
see the [hypertable section](/build/data-management/understand-hypertables).

## Samples

Get the approximate size information for a {C.HYPERTABLE}.

```sql
SELECT * FROM hypertable_approximate_size('devices');
 hypertable_approximate_size
-----------------------------
                        8192
```

Get the approximate size information for all {C.HYPERTABLE}s.

```sql
SELECT hypertable_name, hypertable_approximate_size(format('%I.%I', hypertable_schema, hypertable_name)::regclass)
  FROM timescaledb_information.hypertables;
```

Get the approximate size information for a {C.CAGG}.

```sql
SELECT hypertable_approximate_size('device_stats_15m');

 hypertable_approximate_size
-----------------------------
                        8192
```

## Arguments

The syntax is:

```sql
SELECT hypertable_approximate_size('<hypertable_name>');
```

|Name|Type| Default | Required | Description|
|-|-|-|-|-|
|`hypertable`|REGCLASS| - | ✔ |Hypertable or continuous aggregate to show size of.|

## Returns

|Column|Type|Description|
|-|-|-|
|hypertable\_approximate\_size|BIGINT|Total approximate disk space used by the specified {C.HYPERTABLE}, including all indexes and TOAST data|

<Callout variant="note">
  `NULL` is returned if the function is executed on a non-{C.HYPERTABLE} relation.
</Callout>
