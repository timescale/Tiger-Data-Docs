Manually convert a specific {C.CHUNK} in the {C.HYPERTABLE} {C.ROWSTORE} to the {C.COLUMNSTORE}.

Although `convert_to_columnstore` gives you more fine-grained control, best practice is to use
[`add_columnstore_policy`](/reference/timescaledb/hypercore/add_columnstore_policy). You can also add {C.CHUNK}s to the {C.COLUMNSTORE} at a specific time
[running the job associated with your {C.COLUMNSTORE} policy](/reference/timescaledb/jobs-automation/run_job) manually.

To move a {C.CHUNK} from the {C.COLUMNSTORE} back to the {C.ROWSTORE}, use [`convert_to_rowstore`](/reference/timescaledb/hypercore/convert_to_rowstore).

## Samples

To convert a single {C.CHUNK} to {C.COLUMNSTORE}:

```sql
CALL convert_to_columnstore('_timescaledb_internal._hyper_1_2_chunk');
```

To convert a backlog of {C.CHUNK}s on an existing {C.HYPERTABLE}, list the {C.CHUNK}s with [show_chunks](/reference/timescaledb/hypertables/show_chunks) and call `convert_to_columnstore` on each one. {C.CHUNK}s are converted independently, so you can run multiple calls from separate sessions in parallel to speed up an initial migration:

```sql
-- Session 1
CALL convert_to_columnstore('_timescaledb_internal._hyper_1_2_chunk');

-- Session 2 (concurrent)
CALL convert_to_columnstore('_timescaledb_internal._hyper_1_3_chunk');
```

Each call takes an exclusive lock on the {C.CHUNK} it is converting, so concurrent writes or backfill to the same {C.CHUNK} will wait. For backfill workflows, pause the {C.COLUMNSTORE} policy first — see [convert_to_rowstore](/reference/timescaledb/hypercore/convert_to_rowstore).

## Arguments

The syntax is:

```sql
CALL convert_to_columnstore(
    chunk = '<chunk_name>',
    if_not_columnstore = true | false,
    recompress = true | false
);
```

| Name                 | Type | Default | Required | Description                                                                                                                                        |
|----------------------|--|---------|--|----------------------------------------------------------------------------------------------------------------------------------------------------|
| `chunk`         | REGCLASS | -       |✔| Name of the {C.CHUNK} to add to the {C.COLUMNSTORE}.                                                                                                      |
| `if_not_columnstore` | BOOLEAN | `true`  |✖| Set to `false` so this call fails with an error rather than a warning if `chunk` is already in the {C.COLUMNSTORE}.                                    |
| `recompress`         | BOOLEAN | `false` |✖| Set to `true` to recompress. In-memory recompression is attempted first; it falls back to internal decompress/compress. |
