Manually convert a specific {C.CHUNK} in the {C.HYPERTABLE} {C.COLUMNSTORE} to the {C.ROWSTORE}.

If you need to modify or add a lot of data to a {C.CHUNK} in the {C.COLUMNSTORE}, best practice is to stop
any [jobs][job] moving {C.CHUNK}s to the {C.COLUMNSTORE}, convert the {C.CHUNK} back to the {C.ROWSTORE}, then modify the
data. After the update, [convert the {C.CHUNK} to the {C.COLUMNSTORE}][convert_to_columnstore] and restart the jobs.
This workflow is especially useful if you need to backfill old data.

## Arguments

The syntax is:

```sql
CALL convert_to_rowstore(
    chunk = '<chunk_name>',
    if_columnstore = true | false
);
```

| Name | Type     | Default | Required | Description|
|--|----------|---------|----------|-|
|`chunk`| REGCLASS | -       | ✔        | Name of the {C.CHUNK} to be moved to the {C.ROWSTORE}. |
|`if_columnstore`| BOOLEAN  | `true`  | ✖        | Set to `false` so this call fails with an error rather than a warning if `chunk` is not in the {C.COLUMNSTORE} |
