You use the following Grand Unified Configuration (GUC) parameters to optimize the behavior of your {C.SERVICE_LONG}.

The namespace of each GUC is `timescaledb`.
To set a GUC you specify `<namespace>.<GUC name>`. For example:

```sql
SET timescaledb.enable_tiered_reads = true;
```
