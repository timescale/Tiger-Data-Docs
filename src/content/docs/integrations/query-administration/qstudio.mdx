title: "Integrate qStudio with Tiger Cloud"

---
[qStudio](https://www.timestored.com/qstudio/) is a modern free SQL editor that provides syntax highlighting, code-completion, excel export, charting, and much more. You can use it to run queries, browse tables, and create charts for your Tiger Cloud service. This page explains how to integrate qStudio with Tiger Cloud.

Prerequisites

To follow the steps on this page:

-   Create a target [Tiger Cloud service](/deploy-and-operate/tiger-cloud/get-started/create-services) with Real-time analytics enabled.
    
    You need [your connection details](/integrations/find-connection-details). This procedure also works for [self-hosted TimescaleDB](/deploy-and-operate/self-hosted/install-and-update/install-self-hosted).

-   [Download](https://www.timestored.com/qstudio/download) and install qStudio.

Connect qStudio to your service

To connect to Tiger Cloud:

1.  **Start qStudio**
2.  **Click `Server` > `Add Server`**
3.  **Configure the connection**
    
    -   For `Server Type`, select `Postgres`.
    -   For `Connect By`, select `Host`.
    -   For `Host`, `Port`, `Database`, `Username`, and `Password`, use your [connection details](/integrations/find-connection-details).
    
    ![qStudio integration](https://assets.timescale.com/docs/images/integrations-qstudio.png)
4.  **Click `Test`** qStudio indicates whether the connection works.
5.  **Click `Add`** The server is listed in the `Server Tree`.

You have successfully integrated qStudio with Tiger Cloud.
