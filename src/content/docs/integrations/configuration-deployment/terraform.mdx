[Terraform](https://developer.hashicorp.com/terraform) is an infrastructure-as-code tool that enables you to safely and predictably provision and manage infrastructure. This page explains how to configure Terraform to manage your Tiger Cloud service or self-hosted TimescaleDB.

Prerequisites

To follow the steps on this page:

-   Create a target [Tiger Cloud service](/deploy-and-operate/tiger-cloud/get-started/create-services) with Real-time analytics enabled.
    
    You need [your connection details](/integrations/find-connection-details). This procedure also works for [self-hosted TimescaleDB](/deploy-and-operate/self-hosted/install-and-update/install-self-hosted).

-   [Download and install](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli) Terraform.
