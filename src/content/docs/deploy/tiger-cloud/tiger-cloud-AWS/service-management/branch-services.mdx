A branch is a lightweight copy of a Fluid {C.SERVICE_SHORT}. It shares the primary {C.SERVICE_SHORT}'s storage and
stores only the data that changes after it is created, so it is ready in a minute or two whatever the data size,
and it costs a fraction of a fork. Branches are in public preview, on Fluid {C.SERVICE_SHORT}s only.

A branch is a complete running {C.SERVICE_SHORT} with its own compute. Branch a production {C.SERVICE_SHORT} to give
each developer or agent an isolated copy of real data, or to test every pull request against production data in CI.
A branch of a production {C.SERVICE_SHORT} is writable. Changes on a branch never reach the primary.

Branches are built to be short-lived: create one, use it, delete it. For a long-lived, fully independent copy with
high availability, backups, and point-in-time recovery, [fork the {C.SERVICE_SHORT}](../service-management/fork-services)
instead.

## What a branch includes

A branch runs on its own compute, with its own IOPS setting. You choose and change both the same way as for a
{C.SERVICE_SHORT}: see [Manually change compute resources](../service-management/change-resources) and
[Manage storage and tiering](/build/data-management/storage/manage-storage#configure-iops). It starts with the
primary {C.SERVICE_SHORT}'s data as it is at creation, or as it was at a point in time within the last 30 days.

A branch has no high-availability replicas, backups, or point-in-time recovery, and no environment setting: it is
always treated as a development {C.SERVICE_SHORT}. It has its own connection string, shown on the branch's page in
{C.CONSOLE}.

## Create a branch

<NumberedList>

<NumberedItem title="Open the Branching page">

In {C.CONSOLE}, select your Fluid {C.SERVICE_SHORT}, then click `Operations` > `Branching` > `Create a branch`.

</NumberedItem>

<NumberedItem title="Name the branch and choose the branch point">

Enter a name. Under `Branch point`, select `Use current data`, or `Point in time` and pick a date and time within
the last 30 days.

</NumberedItem>

<NumberedItem title="Click `Create branch`">

The branch is ready in a minute or two and appears in the list.

</NumberedItem>

</NumberedList>

## Manage branches

`Operations` > `Branching` lists the {C.SERVICE_SHORT}'s branches with their diverged storage and status. The menu
on each branch lets you rename it, delete it, or catch it up with the primary {C.SERVICE_SHORT}, which resets the
branch to the primary's current data.

To move between the primary {C.SERVICE_SHORT} and its branches, use the branch switcher next to the
{C.SERVICE_SHORT} name at the top of the page.

## Billing

A running branch is billed by the minute for its compute, and for the storage that diverges from the primary
{C.SERVICE_SHORT}. Stopping a branch stops the compute charge; the storage charge continues until you delete the
branch.
