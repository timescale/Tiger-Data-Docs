A branch is an isolated copy of a Fluid {C.SERVICE_SHORT}. It starts from the {C.SERVICE_SHORT}'s current data,
runs on its own compute, and stores only the data that differs from the {C.SERVICE_SHORT} it was created from. It is
ready in about a minute whatever the data size. Changes on a branch never reach the {C.SERVICE_SHORT}. Branches are in
public preview, on Fluid {C.SERVICE_SHORT}s only.

## Branches compared with forks

A [fork](../service-management/fork-services) is a full, independent {C.SERVICE_SHORT}. A branch is a lighter copy
with fewer operations:

<ForksVsBranches />

A branch has three tabs in {C.CONSOLE}: `Overview`, `Explorer`, and `Operations`. Its `Operations` tab has two
sections, `Compute and storage` and `Branch management`. Everything else a {C.SERVICE_SHORT} offers, such as high
availability, read replicas, backups and point-in-time recovery, connectors, monitoring, exporters, database
parameters, and upgrades, is not available on a branch. Create a fork when you need any of them.

## Create a branch

<NumberedList>

<NumberedItem title="Open the Branches tab">

In {C.CONSOLE}, select your Fluid {C.SERVICE_SHORT}, click `Branches`, then click `Create new branch`.

</NumberedItem>

<NumberedItem title="Name the branch and choose its compute">

Enter a `Branch name`. It must be unique within the {C.SERVICE_SHORT}. Under `Compute / Memory`, choose the compute
size for the branch. Under `I/O boost`, the IOPS are fixed at the base for that size; choose a larger size to get
more.

</NumberedItem>

<NumberedItem title="Click `Create branch`">

The branch appears in the `Branches` table as `Queued`, then `Ready`, in about a minute. {C.CONSOLE} opens the
branch's `Overview`.

</NumberedItem>

</NumberedList>

## Connect to a branch

The branch's `Overview` shows its connection string, compute, and IOPS under `Branch info`. The branch has its own
host. To set a password for the branch without touching the {C.SERVICE_SHORT}'s credentials, click `Operations` >
`Branch management` > `Reset password`.

## Manage branches

To move between the {C.SERVICE_SHORT} and its branches, use the switcher next to the {C.SERVICE_SHORT} name at the
top of the page. The {C.SERVICE_SHORT} is listed as `Main`; the switcher also lets you create a branch or a read
replica set.

The `Branches` tab lists every branch with its status, `Compute / Memory`, `IOPS`, `Total storage`,
`Pricing est. /mo`, and `Created` date. The menu on each row shows the project, {C.SERVICE_SHORT}, and branch IDs and
lets you `Stop branch` or `Delete branch`.

On the branch itself, `Operations` offers:

- `Compute and storage`: change the branch's compute size and I/O boost, as for a {C.SERVICE_SHORT}.
- `Branch management`:
  - `Reset password`: resets the password for this branch only. Not available while the branch is stopped.
  - `Stop branch`: turns the branch off until you start it again. The {C.SERVICE_SHORT} keeps running.
  - `Delete branch`: deletes the branch and its data permanently. The {C.SERVICE_SHORT} and its data are
    unaffected.

## Billing

A branch's compute is billed by the minute while the branch is running. Storage is billed for the data that differs
between the branch and the {C.SERVICE_SHORT}, not for a full copy, and that charge ends when you delete the branch.
The `Branches` table shows a pricing estimate per month for each branch.
