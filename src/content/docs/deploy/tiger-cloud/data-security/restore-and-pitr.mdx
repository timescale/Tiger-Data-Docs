## Overview

Tiger Cloud provides powerful restore capabilities including Point-in-Time Recovery (PITR), which allows you to restore your database to any specific moment within your backup retention window. This enables precise recovery from data corruption, accidental deletions, or application errors with minimal data loss.

## Prerequisites

- An existing Tiger Cloud database with backups enabled
- Understanding of the incident or recovery point you want to restore to
- Sufficient compute and storage quotas for the restored instance
- Knowledge of your backup retention period and available recovery points

## Best practices

- Regularly verify your recovery window meets your RPO requirements
- Take a new base backup after significant schema changes or tablespace modifications
- Test PITR restores periodically in a non-production environment
- Document the exact recovery point needed before initiating a restore
- Never restore directly over your production instance; always restore to a new instance
- Use cloning for investigation before committing to a full restore
- Validate restored data before redirecting application traffic
