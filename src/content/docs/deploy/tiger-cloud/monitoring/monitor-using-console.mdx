## Overview

The Tiger Cloud Console provides a built-in monitoring dashboard that gives you real-time visibility into your database performance and health. This guide explains how to use the Console to monitor your services, interpret metrics, and identify potential issues.

## Prerequisites

- An active Tiger Cloud service
- Access to the Tiger Cloud Console with appropriate permissions

## Dashboard sections

Understanding the different sections of the monitoring dashboard.

### Health status

Overview of your service health indicators, including:

- Service availability (up/down status)
- Connection status
- Replication health (if applicable)

### Performance metrics

Real-time performance data displayed in the Console:

- Query throughput (queries per second)
- Query latency (average and percentiles)
- Active connections
- Transaction rates

### Resource utilization

System resource metrics including:

- CPU utilization
- Memory usage
- Storage capacity and usage
- Network I/O

### Query insights

Tools for analyzing query performance:

- Slow query identification
- Query execution statistics
- Most frequently executed queries
- Query patterns and trends

## Troubleshooting

Common issues when using the monitoring Console:

- Dashboard not loading or displaying errors
- Metrics showing as unavailable
- Time zone or timestamp discrepancies
- Missing historical data

## Best practices

- Establish performance baselines during normal operation
- Review dashboards regularly, not just during incidents
- Use the Console alongside alerting for comprehensive monitoring
- Focus on metrics that directly impact application performance
- Document baseline values for key metrics
