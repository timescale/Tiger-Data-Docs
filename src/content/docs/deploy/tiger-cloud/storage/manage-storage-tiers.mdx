## Overview

Tiger Cloud's tiered storage architecture enables you to optimize costs by automatically moving older, less frequently accessed data to low-cost object storage while keeping recent data on high-performance storage. This guide covers how to configure and manage storage tiers for your Tiger Cloud services.

## Prerequisites

- An active Tiger Cloud service
- A hypertable with time-series data
- Appropriate permissions to modify tiering policies

## Understanding storage tiers

This section explains the two storage tiers available in Tiger Cloud.

### High-performance tier

Details about the high-performance storage tier:
- Block storage optimized for fast reads and writes
- Ideal for frequently accessed, recent data
- Higher cost per GB

### Low-cost tier

Details about the low-cost object storage tier:
- Amazon S3-based storage for infrequently accessed data
- Significantly lower cost per GB
- Data remains fully queryable via standard SQL
