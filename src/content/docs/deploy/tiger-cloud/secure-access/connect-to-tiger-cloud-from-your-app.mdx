## Overview

This guide explains how to connect your application to Tiger Cloud. You will learn how to construct connection strings, configure SSL/TLS, set up connection pooling, and implement best practices for reliable database connectivity.

## Prerequisites

- An active Tiger Cloud service with connection credentials
- Your application's database driver or ORM installed
- Network access to Tiger Cloud (via public internet, VPC peering, or PrivateLink)
- SSL/TLS support in your database client library

## Finding your connection details

How to locate your Tiger Cloud connection information in the console:

- Host address
- Port number
- Database name
- Username and password

## Connection string formats

Tiger Cloud supports standard PostgreSQL connection string formats.

### URI format

The recommended connection string format using the PostgreSQL URI scheme:

```
postgresql://[user[:password]@][host][:port][/dbname][?options]
```

### Key-value format

Alternative connection string format using key-value pairs:

```
host=... port=... dbname=... user=... password=...
```

### Special character handling

How to properly escape special characters in connection strings, including URL encoding for passwords containing special characters.

## Configuring SSL/TLS

How to configure encrypted connections to Tiger Cloud.

### SSL mode options

Overview of SSL modes and when to use each:

- `require`: Encrypt the connection, but do not verify the server certificate
- `verify-ca`: Encrypt and verify the server certificate is signed by a trusted CA
- `verify-full`: Encrypt, verify the CA, and verify the hostname matches the certificate
