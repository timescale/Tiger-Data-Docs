## Overview

Tiger Cloud supports a curated set of {C.PG} extensions that enhance your database with additional functionality for time-series data, geospatial analysis, full-text search, AI/ML workloads, and more. This reference lists all available extensions and explains how to enable them.

## Prerequisites

- An active Tiger Cloud service
- Appropriate permissions to create extensions
- Understanding of your application's extension requirements

## Enable extensions

How to enable extensions in your Tiger Cloud database.

### Using SQL

```sql
CREATE EXTENSION IF NOT EXISTS extension_name;
```

### Using the Tiger Cloud console

Step-by-step instructions for enabling extensions via the web interface.

## Pre-installed extensions

Extensions that are automatically available on all Tiger Cloud services.

### TimescaleDB

The core time-series extension that powers Tiger Cloud:
- Hypertables for time-series data
- Continuous aggregates
- Data compression
- Tiered storage support

### pg_stat_statements

Query performance monitoring:
- Track execution statistics for all SQL statements
- Identify slow queries
- Monitor query patterns

## Available extensions by category

### Time-series and analytics

| Extension | Description | Version |
|-----------|-------------|---------|
| `timescaledb` | Time-series database functionality | Latest |

| Extension | Description | Version |

| Extension | Description | Version |
