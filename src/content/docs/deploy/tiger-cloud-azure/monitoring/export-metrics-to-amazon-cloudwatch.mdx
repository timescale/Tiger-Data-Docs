## Overview

This guide explains how to export database metrics from your Tiger Cloud services to Amazon CloudWatch for centralized monitoring, visualization, and alerting. CloudWatch integration enables you to correlate database performance with other AWS infrastructure metrics and leverage CloudWatch's powerful analytics capabilities.

## Prerequisites

- An active Tiger Cloud service
- An AWS account with CloudWatch access
- IAM credentials with permissions to write to CloudWatch
- Access to the Tiger Cloud Console
