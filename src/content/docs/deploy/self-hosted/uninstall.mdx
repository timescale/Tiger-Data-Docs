You can uninstall {C.TIMESCALE_DB} without uninstalling {C.PG}. Choose your platform below.

<Tabs>

<TabItem label="Docker">

If you installed {C.TIMESCALE_DB} using Docker, you can completely remove the {C.TIMESCALE_DB} container, image, and optionally the data volumes.

<NumberedList>
<NumberedItem title="Stop the running container">

```bash
docker stop timescaledb
```

If you named your container differently when you created it, replace `timescaledb` with your container name.
</NumberedItem>
<NumberedItem title="Remove the container">

```bash
docker rm timescaledb
```

This removes the container but preserves the data volume and the Docker image.
</NumberedItem>
<NumberedItem title="List and remove the Docker image">

<ol type="a">
<li>

See which {C.TIMESCALE_DB} images you have installed:

```bash
docker images | grep timescale
```

You see something like:

```bash
timescale/timescaledb-ha               pg18      1ec79f20f47d   9 hours ago    6.2GB
```

</li>
<li>

Remove the {C.TIMESCALE_DB} image:

<Tabs>
<TabItem label="TimescaleDB-HA">

```bash
docker rmi timescale/timescaledb-ha:pg18
```

</TabItem>
<TabItem label="TimescaleDB light">

```bash
docker rmi timescale/timescaledb:latest-pg18
```

</TabItem>
</Tabs>

Replace `pg18` with your {C.PG} version.

</li>
</ol>
</NumberedItem>
<NumberedItem title="(Optional) Remove the data">

<Callout variant="warning">
This step permanently deletes all your database data. Only proceed if you're sure you no longer need this data or have backed it up.
</Callout>

List all Docker volumes:

```bash
docker volume ls
```

If you used a named volume when creating your container, remove it:

```bash
docker volume rm <volume-name>
```

If you used a host directory mount (with the `-v </a/local/data/folder>:/pgdata` flag), you can manually delete that directory:

```bash
rm -rf </a/local/data/folder>
```
</NumberedItem>
</NumberedList>

</TabItem>

<TabItem label="Kubernetes">

If you deployed {C.TIMESCALE_DB} on Kubernetes, you can completely remove all associated resources including the StatefulSet, Service, PersistentVolumeClaim, Secret, and application deployments.

<NumberedList>
<NumberedItem title={`Back up any important data from your ${C.TIMESCALE_DB} instance`}>

```shell
kubectl exec -it timescaledb-0 -- pg_dump -U postgres postgres > backup.sql
```
</NumberedItem>
<NumberedItem title="If you created a test pod during installation, delete it">

```shell
kubectl delete pod test-pod
```
</NumberedItem>
<NumberedItem title={`Remove any application deployments that connect to ${C.TIMESCALE_DB}`}>

```shell
kubectl delete deployment tigerdata-app
```
</NumberedItem>
<NumberedItem title={`Remove the service that exposes ${C.TIMESCALE_DB} within the cluster`}>

```shell
kubectl delete service timescaledb
```
</NumberedItem>
<NumberedItem title={`Delete the StatefulSet managing the ${C.TIMESCALE_DB} pods`}>

```shell
kubectl delete statefulset timescaledb
```

This terminates the {C.TIMESCALE_DB} pod.
</NumberedItem>
<NumberedItem title="Delete the PersistentVolumeClaim">

<Callout variant="warning">
Deleting the PersistentVolumeClaim permanently deletes all your database data. Ensure you have backed up any data
you need before proceeding.
</Callout>

```shell
kubectl delete pvc tigerdata-pvc
```
</NumberedItem>
<NumberedItem title="Remove the Kubernetes secret containing database credentials">

```shell
kubectl delete secret tigerdata-secret
```
</NumberedItem>
<NumberedItem title="(Optional) Delete the namespace">
If you created a dedicated namespace for {C.TIMESCALE_DB}, you can remove it as well.

<Callout variant="warning">
Only delete the namespace if you're certain no other resources are using it. This will delete all resources in the namespace.
</Callout>

```shell
kubectl delete namespace tigerdata
```
</NumberedItem>
</NumberedList>

</TabItem>

<TabItem label="Linux">

Take the following steps to uninstall {C.TIMESCALE_DB} based on your distribution:

<Tabs>

<TabItem label="Debian">

<NumberedList>
<NumberedItem title={`Drop the ${C.TIMESCALE_DB} extension from your databases`}>

<ol type="a">
<li>

Connect to each database where {C.TIMESCALE_DB} is enabled and remove the extension:

```bash
sudo -u postgres psql -d <database_name>
```

</li>
<li>

At the `psql` prompt:

```sql
DROP EXTENSION timescaledb CASCADE;
```

</li>
</ol>

Repeat this for all databases with {C.TIMESCALE_DB} enabled. To exit psql, type `\q`.

<Callout variant="warning">
Using `CASCADE` will drop all {C.TIMESCALE_DB}-specific objects including hypertables, continuous aggregates, and retention policies. Ensure you have backed up any data you want to keep.
</Callout>
</NumberedItem>
<NumberedItem title={`Remove ${C.TIMESCALE_DB} from shared_preload_libraries`}>
Edit the {C.PG} configuration file:

```bash
sudo vi /etc/postgresql/18/main/postgresql.conf
```

Find the line with `shared_preload_libraries` and remove `timescaledb` from the list. For example, change:

```
shared_preload_libraries = 'timescaledb'
```

to:

```
shared_preload_libraries = ''
```

If there are other extensions in the list, keep them and only remove `timescaledb`.
</NumberedItem>
<NumberedItem title={`Restart ${C.PG}`}>

```bash
sudo systemctl restart postgresql
```
</NumberedItem>
<NumberedItem title={`Uninstall the ${C.TIMESCALE_DB} package`}>

```bash
sudo apt remove timescaledb-2-postgresql-18
```

Replace `18` with your {C.PG} version if different.
</NumberedItem>
<NumberedItem title={`Remove the ${C.TIMESCALE_DB} repository configuration`}>

```bash
sudo rm /etc/apt/sources.list.d/timescaledb.list
sudo rm /etc/apt/trusted.gpg.d/timescaledb.gpg
sudo apt update
```
</NumberedItem>
<NumberedItem title="Remove dependencies">
Remove unused dependencies installed with {C.TIMESCALE_DB}:

<Callout variant="warning">
This step may also remove {C.PG} as a dependency.
</Callout>

```bash
sudo apt autoremove
```
</NumberedItem>
</NumberedList>

</TabItem>

```bash
brew uninstall timescaledb-tools timescaledb
```


<TabItem label="Windows">

If you installed {C.TIMESCALE_DB} on Windows using a package manager, you can uninstall it without removing {C.PG}.

<NumberedList>
<NumberedItem title={`Drop the ${C.TIMESCALE_DB} extension from your databases`}>

<ol type="a">
<li>

Open Command Prompt or PowerShell and connect to each database where {C.TIMESCALE_DB} is enabled:

```bash
psql -U postgres -d <database_name>
```

</li>
<li>

At the `psql` prompt, remove the extension:

```sql
DROP EXTENSION timescaledb CASCADE;
```

</li>
</ol>

Repeat this for all databases with {C.TIMESCALE_DB} enabled. To exit psql, type `\q`.

<Callout variant="warning">
Using `CASCADE` will drop all {C.TIMESCALE_DB}-specific objects including hypertables, continuous aggregates, and retention policies. Ensure you have backed up any data you want to keep.
</Callout>
</NumberedItem>
<NumberedItem title={`Remove ${C.TIMESCALE_DB} from shared_preload_libraries`}>

<ol type="a">
<li>

Open your {C.PG} configuration file. The default location is:

```
C:\Program Files\PostgreSQL\<version>\data\postgresql.conf
```

You may need to run the editor as Administrator.

</li>
<li>

Find the line with `shared_preload_libraries` and remove `timescaledb` from the list. For example, change:

```
shared_preload_libraries = 'timescaledb'
```

to:

```
shared_preload_libraries = ''
```

If there are other extensions in the list, keep them and only remove `timescaledb`.

</li>
<li>

Save the file.

</li>
</ol>
</NumberedItem>
<NumberedItem title={`Restart ${C.PG}`}>

```powershell
Restart-Service postgresql-x64-18
```

Replace `18` with your {C.PG} version if different.
</NumberedItem>
<NumberedItem title={`Remove ${C.TIMESCALE_DB} binaries`}>
Manually remove the {C.TIMESCALE_DB} files from your {C.PG} installation directory.

<ol type="a">
<li>

Remove {C.TIMESCALE_DB} library files. You may need to run PowerShell as Administrator:

```powershell
Remove-Item "C:\Program Files\PostgreSQL\18\lib\timescaledb*.dll"
```

Replace `18` with your {C.PG} version if different.

</li>
<li>

Remove {C.TIMESCALE_DB} extension files:

```powershell
Remove-Item -Recurse "C:\Program Files\PostgreSQL\18\share\extension\timescaledb*"
```

Replace `18` with your {C.PG} version if different.

</li>
</ol>

<Callout variant="note">
If you encounter permission errors, ensure you're running PowerShell as Administrator.
</Callout>
</NumberedItem>
</NumberedList>
