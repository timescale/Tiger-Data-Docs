import * as C from "@constants";

A major upgrade is when you update from TimescaleDB `X.<minor version>` to `Y.<minor version>`.
A minor upgrade is when you update from TimescaleDB `<major version>.x`, to TimescaleDB `<major version>.y`.
You upgrade your {C.SELF_LONG} installation in-place.

This section shows you how to:

* Upgrade {C.SELF_LONG} to a new [minor version](/deploy/self-hosted/upgrades/minor-upgrade).
* Upgrade {C.SELF_LONG} to a new [major version](/deploy/self-hosted/upgrades/major-upgrade).
* Upgrade {C.SELF_LONG} running in a [Docker container](/deploy/self-hosted/upgrades/upgrade-docker) to a new minor version.
* Upgrade [{C.PG}](/deploy/self-hosted/upgrades/upgrade-pg) to a new version.
* Downgrade {C.SELF_LONG} to the [previous minor version](/deploy/self-hosted/upgrades/downgrade).
