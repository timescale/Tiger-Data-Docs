If you are running {C.TIMESCALE_DB} in a Docker container, there are two
different ways to modify your {C.PG} configuration. You can edit the
{C.PG} configuration file inside the Docker container, or you can set
parameters at the command prompt.

## Edit the {C.PG} configuration file inside Docker

You can start the Docker container, and then use a text editor to edit the
{C.PG} configuration file directly. The configuration file requires one
parameter per line. Blank lines are ignored, and you can use a `#` symbol at the
beginning of a line to denote a comment.

<NumberedList>
<NumberedItem title="Start your Docker instance">
```bash
docker start timescaledb
```
</NumberedItem>
<NumberedItem title="Open a shell">
```bash
docker exec -i -t timescaledb /bin/bash
```
</NumberedItem>
<NumberedItem title="Open the configuration file in your preferred text editor">
```bash
vi $PGDATA/postgresql.conf
```
</NumberedItem>
<NumberedItem title="Restart the container to reload the configuration">
```bash
docker restart timescaledb
```
</NumberedItem>
</NumberedList>

## Setting parameters at the command prompt

If you don't want to open the configuration file to make changes, you can also
set parameters directly from the command prompt inside your Docker container,
using the `-c` option. For example:

```bash
docker run -i -t timescale/timescaledb:latest-pg18 postgres -c max_wal_size=2GB
```
