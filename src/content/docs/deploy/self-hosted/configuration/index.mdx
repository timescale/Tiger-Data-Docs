By default, {C.TIMESCALE_DB} uses the default {C.PG} server configuration
settings. However, in some cases, these settings are not appropriate, especially
if you have larger servers that use more hardware resources such as CPU, memory,
and storage.

*   [Learn about configuration](/deploy/self-hosted/configuration/about-configuration) to understand how it works before you
    begin using it.
*   Use the [{C.TIMESCALE_DB} tune tool](/deploy/self-hosted/configuration/timescaledb-tune).
*   Manually edit the `postgresql.conf` [configuration file](/deploy/self-hosted/configuration/postgres-config).
*   If you run {C.TIMESCALE_DB} in a Docker container, configure
    [within Docker](/deploy/self-hosted/configuration/docker-config).
*   Find out more about the [data that we collect](/deploy/self-hosted/configuration/telemetry).
