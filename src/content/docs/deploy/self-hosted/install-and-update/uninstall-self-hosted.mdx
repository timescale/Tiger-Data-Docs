## Overview

You can uninstall TimescaleDB from your PostgreSQL instance without removing PostgreSQL itself. This guide covers how to safely remove the TimescaleDB extension and clean up related configuration.

## Prerequisites

- Administrative access to your PostgreSQL server
- Superuser privileges on the database
- A backup of any data you want to preserve (uninstalling drops all TimescaleDB objects)

## Before you uninstall

### Back up your data

Dropping the TimescaleDB extension removes all TimescaleDB-specific objects including:

- Hypertables and their data
- Continuous aggregates
- Retention policies
- Compression policies

Ensure you have exported or backed up any data you need to keep.

### Check dependent objects

Review objects that depend on the TimescaleDB extension before removal.

## Remove the TimescaleDB extension

### Step 1: drop the extension from the database

Connect to your database and run the DROP EXTENSION command.

```sql
DROP EXTENSION timescaledb;
```

### Step 2: remove from shared_preload_libraries

Edit your `postgresql.conf` file and remove `timescaledb` from the `shared_preload_libraries` setting.

### Step 3: restart PostgreSQL

Restart the PostgreSQL service to apply configuration changes.

### Step 4: verify removal

Confirm the extension has been removed using the `\dx` command in psql.
