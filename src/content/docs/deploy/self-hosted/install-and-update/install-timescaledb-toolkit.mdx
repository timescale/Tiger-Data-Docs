## Overview

TimescaleDB Toolkit is a {C.PG} extension that provides additional hyperfunctions for advanced time-series analysis. While some hyperfunctions are included with TimescaleDB by default, the Toolkit extension adds specialized functions for statistical analysis, interpolation, and more.

## Prerequisites

- A running TimescaleDB installation
- Superuser privileges on the database
- For package installations: access to the TimescaleDB package repository

## Enable the extension

After installing the package, create the extension in each database where you want to use it.

```sql
CREATE EXTENSION IF NOT EXISTS timescaledb_toolkit;
```

## Update the toolkit

### Install the new version

Update the package using your system's package manager.

### Run ALTER EXTENSION

Upgrade the extension in each database.

```sql
ALTER EXTENSION timescaledb_toolkit UPDATE;
```

## Uninstall the toolkit

### Drop the extension

Remove the extension from your database.

```sql
DROP EXTENSION timescaledb_toolkit;
```

### Remove the package

Uninstall the package using your system's package manager.

## Platform limitations

### Windows

TimescaleDB Toolkit is not currently supported on Windows. Use Docker as a workaround to run {C.PG} with the Toolkit in a container.
