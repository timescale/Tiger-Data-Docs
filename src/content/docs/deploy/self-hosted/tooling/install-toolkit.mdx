Some hyperfunctions are included by default in {C.TIMESCALE_DB}. For additional
hyperfunctions, you need to install the {C.TOOLKIT_LONG} {C.PG}
extension.

If you're hosting the {C.TIMESCALE_DB} extension on your self-hosted database, you can install {C.TOOLKIT_SHORT} by:

*   Using the {C.TIMESCALE_DB} high-availability Docker image
*   Using a package manager such as `yum`, `apt`, or `brew` on platforms where
    pre-built binaries are available
*   Building from source. For more information, see the [{C.TOOLKIT_SHORT} developer documentation](https://github.com/timescale/timescaledb-toolkit#-installing-from-source)

<Callout variant="note">
From {C.TOOLKIT_SHORT} 1.23.0, the extension is `trusted`. A role with the `CREATE` privilege on the database, such as the database owner, can run `CREATE EXTENSION timescaledb_toolkit` without superuser access. Earlier versions require a superuser to create the extension.
</Callout>

<Tabs>

<TabItem label="Docker">

## Install {C.TOOLKIT_LONG}

The {C.TOOLKIT_SHORT} extension is pre-installed and pre-enabled when you
install the {C.TIMESCALE_DB} HA docker image from a Docker container. Once you
start the container, the extension is already active in your database and ready to use. No additional
installation steps are required.

## Update {C.TOOLKIT_LONG}

To get the latest version of {C.TOOLKIT_SHORT}, update the {C.TIMESCALE_DB} HA docker image.

## Uninstall {C.TOOLKIT_LONG}

{C.TOOLKIT_SHORT} is included in the {C.TIMESCALE_DB} HA Docker image and cannot be uninstalled separately. To remove {C.TOOLKIT_SHORT}, you need to remove the entire {C.TIMESCALE_DB} container. See [Uninstall {C.TIMESCALE_DB} from Docker](/deploy/self-hosted/uninstall).

To remove the extension from a specific database without removing the container:

<NumberedList>
<NumberedItem title="Connect to your database">

```bash
docker exec -it timescaledb psql -U postgres -d <database_name>
```
</NumberedItem>
<NumberedItem title={`Drop the ${C.TOOLKIT_SHORT} extension`}>

```sql
DROP EXTENSION IF EXISTS timescaledb_toolkit CASCADE;
```

<Callout variant="warning">
Using `CASCADE` drops all objects that depend on the {C.TOOLKIT_SHORT} extension. Ensure you have backed up any
data you want to keep.
</Callout>
</NumberedItem>
</NumberedList>

</TabItem>

<TabItem label="Kubernetes">

## Install {C.TOOLKIT_LONG}

The {C.TOOLKIT_SHORT} extension is pre-installed and pre-enabled when you
install {C.TIMESCALE_DB} on Kubernetes. Once you start the container, the extension is already
active in your database and ready to use. No additional installation steps are required.

## Update {C.TOOLKIT_LONG}

To get the latest version of {C.TOOLKIT_SHORT}, update the {C.TIMESCALE_DB} HA Docker image used by your Kubernetes StatefulSet:

<NumberedList>
<NumberedItem title="Update the StatefulSet to use the latest image">
Replace `<new-version>` with the desired version tag. For example, `pg18`. You find the available tags on
the [{C.TIMESCALE_DB} HA Docker Hub page](https://hub.docker.com/r/timescale/timescaledb-ha/tags).

```shell
kubectl set image statefulset/timescaledb timescaledb=timescale/timescaledb-ha:<new-version> -n tigerdata
```

Kubernetes performs a rolling update, replacing the pod with the new image version.
</NumberedItem>
<NumberedItem title="Verify the new image is running">

```shell
kubectl get statefulset timescaledb -n tigerdata -o jsonpath='{.spec.template.spec.containers[0].image}'
```
</NumberedItem>
<NumberedItem title={`Connect to your ${C.TIMESCALE_DB} pod and verify the extension versions`}>

```shell
kubectl exec -it test-pod -- bash -c "psql -h \$PGHOST -U \$PGUSER -d \$PGDATABASE"
\dx
```
</NumberedItem>
</NumberedList>

## Uninstall {C.TOOLKIT_LONG}

{C.TOOLKIT_SHORT} is included in the TimescaleDB HA Docker image and cannot be uninstalled separately. To remove {C.TOOLKIT_SHORT}, you need to remove the entire TimescaleDB deployment. See [Uninstall TimescaleDB from Kubernetes](/deploy/self-hosted/uninstall).

If you only want to remove the extension from a specific database without removing the deployment:

<NumberedList>
<NumberedItem title={`Connect to your ${C.TIMESCALE_DB} pod`}>

```shell
kubectl exec -it test-pod -- bash -c "psql -h \$PGHOST -U \$PGUSER -d \$PGDATABASE"
```
</NumberedItem>
<NumberedItem title={`Drop the ${C.TOOLKIT_SHORT} extension`}>
At the `psql` prompt:

```sql
DROP EXTENSION timescaledb_toolkit;
```

<Callout variant="warning">
Using `CASCADE` drops all objects that depend on the {C.TOOLKIT_SHORT} extension. Ensure you have backed up any data
you want to keep.
</Callout>
</NumberedItem>
</NumberedList>

## Install {C.TOOLKIT_LONG}

These instructions use the `apt` package manager.

<NumberedList>
<NumberedItem title="Update your local repository list">

```bash
sudo apt update
```
</NumberedItem>
<NumberedItem title="Install TimescaleDB Toolkit">

```bash
sudo apt install timescaledb-toolkit-postgresql-18
```
</NumberedItem>
<NumberedItem title={`Connect to the database where you want to use ${C.TOOLKIT_SHORT}`}>

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```
</NumberedItem>
<NumberedItem title={`Create the ${C.TOOLKIT_SHORT} extension in the database`}>

```sql
CREATE EXTENSION timescaledb_toolkit;
```
</NumberedItem>
</NumberedList>

## Update {C.TOOLKIT_LONG}

Update {C.TOOLKIT_SHORT} by installing the latest version and running `ALTER EXTENSION`.

<NumberedList>
<NumberedItem title="Update your local repository list">

```bash
apt update
```
</NumberedItem>
<NumberedItem title={`Install the latest version of ${C.TOOLKIT_LONG}`}>

```bash
apt install timescaledb-toolkit-postgresql-18
```
</NumberedItem>
<NumberedItem title={`Connect to the database where you want to use ${C.TOOLKIT_SHORT}`}>

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```
</NumberedItem>
<NumberedItem title={`Update the ${C.TOOLKIT_SHORT} extension in the database`}>

```sql
ALTER EXTENSION timescaledb_toolkit UPDATE;
```

<Callout variant="note">
For some {C.TOOLKIT_SHORT} versions, you might need to disconnect and reconnect active
sessions.
</Callout>
</NumberedItem>
</NumberedList>

## Uninstall {C.TOOLKIT_LONG}

If you no longer need {C.TOOLKIT_SHORT}, you can remove it without uninstalling {C.TIMESCALE_DB} or {C.PG}.

<NumberedList>
<NumberedItem title={`Drop the ${C.TOOLKIT_SHORT} extension from your databases`}>
Connect to each database where {C.TOOLKIT_SHORT} is enabled and remove the extension:

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

At the `psql` prompt:

```sql
DROP EXTENSION IF EXISTS timescaledb_toolkit CASCADE;
```

Repeat this for all databases with {C.TOOLKIT_SHORT} enabled. To exit psql, type `\q`.

<Callout variant="warning">
Using `CASCADE` will drop all objects that depend on the {C.TOOLKIT_SHORT} extension. Ensure you have backed up any data you want to keep.
</Callout>
</NumberedItem>
<NumberedItem title={`Uninstall the ${C.TOOLKIT_SHORT} package`}>

```bash
sudo apt remove timescaledb-toolkit-postgresql-18
```

Replace `18` with your {C.PG} version if different.
</NumberedItem>
<NumberedItem title="(Optional) Remove dependencies">
To also remove unused dependencies:

```bash
sudo apt autoremove
```
</NumberedItem>
</NumberedList>

<Callout variant="warning">
If you encounter an error like `could not access file "$libdir/timescaledb_toolkit-X.XX.X"`, you may need to create a symlink from `.so` to `.dylib` format:

```bash
ln -sf $(pg_config --pkglibdir)/timescaledb_toolkit-*.so \
       $(pg_config --pkglibdir)/timescaledb_toolkit-*.dylib
```

This is due to a known issue in the Homebrew formula where the library is installed with a `.so` extension, but {C.PG} on macOS expects a `.dylib` extension.

## Uninstall {C.TOOLKIT_LONG}

If you installed {C.TOOLKIT_SHORT} by building from source, you can uninstall it without removing {C.TIMESCALE_DB} or {C.PG}.

<NumberedList>
<NumberedItem title={`Drop the ${C.TOOLKIT_SHORT} extension from your databases`}>
Connect to each database where {C.TOOLKIT_SHORT} is enabled and remove the extension:

```bash
psql -d "postgres://<username>:<password>@<host>:<port>/<database-name>"
```

At the `psql` prompt:

```sql
DROP EXTENSION IF EXISTS timescaledb_toolkit CASCADE;
```

Repeat this for all databases with {C.TOOLKIT_SHORT} enabled. To exit psql, type `\q`.

<Callout variant="warning">
Using `CASCADE` will drop all objects that depend on the {C.TOOLKIT_SHORT} extension. Ensure you have backed up any data you want to keep.
</Callout>
</NumberedItem>
</NumberedList>
