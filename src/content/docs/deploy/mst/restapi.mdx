{C.MST_LONG} has an API for integration and automation tasks.
For information about using the endpoints, see the [API Documentation](https://api.aiven.io/doc/).
{C.MST_SHORT} offers an HTTP API with token authentication and JSON-formatted data. You
can use the API for all the tasks that can be performed using the {C.MST_CONSOLE_SHORT}.
To get started you need to first create an authentication token, and then use
the token in the header to use the API endpoints.

## Create an authentication token

<NumberedList>

<NumberedItem title="Open user information">

In [{C.MST_LONG}](https://portal.managed.timescale.com/login), click `User Information` in the top right corner.

</NumberedItem>

<NumberedItem title="Generate a token">

In the `User Profile` page, navigate to the `Authentication` tab. Click `Generate Token`.

</NumberedItem>

<NumberedItem title="Save the token">

In the `Generate access token` dialog, type a descriptive name for the
token and leave the rest of the fields blank. Copy the generated authentication token and save it.

</NumberedItem>

</NumberedList>

## Using cURL to get your details

<NumberedList>

<NumberedItem title="Set the API token">

Set the environment variable `MST_API_TOKEN` with the access token that you generated:

```bash
export MST_API_TOKEN="access token"
```

</NumberedItem>

<NumberedItem title="Query the /me endpoint">

To get the details about the current user session using the `/me` endpoint:

```bash
curl -s -H "Authorization: aivenv1 $MST_API_TOKEN" https://api.aiven.io/v1/me|json_pp
```

The output looks similar to this:

```bash
{
    "user": {
        "auth": [],
        "create_time": "string",
        "features": { },
        "intercom": {},
        "invitations": [],
        "project_membership": {},
        "project_memberships": {},
        "projects": [],
        "real_name": "string",
        "state": "string",
        "token_validity_begin": "string",
        "user": "string",
        "user_id": "string"
    }
}
```

</NumberedItem>

</NumberedList>
