You can configure VPC peering for your {C.MST_LONG} project
using VPC on AWS.

## Before you begin

*   Set up a VPC peering for your project in {C.MST_SHORT}. See [Configure VPC peering](/deploy/mst/vpc-peering/vpc-peering).
*   In your AWS console, go to `My Account` and make a note of your `account ID`.
*   In your AWS console, go to `Peering connections`, find the VPC that you want to
    connect, and make a note of the ID for that VPC.

## Configuring a VPC peering

<NumberedList>

<NumberedItem title="Select the VPC connection">

In [{C.MST_CONSOLE_SHORT}](https://portal.managed.timescale.com/login), click `VPC` and select the VPC connection that you
created.

</NumberedItem>

<NumberedItem title="Enter your AWS account ID">

Type the account ID of your AWS account in `AWS Account ID`.

</NumberedItem>

<NumberedItem title="Enter your AWS VPC ID">

Type the ID of the VPC in AWS in `AWS VPC ID`.

</NumberedItem>

<NumberedItem title="Add the peering connection">

Click `Add peering connection`. A new connection with a status of `Pending Acceptance` is listed in your
AWS console. Verify that the account ID and VPC ID match those listed in {C.MST_CONSOLE_SHORT}.

</NumberedItem>

<NumberedItem title="Accept the request in AWS">

In the AWS console, go to `Actions` and select `Accept Request`. Update your
AWS route tables to match your Aiven CIDR settings.

After you accept the request in AWS Console, the peering connection is active in
the {C.MST_SHORT} portal.

</NumberedItem>

</NumberedList>
