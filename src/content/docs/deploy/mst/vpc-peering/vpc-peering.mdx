You can configure VPC peering for your {C.MST_LONG} project,
using the VPC section of the dashboard for your project. VPC peering setup is a
per project and per region setting. This means that all {C.MST_SERVICE_SHORT}s created and
running utilize the same VPC peering connection. If needed, you can have
multiple projects that peer with different connections. Only Admin and operator user roles can create a VPC.

<NumberedList>

<NumberedItem title="Open the VPC section">

In [{C.MST_CONSOLE_SHORT}](https://portal.managed.timescale.com/login), click `VPC`.

</NumberedItem>

<NumberedItem title="Create a new VPC">

Click `Create VPC`.

</NumberedItem>

<NumberedItem title="Choose a cloud provider">

Choose a cloud provider in the `Cloud` list.

</NumberedItem>

<NumberedItem title="Set the IP range">

In the `IP range` field, type the IP range that you want to use for the VPC connection.
Use an IP range that does not overlap with any networks that you want to connect
through VPC peering. For example, if your own networks use the range 10.0.0.0/8,
you could set the range for your {C.MST_LONG} project VPC to 192.168.0.0/24.

</NumberedItem>

<NumberedItem title="Confirm">

Click `Create VPC`. The state of the VPC is listed in the table.

</NumberedItem>

</NumberedList>
