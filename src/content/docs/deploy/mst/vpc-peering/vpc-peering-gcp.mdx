You can configure VPC peering for your {C.MST_LONG} project
using VPC provided by GCP.

## Before you begin

*   Set up a VPC peering for your project in {C.MST_SHORT}. See [Configure VPC peering](/deploy/mst/vpc-peering/vpc-peering).
*   In your GCP console, click the project name and make a note of the `Project ID`.
*   In your GCP console, go to `VPC Networks`, find the VPC that you want to
    connect, and make a note of the network name for that VPC.

## Configuring a VPC peering on GCP

<NumberedList>

<NumberedItem title="Select the VPC connection">

In [{C.MST_CONSOLE_SHORT}](https://portal.managed.timescale.com/login), click `VPC` and select the VPC connection that you
created.

</NumberedItem>

<NumberedItem title="Enter your GCP project ID">

Type the project ID of your GCP project in `GCP Project ID`.

</NumberedItem>

<NumberedItem title="Enter your GCP VPC network name">

Type the network name of the VPC in GCP in `GCP VPC network name`.

</NumberedItem>

<NumberedItem title="Add the peering connection">

Click `Add peering connection`. A new connection with a status of `Pending Peer` is listed in your GCP
console. Make a note of the project name and the network name.

</NumberedItem>

<NumberedItem title="Create the peering in GCP">

In the GCP console, go to `VPC` > `VPC network peering` and select
`Create Connection`. Type a name for the peering connection and type the project ID and network
name that you made a note of. Click `Create`.

After the peering is successful, it is active in both {C.MST_CONSOLE_SHORT} and your
GCP console.

</NumberedItem>

</NumberedList>
