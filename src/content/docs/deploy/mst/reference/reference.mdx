## Configuration parameters

Reference for adjustable configuration parameters.

### PostgreSQL parameters

Common parameters and their allowed ranges in MST.

| Parameter | Default | Range | Requires restart |
|-----------|---------|-------|------------------|
| `shared_buffers` | 25% of RAM | 128MB - 50% RAM | Yes |
| `work_mem` | 4MB | 1MB - 2GB | No |
| `max_connections` | 100 | 25 - 500 | Yes |
| `effective_cache_size` | 75% of RAM | 128MB - 90% RAM | No |

### TimescaleDB parameters

TimescaleDB-specific configuration options.

| Parameter | Default | Description |
|-----------|---------|-------------|
| `timescaledb.max_background_workers` | 8 | Workers for background jobs |
| `timescaledb.compress_segmentby` | N/A | Segmentation column for compression |
| `timescaledb.compress_orderby` | N/A | Ordering for compressed data |

### Connection pool parameters

PgBouncer configuration options when pooling is enabled.

| Parameter | Default | Description |
|-----------|---------|-------------|
| `pool_mode` | transaction | Pooling mode (transaction, session, statement) |
| `default_pool_size` | 20 | Connections per database/user pair |
| `max_client_conn` | 100 | Maximum client connections |

## API reference

REST API endpoints for managing MST instances.

### Instance management

- `GET /services` - List all instances
- `POST /services` - Create a new instance
- `GET /services/{id}` - Get instance details
- `PATCH /services/{id}` - Update instance configuration
- `DELETE /services/{id}` - Delete an instance

### Configuration management

- `GET /services/{id}/config` - Get current configuration
- `PUT /services/{id}/config` - Update configuration

### Metrics and monitoring

- `GET /services/{id}/metrics` - Retrieve instance metrics
- `GET /services/{id}/logs` - Access instance logs

## Troubleshooting

Common issues and resolution steps.

### Connection issues

- Unable to connect to instance
- Connection timeouts
- SSL/TLS errors
- Authentication failures

### Performance issues

- Slow query performance
- High CPU utilization
- Memory pressure
- Storage I/O bottlenecks

### Data issues

- Compression not working
- Tiering policy not executing
- Retention policy not deleting data
- Continuous aggregate not refreshing

### Operational issues

- Backup failures
- Restore errors
- Upgrade issues
- Replication lag

## Error codes

Common error codes and their meanings.

| Code | Message | Resolution |
|------|---------|------------|
| `53300` | Too many connections | Increase max_connections or use pooling |
| `57014` | Query canceled | Check statement_timeout setting |
| `53100` | Disk full | Increase storage or enable tiering |
