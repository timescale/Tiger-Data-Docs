## Overview

Connect Grafana to your Managed Service for TimescaleDB (MST) instance to create interactive dashboards and visualizations. Grafana's built-in PostgreSQL data source works seamlessly with TimescaleDB, enabling you to visualize time-series data with powerful query capabilities.

## Prerequisites

- An active MST service instance
- Grafana installation (v9.x or later recommended) or Grafana Cloud account
- MST connection credentials (host, port, database, username, password)
- Network access from Grafana to your MST instance

### Using time_bucket for aggregations

How to use TimescaleDB's `time_bucket` function in Grafana queries for efficient time-based aggregations.

```sql
SELECT
  time_bucket('1 hour', time) AS time,
  AVG(value) as avg_value
FROM metrics
WHERE $__timeFilter(time)
GROUP BY 1
ORDER BY 1
```

## Troubleshooting

Common issues and solutions when using Grafana with MST.

- **Connection timeout errors**: Check network connectivity and firewall rules
- **Empty panels**: Verify time range selection and column naming in queries
- **Slow dashboard loading**: Optimize queries and consider using continuous aggregates
- **Authentication errors**: Confirm database credentials and user permissions
