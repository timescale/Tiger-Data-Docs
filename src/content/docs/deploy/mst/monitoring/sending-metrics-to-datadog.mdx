## Overview

Integrate your Managed Service for TimescaleDB (MST) instance with Datadog for comprehensive monitoring, alerting, and visualization. Datadog's PostgreSQL integration provides deep visibility into database performance, query metrics, and resource utilization.

## Prerequisites

- An active MST service instance
- A Datadog account with an active subscription
- Datadog API key
- Network access from Datadog to your MST instance (or a Datadog Agent with access)

## Configuring the PostgreSQL integration

This section explains how to set up Datadog's PostgreSQL integration for MST.

### Creating a monitoring user

How to create a read-only database user with appropriate permissions for Datadog monitoring.

```sql
CREATE USER datadog WITH PASSWORD '<PASSWORD>';
GRANT pg_monitor TO datadog;
GRANT SELECT ON pg_stat_database TO datadog;
```

## Troubleshooting

Common issues and solutions when integrating MST with Datadog.

- **No metrics appearing**: Verify Agent connectivity and check configuration syntax
- **Authentication errors**: Confirm database user permissions and credentials
- **Missing DBM data**: Ensure pg_stat_statements extension is enabled
- **High Agent resource usage**: Review metric collection frequency and scope
