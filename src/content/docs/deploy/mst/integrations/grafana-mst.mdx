You can integrate {C.MST_LONG} with Grafana to visualize your
data. Grafana service in {C.MST_SHORT} has built-in Prometheus, {C.PG}, Jaeger, and
other data source plugins that allow you to query and visualize data from a
compatible database.

## Before you begin

*   Created a {C.MST_SERVICE_LONG}
*   Created a Grafana service

## Configure {C.MST_LONG} as a data source

You can configure a {C.MST_SERVICE_LONG} as a data source to a Grafana service
to query and visualize the data from the database.

<NumberedList>

<NumberedItem title="Set up the Datasource integration">

In [{C.MST_CONSOLE_SHORT}](https://portal.managed.timescale.com/login), click the
{C.MST_SERVICE_SHORT} that you want to add as a data source for the Grafana service. In the `Overview` tab, go to the `Service Integrations`
section and click `Set up integration`. In the `Available service integrations for TimescaleDB` dialog, click
the `Use Integration` button for `Datasource`.

</NumberedItem>

<NumberedItem title="Enable the Grafana service">

In the dialog that appears, choose the Grafana service in the drop-down menu,
and click the `Enable` button.

</NumberedItem>

<NumberedItem title="Open and log in to Grafana">

In the `Services` view, click the Grafana service to which you added the {C.MST_SHORT}
{C.MST_SERVICE_SHORT} as a data source. In the `Overview` tab for the Grafana service, make a note of the `User` and
`Password` fields, then click the link in the
`Service URI` field to open Grafana. Log in with your service credentials.

</NumberedItem>

<NumberedItem title="Verify the data source">

Navigate to `Configuration` → `Data sources`. The data sources page lists
{C.MST_LONG} as a configured data source for the Grafana instance.

</NumberedItem>

</NumberedList>

When you have configured {C.MST_LONG} as a data source in
Grafana, you can create panels that are populated with data using SQL.
