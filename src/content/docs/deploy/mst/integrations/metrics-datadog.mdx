Datadog is a popular cloud-based monitoring service. You can send metrics to
Datadog using a metrics collection agent for graphing, service dashboards,
alerting, and logging. {C.MST_LONG} ({C.MST_SHORT}) can send data
directly to Datadog for monitoring. Datadog integrations are provided free of
charge on {C.MST_LONG}.

You need to create a Datadog API key, and use the key to enable metrics for your
{C.MST_SERVICE_LONG}.

<Callout variant="note">

Datadog logging is not currently supported on {C.MST_SHORT}.

</Callout>

## Before you begin

*   Created a {C.MST_SERVICE_LONG}.
*   Signed up for [Datadog](https://app.datadoghq.com/), and can log in to your Datadog
    dashboard.
*   Created an API key in your Datadog account. For more information
    about creating a Datadog API key, see [Datadog API and Application Keys](https://docs.datadoghq.com/account_management/api-app-keys/).

## Upload a Datadog API key

To integrate {C.MST_SHORT} with Datadog you need to upload the
API key that you generated in your Datadog account to {C.MST_SHORT}.

<NumberedList>

<NumberedItem title="Navigate to Integration Endpoints">

In [{C.MST_CONSOLE_SHORT}](https://portal.managed.timescale.com/login), choose the project you want to connect to Datadog,
and click `Integration Endpoints`.

</NumberedItem>

<NumberedItem title="Create a new Datadog endpoint">

Select `Datadog`, then choose `Create new`.

In `Add new Datadog service integration`, complete these details:

*   In the `Endpoint integration` section, give your endpoint a name, and
    paste the API key from your Datadog dashboard. Ensure you choose the
    site location that matches where your Datadog service is hosted.
*   _Optional_: In the `Endpoint tags` section, you can add custom tags
    to help you manage your integrations.

Click `Add endpoint` to save the integration.

<Image src={imgAddDatadogIntegration} alt="Adding a Datadog integration endpoint in MST" />

</NumberedItem>

</NumberedList>

## Activate Datadog integration for a {C.MST_SERVICE_SHORT}

When you have successfully added the endpoint, you can set up one of your
{C.MST_SERVICE_SHORT}s to send data to Datadog.

<NumberedList>

<NumberedItem title="Select the service">

Sign in to {C.MST_CONSOLE_SHORT}, navigate to `Services`, and select the {C.MST_SERVICE_SHORT} you want to monitor.

</NumberedItem>

<NumberedItem title="Enable Datadog Metrics">

In the `Integrations` tab, go to `External integrations` section and select
`Datadog Metrics`. In the `Datadog integration` dialog, select the Datadog endpoint
that you created and click `Enable`.

The Datadog endpoint is listed under `Enabled integrations` for the
{C.MST_SERVICE_LONG}.

</NumberedItem>

</NumberedList>

## Datadog dashboards

When you have your Datadog integration set up successfully, you can use the
Datadog dashboard editor to configure your visualizations. For more information,
see the [Datadog Dashboard documentation](https://docs.datadoghq.com/dashboards/).
