TimescaleDB Enterprise includes pre-configured dashboards for cluster health, available from the
console. They populate automatically once your cluster is running, so there is no separate metrics
stack to set up.

## What you can monitor

- **Host metrics**: CPU, memory, disk, and network for each host.
- **Database metrics**: activity, throughput, and query performance.
- **Connection metrics**: connection pooler and client connections.

## Health status

The console shows the health of each cluster. If a health card or dashboard stays empty or red, a
required port is usually blocked between the console and the host. See
[Troubleshooting](/deploy/enterprise/support/troubleshooting).
