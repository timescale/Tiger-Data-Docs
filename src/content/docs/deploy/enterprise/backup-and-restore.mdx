TimescaleDB Enterprise runs incremental backups automatically and supports point-in-time restore,
all from the console.

## Back up

- Scheduled backups run automatically on the schedule you set.
- Run an on-demand backup at any time from the console.
- To isolate backup storage from the database host, register a dedicated backup host when you
  [register your infrastructure](/get-started/enterprise/register-hosts).

## Restore

Restore from the console by choosing a target time. The cluster restores to its state at that
point, using the incremental backups and write-ahead logs.
