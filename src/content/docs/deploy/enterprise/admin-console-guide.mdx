The console is where you run and monitor a TimescaleDB Enterprise deployment day to day. To
install it, see [Install the console](/get-started/enterprise/install-console). This page is a
guide to what lives where.

- **Hosts**: register and manage the infrastructure hosts your clusters run on. See
  [Register infrastructure hosts](/get-started/enterprise/register-hosts).
- **Clusters**: deploy clusters and view connection details. See
  [Manage your cluster](/deploy/enterprise/cluster-management).
- **Monitoring**: pre-configured dashboards for cluster health. See
  [Monitor your cluster](/deploy/enterprise/monitoring).
- **Backups**: schedule backups and restore to a point in time. See
  [Back up your cluster](/deploy/enterprise/backup-and-restore).
- **Upgrades**: coordinate {C.TIMESCALE_DB} and {C.PG} version upgrades. See
  [Upgrade TimescaleDB and PostgreSQL](/deploy/enterprise/upgrades).
- **Support**: generate a diagnostic bundle for the support team. See
  [Generate a support bundle](/deploy/enterprise/support).
