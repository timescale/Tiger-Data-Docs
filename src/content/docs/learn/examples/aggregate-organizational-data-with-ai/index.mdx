## Overview

Your business already has the answers in Slack threads, GitHub pull requests, Linear tasks, your own docs, Salesforce service tickets, anywhere you store data. However, those answers are scattered, hard to find, and often forgotten. {C.EON_LONG} automatically integrates {C.AGENTS_LONG} with your organizational data so you can let AI Assistants analyze your company data and give you the answers you need. For example:

- What did we ship last week?
- What's blocking the release?
- Summarize the latest GitHub pull requests.

{C.EON_SHORT} responds instantly, pulling from the tools you already use. No new UI, no new workflow, just answers in Slack.

![Query Tiger Agent](https://assets.timescale.com/docs/images/tiger-eon-big-question.png)

By the end of this tutorial, you'll be able to:

- Install and run {C.EON_SHORT} with Docker and Tiger CLI
- Connect Slack, Anthropic, and optionally GitHub and Linear to {C.EON_SHORT}
- Ask questions in Slack and get answers from your organizational data stored in a {C.SERVICE_LONG}

(Optional) You can also watch a walkthrough [on the Tiger Data YouTube channel](https://www.youtube.com/@tigerdata) (insert video link when available).

## Background

{C.EON_LONG}:

- **Unlocks hidden value**: your data in Slack, GitHub, and Linear already contains the insights you need. {C.EON_SHORT} makes them accessible.
- **Enables faster decisions**: no need to search or ask around, you get answers in seconds.
- **Is easy to use**: {C.EON_SHORT} runs a {C.AGENTS_SHORT} and MCP servers statelessly in lightweight Docker containers.
- **Integrates seamlessly with {C.CLOUD_LONG}**: {C.EON_SHORT} uses a {C.SERVICE_LONG} so you securely and reliably store your company data. Prefer to self-host? Use a [{C.PG} instance with {C.TIMESCALE_DB}](/deploy/self-hosted/install-and-update/install-self-hosted).

{C.EON_LONG}'s real-time ingestion system connects to Slack and captures everything: every message, reaction, edit, and channel update. It can also process historical Slack exports. {C.EON_SHORT} had instant access to years of institutional knowledge from the very beginning.

All of this data is stored in your {C.SERVICE_LONG} as time-series data: conversations are events unfolding over time, and {C.CLOUD_LONG} is purpose-built for precisely this. Your data is optimized by:

- Automatically partitioning the data into 7-day chunks for efficient queries
- Compressing the data after 45 days to save space
- Segmenting by channel for faster retrieval

When someone asks {C.EON_SHORT} a question, it uses simple SQL to instantly retrieve the full thread context, related conversations, and historical decisions. No rate limits. No API quotas. Just direct access to your data.

## What is the tech stack we're working with?

**Tiger Eon:** A production-ready system that runs AI agents and MCP servers to connect your organizational data (Slack, GitHub, Linear) with a Tiger Cloud service. It uses [Tiger CLI](https://github.com/timescale/tiger-cli/) and [Tiger Agents for Work](https://github.com/timescale/tiger-agents-for-work) so you can ask questions in Slack and get answers from your company data in seconds.

- **Tiger Cloud** stores the ingested data as time-series and powers the agents.
- **Docker Compose** runs the local components (ingest app, listener app, MCP servers) in lightweight containers.

## Prerequisites

<PrereqAccount />

- [Install Docker](https://docs.docker.com/engine/install/) on your developer device
- Install [{C.CLI_LONG}](https://github.com/timescale/tiger-cli/)
- Have rights to create an [Anthropic API key](https://console.anthropic.com/settings/keys)
- Optionally:
  - Have rights to create a [GitHub token](https://github.com/settings/tokens/new?description=Tiger%20Agent&scopes=repo,read:org)
  - Have rights to create a [Logfire token](http://logfire.pydantic.dev/docs/how-to-guides/create-write-tokens/)
  - Have rights to create a [Linear token](https://linear.app/docs/api-and-webhooks#api-keys)

<Callout variant="note">
  You will create two Slack apps (ingest and listener) during setup. Have access to create apps in your Slack workspace (e.g. at https://api.slack.com/apps/).
</Callout>

## Interactive setup

{C.EON_LONG} is a production-ready repository running [{C.CLI_LONG}](https://github.com/timescale/tiger-cli/) and [{C.AGENTS_LONG}](https://github.com/timescale/tiger-agents-for-work) that creates and runs the following components for you:

- An ingest Slack app that consumes all messages and reactions from public channels in your Slack workspace
- A [{C.AGENTS_SHORT}](https://github.com/timescale/tiger-agents-for-work) that analyzes your company data for you
- A {C.SERVICE_LONG} instance that stores data from the Slack apps
- MCP servers that connect data sources to {C.EON_SHORT}
- A listener Slack app that passes questions to the {C.AGENTS_SHORT} when you @tag it in a public channel, and returns the AI analysis on your data

All local components are run in lightweight Docker containers via Docker Compose.

<NumberedList>

  <NumberedItem title={`Install ${C.EON_LONG} to manage and run your AI-powered Slack bots`}>

    In a local folder, run the following command from the terminal:
    ```shell
    git clone git@github.com:timescale/tiger-eon.git
    ```

  </NumberedItem>

  <NumberedItem title={`Start the ${C.EON_SHORT} setup`}>

    ```shell
    cd tiger-eon
    ./setup-tiger-eon.sh
    ```
    You see a summary of the setup procedure. Type `y` and press `Enter`.

  </NumberedItem>

  <NumberedItem title={`Create the ${C.SERVICE_LONG} to use with ${C.EON_SHORT}`}>

    You see `Do you want to use a free tier Tiger Cloud Database? [y/N]:`. Press `Y` to create a free
    {C.SERVICE_LONG}.

    {C.EON_SHORT} opens the {C.CLOUD_LONG} authentication page in your browser. Click `Authorize`. {C.EON_SHORT} creates a
    {C.SERVICE_LONG} called [tiger-eon](https://console.cloud.timescale.com/dashboard/services) and stores the credentials in your local keychain.

    If you press `N`, the {C.EON_SHORT} setup creates and runs {C.TIMESCALE_DB} in a local Docker container.

  </NumberedItem>

  <NumberedItem title="Create the ingest Slack app">

    <ol type="a">
    <li>

    In the terminal, name your ingest Slack app:

    <ol type="i">
    <li>{C.EON_SHORT} proposes to create an ingest app called `tiger-slack-ingest`, press `Enter`.</li>
    <li>Do the same for the App description.</li>
    </ol>

    {C.EON_SHORT} opens `Your Apps` in https://api.slack.com/apps/.

    </li>
    <li>

    Start configuring your ingest app in Slack. In the Slack `Your Apps` page:

    <ol type="i">
    <li>Click `Create New App`, click `From an manifest`, then select a workspace.</li>
    <li>Click `Next`. Slack opens `Create app from manifest`.</li>
    </ol>

    </li>
    <li>

    Add the Slack app manifest:

    <ol type="i">
    <li>In terminal press `Enter`. The setup prints the Slack app manifest to terminal and adds it to your clipboard.</li>
    <li>In the Slack `Create app from manifest` window, paste the manifest.</li>
    <li>Click `Next`, then click `Create`.</li>
    </ol>

    </li>
    <li>

    Configure an app-level token:

    <ol type="i">
    <li>In your app settings, go to `Basic Information`.</li>
    <li>Scroll to `App-Level Tokens`.</li>
    <li>Click `Generate Token and Scopes`.</li>
    <li>Add a `Token Name`, then click `Add Scope` add `connections:write`, then click `Generate`.</li>
    <li>Copy the `xapp-*` token and click `Done`.</li>
    <li>In the terminal, paste the token, then press `Enter`.</li>
    </ol>

    </li>
    <li>

    Configure a bot user OAuth token:

    <ol type="i">
    <li>In your app settings, under `Features`, click `App Home`.</li>
    <li>Scroll down, then enable `Allow users to send Slash commands and messages from the messages tab`.</li>
    <li>In your app settings, under `Settings`, click `Install App`.</li>
    <li>Click `Install to &lt;workspace name&gt;`, then click `Allow`.</li>
    <li>Copy the `xoxb-` Bot User OAuth Token locally.</li>
    <li>In the terminal, paste the token, then press `Enter`.</li>
    </ol>

    </li>
    </ol>

  </NumberedItem>

  <NumberedItem title={`Create the ${C.EON_SHORT} Slack app`}>

    Follow the same procedure as you did for the ingest Slack app.

  </NumberedItem>

  <NumberedItem title={`Integrate ${C.EON_SHORT} with Anthropic`}>

    The {C.EON_SHORT} setup opens https://console.anthropic.com/settings/keys. Create a Claude Code key, then
    paste it in the terminal.

  </NumberedItem>

  <NumberedItem title={`Integrate ${C.EON_SHORT} with Logfire`}>

    If you would like to integrate logfire with {C.EON_SHORT}, paste your token and press `Enter`. If not, press `Enter`.

  </NumberedItem>

  <NumberedItem title={`Integrate ${C.EON_SHORT} with GitHub`}>

    The {C.EON_SHORT} setup asks if you would like to enable the GitHub MCP server so {C.EON_SHORT} can answer questions
    about the activity in your GitHub organization. Press `y` to integrate with GitHub.

  </NumberedItem>

  <NumberedItem title={`Integrate ${C.EON_SHORT} with Linear`}>

    The {C.EON_SHORT} setup asks if you would like to `Enable linear MCP server? [y/N]:`. Press `y` to integrate with Linear.

  </NumberedItem>

  <NumberedItem title={`Give ${C.EON_SHORT} access to private repositories`}>

    <ol type="a">
    <li>The setup asks if you would like to include access to private repositories. Press `y`.</li>
    <li>Follow the GitHub token creation process.</li>
    <li>In the {C.EON_SHORT} setup add your organization name, then paste the GitHub token.</li>
    </ol>

    The setup sets up a new {C.SERVICE_LONG} for you called `tiger-eon`, then starts {C.EON_SHORT} in Docker.

    ![Eon running in Docker](https://assets.timescale.com/docs/images/tiger-eon-docker-services.png)

  </NumberedItem>

</NumberedList>

You have created:

- The {C.EON_SHORT} ingest and chat apps in Slack
- A private MCP server connecting {C.EON_SHORT} to your data in GitHub
- A {C.SERVICE_LONG} that securely stores the data used by {C.EON_SHORT}
