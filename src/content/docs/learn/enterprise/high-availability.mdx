TimescaleDB Enterprise runs your database as a cluster with automatic failover. If a node goes
down, the console promotes a standby and reroutes connections, so the database keeps serving
without manual intervention.

This is high availability for infrastructure you own and run yourself, which isn't the same as
failover in a managed cloud: the hardware and network stay with you, and TimescaleDB Enterprise
takes care of the coordination. To turn it on for a cluster, see
[Configure high availability](/deploy/enterprise/high-availability).
