# Querying time-series data

Learn how to write efficient queries for time-series workloads.

## Time-Based filtering

Always include time constraints in your WHERE clause:

```sql path=null start=null
SELECT * FROM conditions
WHERE time > NOW() - INTERVAL '1 day';
```

## Time buckets

Group data into time intervals using `time_bucket`:

```sql path=null start=null
SELECT 
  time_bucket('1 hour', time) AS bucket,
  AVG(temperature) AS avg_temp
FROM conditions
WHERE time > NOW() - INTERVAL '7 days'
GROUP BY bucket
ORDER BY bucket;
```
