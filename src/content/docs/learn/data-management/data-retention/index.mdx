Data retention helps you save on storage costs by deleting old data. You can
combine data retention with [{C.CAGG}s](/build/continuous-aggregates/create-a-continuous-aggregate) to downsample your
data.

In this section:

- [Learn about data retention](/learn/data-management/data-retention/about-data-retention) before you start using it
- [Learn about data retention with {C.CAGG}s](/learn/data-management/data-retention/data-retention-with-continuous-aggregates)
  for downsampling data
- Create a [data retention policy](/build/data-management/data-retention/create-a-retention-policy)
- [Manually drop {C.CHUNK}s](/learn/data-management/data-retention/manually-drop-chunks) of data
