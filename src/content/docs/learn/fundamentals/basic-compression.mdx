TimescaleDB's native compression can reduce storage by 90%+ while often improving query performance.

## How compression works

TimescaleDB compresses data at the chunk level, converting row-oriented data into a columnar format optimized for analytics queries.

## Enabling compression

```sql path=null start=null
-- Enable compression on a hypertable
ALTER TABLE conditions SET (
  timescaledb.compress,
  timescaledb.compress_segmentby = 'location'
);

-- Add a compression policy
SELECT add_compression_policy('conditions', INTERVAL '7 days');
```

## Benefits

- **Storage Savings**: 90%+ compression ratios are common
- **Query Performance**: Analytical queries often run faster on compressed data
- **Cost Reduction**: Less storage = lower cloud costs
