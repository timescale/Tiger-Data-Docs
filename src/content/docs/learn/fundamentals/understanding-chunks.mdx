Chunks are the underlying mechanism that makes hypertables fast and scalable.

## What are Chunks?

When you insert data into a hypertable, TimescaleDB automatically creates "chunks" - smaller tables that hold data for specific time ranges. This happens transparently; you interact with the hypertable as if it were a single table.

## Why Chunks Matter

- **Query Performance**: Queries with time constraints only scan relevant chunks
- **Maintenance**: Operations like compression and deletion work on individual chunks
- **Parallelism**: Multiple chunks can be processed in parallel

## Chunk Intervals

The default chunk interval is 7 days, but you can customize it:

```sql path=null start=null
SELECT create_hypertable('conditions', by_range('time', INTERVAL '1 day'));
```
