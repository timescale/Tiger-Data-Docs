A hypertable is TimescaleDB's core abstraction for handling time-series data. It looks and acts like a regular PostgreSQL table, but automatically partitions your data by time for better performance.

## What is a Hypertable?

A hypertable:
- Automatically partitions data into chunks based on time
- Provides transparent access - query it like a normal table
- Scales to billions of rows without manual partitioning
- Enables time-based data management (compression, retention)

## Creating a Hypertable

```sql path=null start=null
-- First, create a regular table
CREATE TABLE conditions (
  time        TIMESTAMPTZ       NOT NULL,
  location    TEXT              NOT NULL,
  temperature DOUBLE PRECISION  NULL,
  humidity    DOUBLE PRECISION  NULL
);

-- Convert it to a hypertable
SELECT create_hypertable('conditions', by_range('time'));
```
