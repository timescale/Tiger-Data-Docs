From real-time dashboards to performance monitoring and historical trend analysis, data aggregation is a must-have for any sort of analytical application. To address this need, {C.TIMESCALE_DB} uses {C.CAGG}s to precompute and store aggregate data for you. Using {C.PG} [materialized views](https://www.postgresql.org/docs/current/rules-materializedviews.html), {C.TIMESCALE_DB} incrementally refreshes the aggregation query in the background. When you do run the query, only the data that has changed needs to be computed, not the entire dataset. This means you always have the latest aggregate data at your fingertips, and spend as little resources on it, as possible.
