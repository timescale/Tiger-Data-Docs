# Cloud-exclusive features

{C.CLOUD_LONG} includes all the core capabilities of {C.TIMESCALE_DB} — {C.HYPERTABLE}s, {C.HYPERCORE_CAP},
{C.CAGG}s, {C.HYPERFUNC}, and the full {C.PG} ecosystem — plus the following managed-service features
that are only available in {C.CLOUD_LONG}.

## Tiered storage

{C.CLOUD_LONG} provides a [hierarchical storage architecture](/learn/data-management/storage) with two tiers:

- **High-performance tier**: block storage optimized for fast reads and writes, available in standard
  (up to 16 TB, 16K IOPS) and enhanced (up to 64 TB, 32K IOPS) configurations.
- **Object storage tier**: low-cost, virtually unlimited storage backed by AWS S3 or Azure Blob,
  using Apache Parquet format for efficient analytical queries.

Tiering policies automate data movement between tiers based on age, so recent data stays fast
and older data stays affordable. Tiered data remains fully queryable with standard SQL.

## High-availability replicas

{C.CLOUD_LONG} supports automatic failover replicas that maintain a synchronized copy of your
{C.SERVICE_SHORT}. If the primary instance becomes unavailable, the replica is promoted automatically,
minimizing downtime. HA replicas are available on {C.SCALE} and {C.ENTERPRISE} {C.PRICING_PLAN}s.

## Read replicas

Offload read-heavy workloads — dashboards, reporting queries, and analytics — to dedicated
read replicas. Read replicas receive streaming replication from the primary and serve
read-only queries independently, which helps avoid resource contention on the primary.

## Built-in observability

{C.CONSOLE} provides observability tools without requiring additional monitoring infrastructure:

- **Insights**: analyze query performance, identify slow queries, and understand resource
  utilization patterns directly from {C.CONSOLE}.
- **Service metrics**: monitor CPU, memory, storage, and connection usage with built-in dashboards.
- **Alerting**: configure alerts on service health metrics to catch issues before they affect
  your application.
- **External integrations**: export metrics to CloudWatch (AWS) or Azure Monitor for
  integration with your existing monitoring stack.

## Data connectors

{C.CLOUD_LONG} provides built-in connectors for ingesting and exporting data:

- **Source {C.PG} connector**: replicate data from an external {C.PG} database into your {C.SERVICE_SHORT}.
- **Source S3 connector**: import data from CSV and Parquet files stored in Amazon S3.
- **Kafka connector**: stream data from Apache Kafka topics directly into {C.HYPERTABLE}s.
- **{C.LAKE_SHORT}**: export data from {C.CLOUD_LONG} to Apache Iceberg tables for lakehouse
  analytics workflows.

<Callout variant="note">
Connector availability varies by cloud provider and {C.PRICING_PLAN}. See the
[feature comparison](/get-started/feature-comparison) for details.
</Callout>

## Managed security and compliance

{C.CLOUD_LONG} includes security features managed at the platform level:

- **Encryption**: data is encrypted at rest and in transit by default.
- **Network isolation**: VPC peering (AWS), AWS Transit Gateway, and Azure Private Link
  provide private connectivity between your application and {C.SERVICE_SHORT}.
- **SOC 2 compliance**: {C.CLOUD_LONG} is SOC 2 Type II certified.

## Automated operations

{C.CLOUD_LONG} manages the operational overhead of running a production database:

- **Automated backups**: continuous backups with point-in-time recovery (PITR).
- **Upgrades**: {C.PG} major version upgrades, {C.TIMESCALE_DB} updates, and security patches
  are applied automatically with minimal disruption.
- **Scaling**: resize compute and storage independently through {C.CONSOLE} or the {C.REST_LONG}.
