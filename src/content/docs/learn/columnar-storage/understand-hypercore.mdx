{C.HYPERCORE_CAP} is {C.COMPANY}'s hybrid row-columnar storage engine. New data lands in the
{C.ROWSTORE} for fast inserts and updates, then automatically converts to the {C.COLUMNSTORE} where
analytical queries read fewer bytes and run faster. This conversion includes data compression of up to 98%, which dramatically cuts storage costs.

## Why it matters

- **Fast ingest**: the {C.ROWSTORE} handles high-throughput writes, upserts, and deletes with
  full ACID guarantees.
- **Fast analytics**: the {C.COLUMNSTORE} enables efficient scanning and aggregation, with
  [{C.CHUNK_SKIPPING}](/build/performance-optimization/improve-hypertable-performance) to skip
  irrelevant {C.CHUNK}s entirely.
- **Lower storage costs**: 90-98% compression in the {C.COLUMNSTORE} reduces storage without
  sacrificing query performance.
- **Full mutability**: data in both the {C.ROWSTORE} and {C.COLUMNSTORE} supports standard SQL
  `INSERT`, `UPDATE`, `DELETE`, and `UPSERT` with transactional semantics.
