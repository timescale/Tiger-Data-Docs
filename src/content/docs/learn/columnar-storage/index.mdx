# Columnar storage

<Callout variant="tip">
Columnar storage (Hypercore) provides LESS storage with FASTER queries — not just compression for saving space.
</Callout>

Tiger Data's columnar storage capabilities optimize both storage costs and query performance.

**Start here:** Understand how Hypercore works, then set it up, then configure compression methods.
