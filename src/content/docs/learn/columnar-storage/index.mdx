# Columnar storage with Hypercore

<Callout variant="tip">
Hypercore stores older data in a columnar form so analytical queries read fewer bytes and often run faster than scanning wide rows alone. Compression is part of that story, not the only benefit.
</Callout>

Use the links below to learn how Hypercore works, enable it on hypertables, and pick compression settings.
