## Knowledge Check

### Question 1

Which of the following is NOT a characteristic of time-series data?

- A) Data points are ordered by timestamp
- B) Data is rarely updated once written
- C) Queries most often filter by primary key lookup
- D) Write volume is typically high and continuous

### Question 2

Which pattern describes discrete occurrences with associated metadata, for example, a user login event or a machine fault code?

- A) Metrics
- B) Events
- C) States
- D) Rollups

### Question 3

A team stores user profile data (name, email, account tier) alongside application clickstream events in the same database. Which data is time-series?

- A) User profiles only
- B) Clickstream events only
- C) Both, since any data with a timestamp is time-series
- D) Neither, both are relational data

---

## Answers

| # | Answer | Explanation |
| --- | --- | --- |
| 1 | **C** | Time-series queries filter by time range, not by primary key. Primary key lookups are a relational pattern |
| 2 | **B** | Events are discrete occurrences with timestamps and metadata. Metrics are continuous numeric measurements; states track changes over time |
| 3 | **B** | Clickstream events are time-ordered measurements. User profiles are entity records: relational, not time-series |
