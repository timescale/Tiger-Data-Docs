Drop {C.CHUNK}s manually by time value. For example, drop {C.CHUNK}s containing data
older than 30 days.

<Callout variant="note">
Dropping {C.CHUNK}s manually is a one-time operation. To automatically drop {C.CHUNK}s
as they age, set up a
[data retention policy](/build/data-management/data-retention/create-a-retention-policy).
</Callout>

## Drop {C.CHUNK}s older than a certain date

To drop {C.CHUNK}s older than a certain date, use the [`drop_chunks`](/reference/timescaledb/hypertables/drop_chunks)
function. Provide the name of the {C.HYPERTABLE} to drop {C.CHUNK}s from, and a time
interval beyond which to drop {C.CHUNK}s.

For example, to drop {C.CHUNK}s with data older than 24 hours:

```sql
SELECT drop_chunks('conditions', INTERVAL '24 hours');
```

## Drop {C.CHUNK}s between 2 dates

You can also drop {C.CHUNK}s between 2 dates. For example, drop {C.CHUNK}s with data
between 3 and 4 months old.

Supply a second `INTERVAL` argument for the `newer_than` cutoff:

```sql
SELECT drop_chunks(
  'conditions',
  older_than => INTERVAL '3 months',
  newer_than => INTERVAL '4 months'
)
```

## Drop {C.CHUNK}s in the future

You can also drop {C.CHUNK}s in the future, for example, to correct data with the
wrong timestamp. To drop all {C.CHUNK}s that are more than 3 months in the
future, from a {C.HYPERTABLE} called `conditions`:

```sql
SELECT drop_chunks(
  'conditions',
  newer_than => now() + INTERVAL '3 months'
);
```
