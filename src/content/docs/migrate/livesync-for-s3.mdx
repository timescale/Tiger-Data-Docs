This guide walks you through syncing CSV and Parquet files from an Amazon S3 bucket to your {C.SERVICE_LONG} in real time using the {C.S3_CONNECTOR} in {C.CLOUD_LONG}. The connector runs continuously so you can use {C.CLOUD_LONG} as your analytics database with data constantly synced from S3—without building or operating custom ETL between S3 and {C.CLOUD_LONG}.

**What you get:** The connector syncs from an S3 bucket to a {C.SERVICE_LONG} using glob patterns, watches for new files and imports them on a configurable schedule, supports CSV (including GZ and ZIP compression) and Parquet (converted to CSV then processed with timescaledb-parallel-copy), lets you enable a {C.HYPERTABLE} during file-to-table mapping and add {C.COLUMNSTORE} and {C.CAGG}s later in the {C.SQL_EDITOR}, and polls on a default 1-minute interval (configurable with a cron expression).

**File ordering:** The connector processes files in **lexicographical order**. It uses the name of the last file processed as a marker and only fetches files that sort later in the alphabet. Files whose names sort earlier than the marker are skipped and never synced (for example, if the marker is at `Elephant`, a file named `Bob` added later is never processed). For large backlogs, use a 1-minute check until caught up.

<Callout variant="note">
The connector only syncs existing and new files. It does not update or delete records in your {C.CLOUD_LONG} tables when files are updated or deleted in S3.
</Callout>

## Before you start

### Prerequisites

To follow the steps on this page:

- Create a [{C.SERVICE_LONG}](/get-started/create-service/).
- Ensure access to a standard Amazon S3 bucket containing your data files. **Directory buckets are not supported.**
- Configure access credentials for the S3 bucket:
  - **IAM Role:** Set the trust policy `Principal` to `arn:aws:iam::142548018081:role/timescale-s3-connections` and `ExternalID` to your {C.CLOUD_LONG} {C.PROJECT_SHORT} and {C.SERVICE_SHORT} ID in the form `<projectId>/<serviceId>` (to avoid the confused deputy problem). Grant `s3:GetObject` and `s3:ListBucket`.
  - **Public anonymous user:** Supported if the bucket is public.

<NotSupportedAzure />

### Limitations

- **File naming:** Files must follow lexicographical ordering; names that sort earlier than already-processed files are permanently skipped (for example, after `file_2024_01_15.csv` is processed, `file_2024_01_10.csv` added later is never synced). Use timestamps (for example, `YYYY-MM-DD-HHMMSS`) or sequential names with fixed padding (for example, `file_00001`, `file_00002`).
- **CSV:** Max file size 1 GB (contact {C.CONTACT_SALES} to increase), max row size 2 MB. Compressed formats: GZ, ZIP. Delimiter and “skip header” are configurable in advanced settings.
- **Parquet:** Max file size 1 GB, max row size 2 MB.
- **Sync iteration:** Up to 100 files per sync iteration; additional checks only fill empty queue slots.

## How to set up S3 sync

Follow these steps in [{C.CONSOLE}](https://console.cloud.timescale.com/dashboard/services) to connect your S3 bucket and start syncing.

<NumberedList>

<NumberedItem title={`Connect to your ${C.SERVICE_LONG}`}>
In [{C.CONSOLE}](https://console.cloud.timescale.com/dashboard/services), select the {C.SERVICE_SHORT} you want to sync live data into.
</NumberedItem>

<NumberedItem title={`Connect the source S3 bucket to the target ${C.SERVICE_SHORT}`}>
1. Click `Connectors` → `Amazon S3`.
1. Click the pencil icon and set the name for the new connector.
1. Set `Bucket name` and `Authentication method`, then click `Continue`. For IAM role setup, click `Learn how` in the UI. {C.CONSOLE} connects to the source bucket.
1. In `Define files to sync`, choose `File type` and set the `Glob pattern`. Examples:
      - `<folder name>/*` — all files in a folder (patterns ending with `/` are treated as `/*`).
      - `<folder name>/**` — all files recursively.
      - `<folder name>/**/*.csv` — a specific file type.
       Keep filters toward the end of the pattern; complex filtering can cause S3 list operations to time out.
1. Click the search icon to see the files that match, then click `Continue`.

   <Image src={s3ConnectorTigerConsole} alt="Connect Tiger Cloud to S3 bucket" />
</NumberedItem>

<NumberedItem title={`Map schema and optimize for ${C.HYPERTABLE}s`}>
{C.CONSOLE} infers the file schema and, when possible, suggests the time column for a {C.HYPERTABLE}.

<Image src={s3ConnectorCreateTables} alt="S3 connector table selection" />

- Choose `Create a new table for your data` or `Ingest data to an existing table`.
- Set the `Data type` for each column, then click `Continue`.
- Configure insert behavior on conflict, then click `Continue`.
- Choose the polling interval (for example, minute, hour, or a cron expression).
- Click `Start Connector`. {C.CONSOLE} starts the connector and shows progress.
</NumberedItem>

</NumberedList>

You now have continuous sync from your S3 bucket to your {C.SERVICE_LONG}.

## How to monitor synchronization

- **Connector data flow:** Click `Connectors` to see the diagram with connector status and amount of data replicated.
- **Per-connector stats:** Click `Connectors` → `Source connectors`, then select your connector.

   <Image src={s3ConnectorImportDetails} alt="S3 connector import details and stats" />

From the connector dashboard you can:

- **Search by file name** to find specific imports.
- **Filter by status:** All statuses, Cancelled, Failure, In Queue, Paused, Pending Retry, Running, Success.
- **Bulk retry** for files in Error status.
- View **Lifecycle history** for time spent in each status.
- **Refresh every minute** (auto-refresh).

## How to manage the connector

- **Pause:** `Connectors` → `Source connectors` → three-dot menu next to your connector → `Pause`.

  <Image src={s3ConnectorPause} alt="Pause S3 connector" />

- **Edit:** Same table → three-dot menu → `Edit` → `Connector settings`. You must pause the connector before editing.

  <Image src={s3ConnectorEdit} alt="Edit S3 connector settings" />

- **Delete:** Three-dot menu → `Delete` (pause the connector first).

## Summary

You now have continuous sync from your S3 bucket to your {C.SERVICE_LONG}: new files that match your glob pattern are picked up on the schedule you chose, and you can monitor imports and manage the connector (pause, edit, or delete) from {C.CONSOLE} anytime. To extend the pipeline, enable [{C.HYPERTABLE}s](/build/data-management/understand-hypertables), [{C.COLUMNSTORE}](/build/columnar-storage), or [{C.CAGG}s](/build/continuous-aggregates/about-continuous-aggregates) on the synced table via the {C.SQL_EDITOR}.
