Tiger Data is built on {C.PG}, making migration straightforward.

## Overview

Since Tiger Data is compatible with {C.PG}, you can use standard {C.PG} tools like `pg_dump` and `pg_restore`.

## Steps

1. Export your data from {C.PG}
2. Create your Tiger Data service
3. Import the data
4. Convert tables to hypertables
5. Verify the migration
