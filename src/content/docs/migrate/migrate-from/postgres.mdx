Tiger Data is built on PostgreSQL, making migration straightforward.

## Overview

Since Tiger Data is PostgreSQL-compatible, you can use standard PostgreSQL tools like `pg_dump` and `pg_restore`.

## Steps

1. Export your data from PostgreSQL
2. Create your Tiger Data service
3. Import the data
4. Convert tables to hypertables
5. Verify the migration
