# How to upload a file using the Console

This guide walks you through uploading CSV, Parquet, and text files into your {C.SERVICE_LONG} using [Tiger Console](https://console.cloud.timescale.com/dashboard/services). The console has **three upload tabs**: **From CSV**, **From Parquet**, and **From a text file**. Pick the tab that matches your file type, then follow the steps—you can upload from your local machine or from an S3 bucket, with no command-line tools required. You’ll map columns to your table schema, set format options (e.g. delimiter, headers), and monitor import progress in the same interface.

## Before you start

### Prerequisites

- An active Tiger Cloud account with [console access](https://console.cloud.timescale.com/dashboard/services).
- A [Tiger Cloud service](/deploy/tiger-cloud/get-started/create-services) with a database.
- Data files in a supported format (CSV, TSV, Parquet, or text).
- A target table with the right schema, or plan to create one during the import.

### File type tabs in the console

In the upload flow, Tiger Console shows three tabs. Choose the one that matches your file:

- **From CSV** — For comma- or delimiter-separated files (CSV, TSV). You can set delimiter, header row, and null handling.
- **From Parquet** — For Parquet files. The console infers schema and lets you map columns to your table.
- **From a text file** — For other text-based formats. Configure delimiter and parsing options as needed.

### Supported file formats and limits

- **CSV / TSV (From CSV tab):** UTF-8 encoding recommended. Use a consistent delimiter; the first row can be headers. Fields with commas or special characters should be in double quotes. Files must be within the console upload size limits—for very large files, use [Import via Terminal](/migrate/import-terminal) or [Sync from S3](/migrate/livesync-for-s3).
- **Parquet (From Parquet tab):** Supported for upload; follow the same mapping and validation steps. Schema is inferred from the file.
- **Text file (From a text file tab):** Supported for other text formats; set delimiter and options in the console.

<Callout variant="tip">
Validate your file (encoding, headers, delimiter) before uploading. Test with a small sample to confirm column mapping, then run the full import.
</Callout>

## How to upload a file

Follow these steps in Tiger Console to import a file into your service.

<NumberedList>

<NumberedItem title="Open your service and go to import">
In [Tiger Console](https://console.cloud.timescale.com/dashboard/services), select the service you want to load data into, then open the import or upload feature from the dashboard (e.g. **Data** or **Import**).
</NumberedItem>

<NumberedItem title="Choose the file type tab">
Select one of the three tabs: **From CSV**, **From Parquet**, or **From a text file**. The steps that follow depend on this choice (e.g. CSV and text let you set delimiter and header; Parquet infers schema from the file).
</NumberedItem>

<NumberedItem title="Choose where the file comes from">
Select **Upload from your computer** for a local file, or **Import from S3** if the file is in an S3 bucket. If using S3, provide bucket and path (and credentials if required).
</NumberedItem>

<NumberedItem title="Select or create the target table">
Choose an existing table to receive the data, or create a new table. If you create a new table, define column names and types to match your file or let the console suggest a schema from the file.
</NumberedItem>

<NumberedItem title="Upload the file and set import options">
Upload your file (or confirm the S3 path), then set:
- **Delimiter** (e.g. comma, tab) if using CSV/TSV.
- **Header row:** whether the first row is column headers.
- **Null value handling** (how empty or placeholder values are stored).
</NumberedItem>

<NumberedItem title="Map columns">
Review the mapping between file columns and table columns. The console tries to match by name; adjust or override as needed and ensure data types are compatible.
</NumberedItem>

<NumberedItem title="Preview and run the import">
Preview a sample of the data to catch formatting or mapping issues, then start the import. Monitor progress in the console until it completes.
</NumberedItem>

</NumberedList>

Your data is now imported into your Tiger Cloud service.

## Column mapping tips

- **Automatic mapping:** The console matches file headers to table columns by name. Always review before importing.
- **Manual adjustments:** Change mappings when names differ or when you want to skip columns.
- **Data types:** If the console warns about type mismatches, fix the file (e.g. date format, numbers as text) or adjust the target column type.

## Troubleshooting

- **Upload fails or times out:** Use a smaller file or split the data; for large or automated loads, use [Import via Terminal](/migrate/import-terminal).
- **Column mapping errors:** Ensure headers match the expected table columns (including case).
- **Data type or null errors:** Check that values fit the column types and that NOT NULL columns have no empty values, or adjust null handling in the import settings.
- **Encoding issues:** Save the file as UTF-8 to avoid corrupted characters.

## Summary

You can upload CSV, Parquet, and text files into your Tiger Cloud service from your local machine or from S3 using Tiger Console. After mapping columns and setting options, the import runs in the UI—no CLI needed. For continuous sync from S3 or bulk/scripted imports, use [Sync from S3](/migrate/livesync-for-s3) or [Import via Terminal](/migrate/import-terminal).
